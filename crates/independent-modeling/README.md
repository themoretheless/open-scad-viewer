# Чистое и informed геометрическое ядро

Отдельный Rust workspace внутри репозитория. Он не включён в основной CAD
workspace, не использует его геометрические crates и пока не подключён к UI.

| Версия | Содержание |
|---|---|
| `modeling-clean` | Собственные геометрические определения, алгоритмы и проверки по функциональной спецификации |
| `modeling-kernel-informed` | Геометрическая версия с retained B-rep экструзии, совместимостью loft и convex planar clipping; использует общие математические типы clean |
| `modeling-informed` | Отдельный ранее созданный системный слой документа/транзакций; сам по себе не улучшает геометрические алгоритмы |

Первая версия была реализована, проверена и зафиксирована в `clean-baseline.json`
перед созданием второй. `python3 verify_clean.py` проверяет состав и SHA-256
исходников. После создания informed clean не изменялась. Само разделение по
времени и файлам не доказывает формальную чистую комнату: автор ранее видел
результаты реверса. Граница процесса описана в [SPEC.md](SPEC.md).

## Реальное покрытие

Новая геометрическая версия описана в [kernel-informed/README.md](kernel-informed/README.md).
Она добавляет замкнутые рациональные экструзии круга/кольца, arbitrary-workplane
extrusion, loft разных базисов, пересечение повёрнутых convex polyhedra и
разложение разности на convex pieces. Это отдельный путь от старого слоя документа:
его API пока не переподключён к новому ядру. Чистая версия сохранена для сравнения.

Таблица ниже фиксирует покрытие исходной clean-базы и системного слоя документа;
новые возможности kernel-informed не приписываются чистой версии.

| Ветка дерева функций | Реализовано сейчас | Граница |
|---|---|---|
| Кривые | Линии, полилинии, Bézier, рациональные B-сплайны, круг/эллиптическая дуга, спираль | Спираль ломаная; степени 1–16; положительные веса; clamped basis |
| Редактирование кривых | Вставка узла, split, trim, reverse, affine | Сохранение определения в binary64; без knot removal и общего degree elevation |
| Анализ кривых | Производные, касательная, кривизна, дискретная длина | Односторонние производные на узлах; длина без строгой оценки ошибки |
| Поверхности | Рациональный tensor product; extrude/revolve, loft, sweep | Loft piecewise ruled с совместимыми базисами; sweep по ломаной |
| Анализ поверхностей | Частные производные, нормаль, Gaussian/mean curvature | Без доказательства регулярности всей поверхности |
| Тела | Box, cylinder, sphere, torus, extrusion, loft | Явно треугольные тела; не точный криволинейный B-rep |
| Скругления и фаски | Скруглённый/срезанный прямоугольный профиль с экструзией | Не general solid edge fillet/chamfer; скругления семплируются |
| Boolean | Union/intersection/difference/XOR боксами | Осевые боксы; бюджеты клеток; nonmanifold-контакты отклоняются |
| Shell | Внутренняя оболочка бокса с одной открытой стороной или без неё | Не произвольные поверхности/тела |
| Преобразования | Перенос, масштаб, поворот, общая affine, отражение | Невырожденные конечные матрицы; без геометрического сертификата обусловленности |
| Топология и выбор | Инцидентность рёбер, vertex fans, компоненты, соседние треугольники, raycast | Индексированная сетка; не проверка самопересечений и не точный CAD picking |
| Анализ тел | Площадь, signed volume, центр масс, сечение плоскостью | Численное интегрирование; сечение — неупорядоченные сегменты, coplanar отказывается |
| Отображение | Семплирование кривых и поверхностей; отдельный кэш во второй версии | Фиксированное разрешение; нет сертифицированного chord-error bound |
| Файлы | Простой triangle OBJ import/export, ASCII STL export | Без STEP/IGES и формата Plasticity |
| Документ | Групповые транзакции, rollback, undo/redo, снимки, stable IDs | Только informed; bounded snapshot history |
| Фоновые задачи | Изолированное вычисление, проверка ревизии, отмена публикации | Только informed; не preemptive cancellation и не автоматический планировщик |
| Общие NURBS booleans, trim/sew | Не реализовано | Отдельная будущая разработка |
| Surface constraints / XNURBS-подобный solve | Не реализовано | Нет переноса чужого solver |
| Общие offsets, fillets, healing | Не реализовано | Ограниченные профиль/box операции не считаются заменой |

Это рабочая начальная библиотека, а не достижение полного паритета с деревом
Plasticity. Нереализованные ветки не заменены функциями-заглушками с ложным успехом.
У старого `modeling-informed` отдельного геометрического алгоритмического
преимущества нет. Геометрические расширения теперь реализованы отдельно в
`modeling-kernel-informed`; они не являются заменой всего ядра Parasolid.

## Запуск

Из этого каталога:

```sh
cargo +stable test
cargo +stable clippy --all-targets -- -D warnings
python3 verify_clean.py
cargo +stable run -p modeling-informed --example two_versions -- /tmp/modeling-two-versions
cargo +stable run -p modeling-kernel-informed --example compare_kernels -- target/kernel-comparison
```

Пример строит тело с карманом двумя путями, проверяет одинаковую сетку, экспортирует
OBJ/STL и проходит undo/redo. Это проверка организационного слоя, а не независимый
oracle геометрии: обе версии намеренно используют один собственный clean kernel.
Геометрические тесты отдельно сверяют радиусы, кривизну, объёмы и инварианты.
Пример `compare_kernels` сравнивает геометрические представления и область
поддержки clean и kernel-informed; сохраняет JSON с численными результатами и OBJ.

Разработка не загружает и не исполняет код целевого приложения, не требует его
установки и не использует FFI. Все три пакета используют стандартную библиотеку
Rust без внешних Cargo-пакетов; informed и kernel-informed зависят только от
собственного clean. Общая рациональная математика переиспользуется, а новые B-rep,
common refinement/degree elevation и convex clipping реализованы в kernel-informed.

## Проверка и ограничения

Проверены macOS ARM64, Rust stable 1.98.1 и проектный nightly. Набор содержит
12 integration-тестов чистого ядра, 10 integration-тестов документа, 15 integration-
тестов нового геометрического ядра, rustdoc-пример нового ядра и исполняемые
сквозные примеры. Clippy запускается с `-D warnings`.
Численные тесты — конечные сценарии, не доказательство корректности всех входов.
Крупных моделей, экспорта STEP и UI-совместимости эта квалификация не покрывает.

См. [clean](clean/README.md), [informed](informed/README.md) и
[решения второй версии](PROVENANCE.md).
Для нового ядра см. [его provenance](kernel-informed/PROVENANCE.md) и
[зафиксированное сравнение](kernel-informed/qualification/COMPARISON.md).
