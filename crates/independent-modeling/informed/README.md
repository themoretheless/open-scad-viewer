# modeling-informed

Вторая версия независимой библиотеки. Использует собственное замороженное ядро
`modeling-clean`, добавляя документ и операции. Никаких зависимостей от
`nurbs-core`, `brep-core`, Plasticity, Parasolid или других C/C++ библиотек нет.

Архитектурные наблюдения о разделении операций, геометрии, фоновой работы и
отображения повлияли на дизайн. Реализация, имена публичного API и формат
документа не переносились из исследованного приложения. Это не совместимый
клон его ABI, проекта или командного протокола.

## Контракт документа

- Сущности имеют непрозрачный ID и отдельный ID содержимого; отменённые ID не
  переиспользуются. Снимки хранят неизменяемые `Arc` на геометрию.
- `Transaction` публикуется только через `commit`. Drop отменяет изменения.
  Ошибка любой операции запрещает commit всей группы.
- Undo/redo восстанавливают снимки; ревизия при этом монотонно увеличивается.
  Новая операция после undo удаляет ветку redo.
- `prepare` создаёт изолированную задачу. `Job::run` можно вызвать в своём потоке.
  `publish` проверяет документ и исходную ревизию. При конфликте `PublishError`
  сохраняет вычисленный результат для просмотра; автоматического rebase нет.
- Отмена проверяется до и после геометрической операции и перед публикацией.
  Это не прерывание внутренних циклов вычисления и не обещание малой задержки.
- Display mesh/polyline кэшируется отдельно от исходных кривых/поверхностей.
  Ключ включает сущность, содержимое и разрешение. История не хранит display cache.

Пределы: 10000 сущностей; по умолчанию 64 записи undo, настраиваемо до 1024;
64 записи display cache. Геометрические ограничения описаны в clean/README.md.

## Представления и операции

Поддерживаются `Curve`, `Surface`, `Mesh` и переиспользуемые `BoxCells`.
Операции: добавление геометрии; box/cylinder/sphere/torus; экструзия полигона;
extrude/revolve/loft/sweep поверхностей; CSG боксами; shell бокса;
преобразования; вставка узла, trim и split кривой; OBJ import; удаление.

`Transform` для `BoxCells` намеренно возвращает `FacetedMesh`: произвольное
аффинное преобразование не сохраняет осевую модель боксов. Последующий
`BoxBoolean` над такой сущностью возвращает `WrongGeometry`, а не подменяет
вращённое тело его AABB. Split добавляет две кривые, сохраняя исходную;
InsertKnot/Trim/Transform заменяют геометрию той же сущности.

## Пример

```rust
use modeling_informed::{Document, Operation};
use modeling_informed::geometry::math::Bounds;
let mut doc = Document::new()?;
let job = doc.prepare(Operation::Box {
    bounds: Bounds::new([0.0; 3], [2.0, 3.0, 4.0])?,
});
let computed = std::thread::spawn(move || job.run()).join().unwrap()?;
doc.publish(computed)?;
assert_eq!(doc.entities().count(), 1);
doc.undo()?;
assert_eq!(doc.entities().count(), 0);
# Ok::<(), Box<dyn std::error::Error>>(())
```

Геометрическое покрытие совпадает с ядром clean. Вторая версия не добавляет
общие NURBS Boolean, аналитические fillet/shell или решатель поверхностей.
