# Плоский offset кривой с допуском

`nurbs_core::curve_offset::approximate_curve(curve, distance, tolerance_mm, max_cells)` — типизированный Rust API без codec. Аппроксимирует нормальное смещение валидной положительно взвешенной XY NURBS-кривой F(t)=C(t)+distance*(-Cy'(t),Cx'(t))/|C'(t)| непрерывно ограниченными хордами, объединёнными в degree-one NURBS-цепочки. Отрицательное distance меняет сторону; единицы совпадают с координатами.

Исходные рациональные производные до третьего порядка вычисляются интервально на оригинальных узловых интервалах. Доказанная положительная нижняя граница скорости позволяет ограничить вторую производную нормального offset. Ошибка линейной интерполяции ограничена sup|F''|/8 в локальном параметре плюс внешняя граница округления концов. При объединении соседних концов их perturbation добавляется к границе соответствующего сегмента. Источник не меняется.

Сохраняются активный параметрический домен и общие authored-концы цепочки. Каждая Curve имеет не больше 256 контролей, поэтому длинные результаты разбиваются на chunks с общими концами и параметрами. Для периодического источника сохраняется замыкание с учётом ошибки общей точки. closed указывает периодическое хранилище источника, а не общее доказательство топологической валидности региона.

Distance конечный, tolerance положительный конечный, max_cells 1..65536. Нулевое смещение возвращает исходную кривую точно. Ненулевой offset требует C1 базиса внутренних узлов; углы требуют отдельного bevel/miter/иного решения. Неподтверждённая регулярность источника, cusp, невозможность достигнуть допуска в бюджете, неверные данные, слишком малый представимый допуск и арифметическое переполнение возвращают ошибку. Нет silently relaxed допуска или результата по нескольким выбранным точкам.

Это смещение параметрической кривой, а не очищенная граница плоской области: кривизна может вызвать складки и самопересечения offset. API не удаляет их, не строит Boolean-регион, не обрезает соседние участки на углах и не сертифицирует machining-topology. `approximate` отдельно возвращает независимые сегменты; `approximate_curve` соединяет только допустимый гладкий источник. Доказательство относится к входным binary64 данным, без ошибок измерений неизвестной идеальной формы.

Три независимых интеграционных теста `crates/nurbs-core/tests/curve_offset.rs` и семь существующих unit-тестов прошли без default features. Независимая рациональная формула четверти окружности на домене [2,7] проверяет все сегменты для distance=-0.25,0.25,1.25; точный нулевой offset, соединение chunks, отказ для C0-угла, cusp, нехватки ресурсов, некорректных допусков/лимитов и неизменность источника. Существующие проверки также покрывают рациональные и некруговые многопролётные источники и периодические углы.
