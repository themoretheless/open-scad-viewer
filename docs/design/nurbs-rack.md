# Прямая зубчатая рейка в Rust

`nurbs_core::rack::profile(Spec)` возвращает один замкнутый 3D NURBS-контур степени 1 в плоскости XY и геометрические размеры. Начало ширины x=0; делительная линия y=0; нижняя грань y=−dedendum−backing_height. Обход CCW, Z=0. Первая контрольная точка точно повторяется в конце; periodic storage не используется. Максимум 50 зубьев, 4·teeth+5 контрольных точек; веса равны 1. Каждый участок точно описывает соответствующий прямой сегмент исходного binary64-полигона.

Шаг π·module. Толщина на делительной линии π·module/2−backlash. Полуширины вершины и основания равны thickness/2−addendum·tan(angle) и thickness/2+dedendum·tan(angle). Вычисление этих размеров использует обычный binary64, включая π и tan; непрерывный сертификат относительно бесконечно точного угла не заявляется. Контур не проходит spline fit или дискретизацию кривых.

Допускаются 1..50 зубьев, положительные конечные module/addendum/dedendum/backing_height, угол строго между 0 и 45 градусами и неотрицательный backlash, оставляющий положительную толщину. Исчезающая вершина, перекрытие соседних оснований, потеря наклона боков или совпадение соседних вершин из-за точности координат приводят к отказу. Дополнительно действуют лимиты Curve::validate, включая координаты до 1e9. Рейка имеет острые углы и прямые площадки, без root fillet, профильного смещения и оценки прочности/зацепления. Это параметрический профиль, из которого можно строить тела существующими extrusion API.

Два теста Rust без default features независимо проверяют 1,12,50 зубьев: CCW-обход, полное закрытие, шаг, пересечение боков с делительной линией, наклон, аналитическую площадь (прямоугольник основания и сумма трапеций зубьев), положение внутри каждого NURBS-сегмента и отказы при неверных размерах, NaN, схлопывании/перекрытии зубьев и превышении ресурса. WASM/Rush/редактор не подключены и отдельно не квалифицированы.

## Замкнутое тело

`brep_core::rack::extrude(Spec,z_min,z_max)` строит одну B-rep деталь через существующий prism-конструктор. Исходный контур раскладывается только на его реальные линейные рёбра для топологии; зубья не становятся отдельными пересекающимися телами. Получаются один body, по одной плоской NURBS-грани на сегмент и две крышки; число граней 4·teeth+6. Возвращаются Model, исходный Profile и Z-границы. Применяются общие ограничения prism: координаты профиля до 1e6, Z в пределах ±1e6 и толщина минимум 1e-5.

Два теста brep-core проходят: 1,12,50 зубьев, одна деталь, отсутствие открытых топологических рёбер, число граней, плоские поверхности степени 1, объём по независимой формуле площади и толщине, смещённый Z-диапазон и отказы при неверной высоте/ресурсе. Эти проверки подтверждают конкретное призматическое тело; производственная оценка прочности и зацепления по-прежнему отдельно не заявлена.
