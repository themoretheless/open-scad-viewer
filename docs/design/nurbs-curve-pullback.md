# Перенос пространственного контура в UV

`nurbs_core::curve_pullback::project(C,S,Limits)` строит 2D NURBS pcurve для пространственной 3D NURBS относительно исходной tensor NURBS поверхности. Кривая может содержать несколько spans или представлять замкнутый контур. Ищется представление, а не обязательно ближайший/единственный прообраз. Источники неизменны.

Для bilinear/affine candidate преобразуются исходные control points с сохранением степени, knots и положительных весов; это только предложение. Общий путь строит Newton proposals по dyadic source samples и degree-one UV полилинию с сохранением нормализованного параметра исходной кривой. Оба пути принимаются исключительно при полном continuous curve_surface_agreement=WithinTolerance относительно исходной поверхности. Ошибка Newton, выбор локальной ветви, округление построения или недостаточная дискретизация никогда не заменяют такую проверку. Неподтверждённая кривая не возвращается как pcurve: within_tolerance=false, pcurve=None, сохраняются последний report и cumulative counters.

Limits: положительный finite tolerance, max_segments 1..256, max_iterations 1..64, agreement_cells 1..1_000_000; каждый continuous check <=100_000. Число dyadic сегментов не превосходит заданное; лимит Curve в 256 controls ограничивает dyadic refinement 128 сегментами. Все неуспешные проверки включены в общий agreement budget. evaluations включает точечные обращения к исходной кривой и поверхности. Поверхность не обрезается; ветви Newton ограничены её active chart. Для periodic seams или неоднозначных прообразов поиск может остаться unresolved; вне active image сертификат не выдаётся. Топология trim и уникальность прообраза не заявляются.

Проверки: рациональная quadratic кривая на affine plane с неединичными parameter domains — известные UV controls и сохранение weights/degree/knots; кривая естественного сечения quadratic curved support — ожидаемый UV ход, непрерывное согласование и факт использования общего пути; off-surface контур не принимается; нулевые work limits отклоняются. Все 3 независимых теста прошли.
