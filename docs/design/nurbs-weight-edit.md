# Локальное редактирование весов в Rust

`weight_edit::curve(&Curve, &[(index, weight)])` и
`weight_edit::surface(&Surface, &[(u, v, weight)])` возвращают новую
геометрию, сохраняя контрольные точки, степени, узлы и periodic-флаги.
Редактируются абсолютные веса, не множители. Исходный объект не изменяется
даже при ошибке. Проверяются входная геометрия и весь результат.
Пустой запрос отклоняется; максимум 256 правок кривой и 1024 поверхности.
Индексы относятся к хранимому массиву/сети, обязаны быть в диапазоне.

Периодические копии соответствуют одной логической контрольной точке:
правка любой копии обновляет остальные. При двух periodic-осях обновляются
также угловые копии. Повтор одного логического индекса в запросе запрещён,
даже при равных значениях, чтобы порядок запросов не менял результат.
Непериодические совпадающие координаты не считаются алиасами.

Действуют ограничения Curve/Surface: конечные положительные веса
[1e-12,1e12], отношение максимума к минимуму <=1e12 (у поверхности
по всей сети). Правки не нормализуют веса автоматически и не создают
новые узлы. Форма может меняться только в области поддержки базисных
функций изменённых логических весов; для periodic-связанных копий
учитываются все области поддержки.

Операция не гарантирует сохранение касательных, кривизны, регулярности,
простоты контура или отсутствия самопересечений. Сертификат отклонения
от исходной формы не возвращается. Размеры данных ограничены самими
Curve/Surface, сбор правок использует BTreeMap, память O(edit_count+net_size).

Четыре интеграционных теста проверяют независимые рациональные формулы
квадратичной кривой и билинейной поверхности, инвариантность при общем
масштабе весов, периодические алиасы и угловые копии, неправильные
индексы/веса, глобальную обусловленность и неизменность входа при отказе.
API нативный, без обязательных JSON/WASM/TypeScript/Rush адаптеров.

Проверка: все 4 теста weight_edit прошли с no-default-features.
