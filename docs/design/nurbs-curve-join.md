# Геометрический стык концов кривых в Rust

`curve_join::inspect(reference, reference_end, edited, edited_end, Tolerances)`
не меняет кривые. Endpoint=Start/End: касательная reference направлена
к выходу из выбранного конца, edited — ко входу. End→Start использует
естественные направления; Start/End для других сочетаний учитывают
обратный проход. Сторона производных внутренняя к активному домену,
без неявного periodic wrap. Размерности 2D/3D должны совпадать.

Исходные rational jets извлекаются интервально из оригинального knot
span, включая округление blossom и рационального деления, без
материализации округлённой промежуточной кривой. Производные локального
параметра нормализуются: T=v/|v|, K=(a/|v|-T*(T·a/|v|))/|v|.
G0 проверяет норму разницы положений, G1 — норму разницы единичных
касательных, G2 — норму разницы векторов кривизны. Это геометрические
величины, независимые от положительной скорости параметризации.
G1 требует принятого G0; G2 требует принятого G1.

Допуски конечны и неотрицательны: position в единицах координат,
tangent безразмерный (для точных единичных векторов 2*sin(angle/2)),
curvature в обратных единицах координат. Каждый interval сравнивается
с допуском: верхняя граница <=t — WithinTolerance, нижняя >t —
ExceedsTolerance, иначе Unresolved. При принятом G0 и скорости, не отделённой от
нуля, G1/G2 — RegularityUnproven, без выдуманной касательной/кривизны.
Численные переполнения возвращают ошибку. Нулевой допуск может
оставаться Unresolved из-за округления даже на идеальном стыке.

Сертификат относится к точной геометрии записанных binary64 данных
и заданным допускам, не к идеальным размерам исходного CAD-рецепта.
Операция не строит blend, не перемещает контролы, не проверяет весь
контур на самопересечения и не сравнивает третьи производные.
Полный стык поверхностей остаётся отдельной задачей.

Четыре независимых теста: два участка y=x² с разными скоростями
имеют G2; обратный проход edited сохраняет геометрический стык;
изменённая кривизна нарушает G2, прямой угол нарушает G1;
стационарный конец даёт RegularityUnproven; разные домены и общие
масштабы весов сохраняют результат, зазор нарушает G0,
недопустимый допуск отклоняется. Все прошли с no-default-features.

Расширенная проверка: все 7 тестов curve_join прошли. Дополнительно
проверены прямые с различными рациональными весами (нелинейные
параметризации), Start→Start с обратным проходом reference и
пространственная [x,x²,x³] с разными скоростями. Изменение третьей
производной edited при неизменном втором jet не нарушает G2.
Доказанное нарушение G0 теперь передаётся в G1/G2 даже при
стационарном конце: недоказанная регулярность не скрывает уже
доказанный зазор. При неизвестном G0 сохраняется его Unresolved.
