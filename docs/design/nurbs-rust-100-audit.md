# 100 полезных возможностей в Rust

Пользователь уточнил цель: любые 100 полезных возможностей в Rust, а не первые 100 пунктов исходного списка. Ниже фиксированная выборка: все 47 native-записей и первые 53 integrated-записи, у каждой указан нативный API. Расширенный каталог 1200 остаётся отдельным историческим roadmap, без требования закончить его для этой цели.

Критерий этой цели: доступный typed Rust API, реализованная геометрия/операция, проверки геометрии и неправильных входов, документированные ограничения. Наличие визуальной/STEP квалификации приложения не требуется для нативного API. Неподдерживаемые случаи и незавершённые сертификаты сохраняются в remainingQualification каталога.

Число 100 означает возможности, а не 100 независимых алгоритмов: общие ядра рациональных дуг, sweep и измерений переиспользуются. Частичные planned-возможности, включая произвольный перенос periodic seam и полный поверхностный G1/G2, в выборку не включены.
