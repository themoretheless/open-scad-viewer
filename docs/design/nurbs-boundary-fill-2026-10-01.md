# Многограничное заполнение веером патчей: NURBS-0059

Статус: integrated. WASM/TypeScript/Rush, пример и export regression
подключены. Визуальная/STEP-квалификация ещё ожидают выполнения.

`boundary_fill::fan(boundaries,center)` принимает 3..32 непериодические
рациональные 3D-кривые, ориентированные вокруг одного замкнутого контура,
и конечную центральную точку. Последний конец каждой активной кривой должен
точно совпадать с первым концом следующей, включая замыкание последней
на первую. Snapping, изменение ориентации и выбор центра не выполняются.

Для каждого ребра создаётся трёхграничный патч: исходная кривая и две
прямые от её концов к центру. Спицы используют единичные веса и одинаковую
Cartesian-параметризацию в обоих соседних патчах. Результат — массив
отдельных рациональных NURBS-поверхностей, сохраняющих весь внешний
контур и согласующих общие спицы по G0 в вещественной арифметике.

Центр может быть вне плоскости контура. Каждый патч имеет нормированные
домены [0,1]² и намеренную сингулярность V=1 в центре. Положительность
весов и бюджет 32 контроля по оси наследуются от трёхграничного Coons-патча.
G1/G2 по спицам, простота контура, положение центра внутри него,
инъективность, отсутствие перекрытий и solid-топология не сертифицированы.
Контур с отверстиями или несколько компонент этим контрактом не задаются.
Наличие замкнутого входного цикла само по себе не доказывает корректное
топологическое заполнение. Binary64-ошибка непрерывных границ не сертифицирована.

JSON: `surface_boundary_fill`, поля `boundaries` и `center`; результат —
массив всех патчей. Нельзя заменять его только первой поверхностью.

Native tests проверяют сохранение каждой внешней границы, общие спицы
и их независимую линейную параметризацию при различных весах ребра;
независимые affine-треугольники плоского пятиугольного веера; четыре
рациональные дуги круга и радиальные швы; JSON-массив всех пяти патчей;
отказы незамкнутого контура, числа границ и нечислового центра.

`cargo test --manifest-path crates/nurbs-core/Cargo.toml --features transport`
— 298 тестов и 2 doctest прошли.

TypeScript: `boundaryFillNurbsSurfaces`; Rush:
`boundary_fill(a,b,c,...,center:[...]).nurbs_patches_tessellate(segments:12)`.
Центр использует единицы длины модели. Пример: `examples/rush/boundary-fill.r`.
Набор поверхностей содержит `patches` и `faceIds`, без фиктивных метрик
восстановления mesh. Общий тесселятор принимает этот минимальный контракт
и прежний reconstruction PatchSet; faceIds сохраняются для каждого треугольника.

Графовые affine-преобразования теперь применяются ко всем поверхностям

всех пяти патчей. Метрики исходной mesh-реконструкции не копируются в
преобразованный набор: они не описывали бы его ошибку после масштабирования.

Отчёт графа теперь возвращает общие bounds набора патчей: объединение
консервативных контрольных hull всех поверхностей. Это не tight bounds
непрерывной поверхности и не сертификат ошибки вычисления. Независимый
пятиугольный веер даёт [-1,0,0]..[3,3,2]; перенос, неравномерный scale и
отражение Z дают [5,-2,-5]..[13,7,3]. Проверка охватывает крайние точки
на разных патчах. Повторный прогон тех же трёх файлов — 224 теста прошли;
проверка типов прошла.
