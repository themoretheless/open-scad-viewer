# Радиальный кулачок с законами движения

`nurbs_core::radial_cam::profile(Request,&[Motion])` строит замкнутый планарный 3D contour для translating radial knife-edge/roller follower. Request задаёт center, positive base_radius, nonnegative roller_radius, phase в градусах, positive tolerance и max_spans. Нулевой roller_radius — ножевой толкатель. Положительный roller radius вычитается по наружной нормали pitch curve. Base radius — радиус кулачка при zero lift/zero slope; phase предварительно нормируется modulo 360.

Программа содержит 1..64 Motion: end_degrees strictly increasing до 360, end_lift finite≥0. Начальная/конечная высота 0; Dwell требует неизменной высоты. Law: Dwell, Harmonic, Cycloidal, Polynomial345, Polynomial4567. Подъём/опускание задаются разностью lifts. Производные законов аналитические; zero velocity в endpoints материализована точно. Harmonic acceleration может иметь разрыв на стыке с выдержкой, поэтому полная C1/C2 регулярность roller contour не заявляется.

Для θ pitch radius r=base+roller+lift(θ), pitch P=r*e_r, speed=hypot(r,r'), outward N=(r*e_r−r'*e_theta)/speed. Contour C=P−roller*N, C'=(1−roller*κ)*P', κ=(r²+2r'²−r*r'')/speed³. Формула κ вычисляется в масштабированном виде. Pressure angle=abs(atan2(r',r)). Значение 1−roller*κ≤0 записывается как sampled_undercut. Это diagnostic sample, не непрерывная проверка undercut/global self-intersection; отсутствие флага не является разрешением изготовления.

Cubic Hermite segments адаптируются по расхождению с analytic target в трёх внутренних точках каждого leaf (.25,.5,.75). max_sampled_error — максимум по итоговым leaves, не continuous Hausdorff certificate и не rounding-inclusive bound. Report cells сохраняют исходные angle intervals в радианах; Curve domains используют ту же угловую шкалу. Угловой midpoint обязан быть представим между endpoints; иначе возвращается ParameterPrecision с полным contour. SpanBudget также сохраняет всю программу, не частичный путь. SampleEstimateReached означает только достижение критерия по пробам.

max_spans 1..4096 и не меньше числа motions. Полный контур разбивается на clamped cubic Curve chunks максимум 85 spans / 256 controls с unit weights. Boundary control points общие; последняя точка канонически равна первой. Это exact data closure, не подтверждение гладкости, отсутствия самопересечений или periodic storage. Surface/solid extrusion, machining clearances, follower dynamics и manufacturing topology отдельно. Численная непредставимость motion/offset/controls даёт typed error.

Независимые regressions: dwell circle для knife/roller, все четыре законы подъёма/опускания, заданные lift stations, roller-center distance и ортогональность pitch tangent, общий angular coverage/bit-identical closure, sampled undercut на steep harmonic lift, budget completeness, invalid programs и very short angular precision limit. Проверка 2026-10-14: все пять integration groups прошли offline/locked, no-default-features, включая ParameterPrecision case. NURBS-0091: native в описанном контракте radial cam contour constructor. Это не manufacturing/solid или непрерывная error qualification.
