# Непрерывная оценка отклонения поверхности

`nurbs_core::continuity::deviation::positional_upper(a, b)` — существующий типизированный Rust API без codec. Возвращает верхнюю границу расстояния между соответствующими точками двух валидных положительно взвешенных 3D NURBS-поверхностей с точно одинаковым активным UV-прямоугольником. Она также является верхней границей симметричного расстояния Хаусдорфа между полными образами, поскольку соответствие покрывает оба домена.

Код переводит исходные координаты в однородные интервалы с внешним округлением, согласует разбиение по объединению узлов, затем ограничивает Bernstein-коэффициенты числителя Xa*Wb-Xb*Wa и положительного знаменателя. Степени и внутренние узлы могут различаться. Точно одинаковое представление возвращает 0. Оценка учитывает округление собственной арифметики относительно переданных binary64 данных; она не включает ошибку измерения или округление предыдущего редактирования относительно неизвестной идеальной геометрии.

Это верхняя граница, а не точное максимальное отклонение, нижняя граница или оптимизация перепараметризации. Большая оценка не доказывает нарушения допуска. Разные параметрические соответствия способны дать ненулевую оценку для совпадающих образов. Trim-области и топологическое соответствие не входят в контракт.

Ошибки: разные активные UV-домены, неверные поверхности, недоказанный положительный знаменатель, арифметическое переполнение, превышение лимитов уточнения. Коэффициентная работа ограничена 2000000, сетка уточнения — 262144, внутреннее уточнение одной кривой — 8192 контролей. Ошибка возвращается вместо неквалифицированного сертификата; нет обещания успеха для любого валидного представления.

Три независимые проверки `crates/nurbs-core/tests/surface_deviation.rs` прошли без default features: рациональная панель с неединичными UV-доменами и точным смещением длины 5 в обоих порядках; узкий пик высоты 1 шириной 0.0002 с иным узловым разбиением целевой поверхности; вставка узла и повышение степени с малой границей ошибки; отказ на несовпадающих доменах и нулевых весах.
