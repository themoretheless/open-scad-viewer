# Аудит curve/surface intersection

NURBS-0164 остаётся planned: наличие `intersect_curve_surface_report` ещё не доказывает общий квалифицированный решатель пересечений.

Исправлены две ветки ложного точного overlap в плоском сокращении:

- Малый ненулевой остаток плоскости, даже меньше пространственного допуска, больше не объявляется точным совпадением. Возвращается неразрешённый интервал кривой.
- Coplanar-сегмент вне конечной UV-области поверхности больше не объявляется overlap с её бесконечной опорной плоскостью. Проверяются UV контрольных точек сегмента; отсутствие достаточного условия покрытия оставляет неразрешённый интервал.

Это исправление не является квалификацией общего overlap. `plane_of` использует округлённую нормаль и допуск для распознавания плоскости; `invert_plane_uv` предполагает аффинную плоскую параметризацию, что требует отдельной проверки для рациональных и неаффинных билинейных поверхностей. Нужны внешние границы арифметики плоского сокращения, доказанное существование/уникальность корней и корректный UV-trim всего совпадающего участка. Нельзя учитывать эту операцию как готовую до устранения оставшихся пробелов.

Три независимые регрессии `crates/nurbs-core/tests/curve_surface_overlap_regressions.rs` прошли без default features: зазор 5e-10 при нулевой плоскости; отрезок x=2..3 вне панели x=0..1; точный внутренний отрезок сохраняет прежний overlap. Дополнительно запущен существующий default-feature тест `foundation_v5_certified_curve_curve_and_curve_surface`.

## Дополнительные исправления плоского overlap

Аффинный UV-inverse теперь допускается для overlap только у одиночной равномерно взвешенной билинейной панели-параллелограмма. Рациональные и неаффинные плоские панели остаются неразрешёнными до реализации правильного inverse. Это ограничение предотвращает выдуманные UV, но не завершает общий решатель.

Пространственная оболочка overlap строится по положительно взвешенной контрольной оболочке всей исходной кривой. Она консервативна и включает весь участок, тогда как прежняя оболочка вокруг первого конца не покрывала участок. Средний UV-sample теперь вычисляется по фактической точке кривой в среднем параметре, а не по среднему UV концов; последнее неверно для рациональной или нелинейной параметризации.

В файле регрессий теперь шесть тестов: добавлены рациональная и трапециевидная панели, покрытие обоих концов пространственной оболочкой и независимая рациональная формула средней точки (0.625,0.575). Полная квалификация NURBS-0164 по-прежнему не доказана: требуется внешняя арифметика плоского сокращения и корректный trim-путь совпадающего участка, включая случаи вне аффинного представления.

## Отдельные точки в плоском сокращении

Предположение аффинного UV теперь проверяется не только для overlap, но и для отдельных точек. Рациональные и неаффинные панели не получают ошибочные UV; пересечение бесконечной опорной плоскости вне активного UV-прямоугольника не объявляется точкой конечной поверхности. Эти участки сохраняются как неразрешённые, поскольку само округлённое candidate UV не доказывает отсутствие действительного корня.

Проверка левого конца теперь использует абсолютный остаток плоскости, как и проверка правого конца. Отрицательный большой остаток больше не удовлетворяет условию лишь из-за знака. Плоские кандидаты больше не увеличивают `krawczyk_isolated`: этот путь не выполняет Krawczyk-доказательство. Отсутствие неразрешённых участков в старом отчёте само по себе по-прежнему не квалифицирует общий решатель.

Добавлены две регрессии: вертикальный отрезок при x=2 вне единичной панели и пересечение рациональной панели, которое ранее получало аффинные UV. Восемь интеграционных проверок прошли; существующий default-feature smoke test запускается дополнительно. NURBS-0164 остаётся planned до доказательств корней и корректного общего UV-inverse.

## Доказанность отчёта и завершение поиска

Нативный `CurveSurfaceIntersection` теперь содержит `certified`. Текущий legacy-решатель не имеет непрерывного доказательства всего отчёта с внешней арифметикой и возвращает false. Геометрические кандидаты сохраняются для дальнейшей обработки; они не превращаются в доказанные корни только из-за малого остатка.

В host JSON `coverage.searchComplete` отражает прежнее условие отсутствия неразрешённых областей. `coverage.complete` требует также certified, поэтому для этого legacy-пути остаётся false. `coverage.certified` доступен отдельно, а `rounding` теперь `uncertified-binary64`: прежняя метка внешнего округления была неверна для плоского сокращения. Это намеренное уточнение контракта; потребители, требующие доказанного полного пересечения, должны отказаться от такого отчёта, а потребители приближённых кандидатов могут использовать searchComplete без вывода о доказанности.

Регрессия проверяет, что проходящий через панель отрезок даёт кандидата и законченный поиск, но не сертификат и не прирост Krawczyk-isolated. Отдельный codec-тест проверяет все четыре поля сериализованного отчёта. NURBS-0164 остаётся planned.
