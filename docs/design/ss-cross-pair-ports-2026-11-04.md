# Exact triple-surface vertex ports

`bind_original_ss_third_port` binds a sealed real original-equation triple-surface witness to an explicitly ordered pair of its three surfaces. The target must carry an original deflated graph with uniform fiber uniqueness. Exact rational Cox-frame transfer verifies every target UV coordinate against the finite span and graph domain. The projected free-coordinate enclosure remains attached to the witness and original algebraic clock; it is never converted into a sampled endpoint definition.

The global point owner remains literal across AB, AC, BC and reversed surface roles. Replay checks both graph authorities and the original triple witness. Rebinding permits a query-policy clone of that same selector, and refuses silently replacing its clock owner. Nonzero seam phases are not admitted by this API.

Cross-pair endpoint binding is not a common-face winding proof. Existing winding, path parity and local joint admission explicitly refuse this new port kind until common-face UV transport is implemented. Existing edge enclosure and BRep pcurves use the target graph, while the shared vertex retains its original global selector.
