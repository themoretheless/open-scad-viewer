# Непрерывное отклонение кривых

`nurbs_core::curve_deviation::inspect(a, b, accuracy, max_cells)` — типизированный Rust API без codec. Возвращает нижнюю и верхнюю границы супремума расстояния между соответствующими точками валидных положительно взвешенных 2D/3D кривых одинаковой размерности и с точно одинаковыми активными параметрическими интервалами.

Исходная сетка строится по объединению внутренних узлов. Интервальный de Boor с внешним округлением ограничивает оба исходных рациональных образа каждого интервала. Расстояние между оболочками даёт верхнюю границу максимального отклонения; интервальные точечные кандидаты дают нижнюю. Алгоритм подразделяет участок с наибольшей верхней границей и сохраняет покрытие остальных. Различные степени, веса и узловые разбиения допускаются. Точно одинаковое валидное непрерывное представление имеет границы [0,0].

`accuracy` ограничивает ширину интервала максимального отклонения, а не допустимое изменение геометрии. Для проверки пользовательского допуска D достаточно upper<=D; lower>D доказывает превышение, остальные случаи не разрешены. Верхняя граница также ограничивает симметричное расстояние Хаусдорфа образов, однако нижняя относится только к данному параметрическому соответствию и не ограничивает Хаусдорф снизу. Нет поиска оптимальной перепараметризации.

Неконечная или неположительная accuracy, бюджет вне 1..100000, несовпадающие домены/размерности, неверные кривые и полностью повторённые внутренние узлы отклоняются. Последнее — консервативное требование непрерывного базиса. Бюджет считает исходные и все созданные интервалы. Если исходная сетка не помещается, ошибка; при исчерпании бюджета или представимых промежуточных параметров сохраняются границы и явная причина остановки. Арифметическое переполнение возвращает ошибку. Выбор максимального участка линейный, лимит интервалов не является гарантией времени.

Учёт округления относится к арифметике проверки относительно переданных binary64 данных. Он не включает ошибку измерений или предшествующее округление неизвестной идеальной геометрии. Периодические кривые рассматриваются на одном активном периоде; изменение фазы без согласования параметров может дать большую оценку для одинаковых образов.

Тесты `crates/nurbs-core/tests/curve_deviation.rs`: независимое рациональное смещение длины 3 на неединичном домене, требующее подразделения; узкий пик высоты 1 между обычными точками выборки; вставка узла и повышение степени; точное совпадение; бюджетная остановка и исходная сетка сверх бюджета; несовпадающие домены/размерности, неверные допуски/лимиты и отказ для разрыва.
