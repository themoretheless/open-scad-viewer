# Target-axis SS clocks generated from original equations

`OriginalSsRootPoint::reparameterize_to` derives a clock on a target original SS
graph. Native membership first encloses the whole original source point in the
target's unique graph and supplies a conservative target-clock interval. The
source graph's ORIGINAL rational span equations are augmented with the owned
source-clock polynomial. Exact bounded Groebner elimination puts the requested
target coordinate last and extracts a univariate consequence. Exact coefficient
composition then expresses it in the target graph's native knot-span frame.

The resulting polynomial and entire native target-clock enclosure must qualify
as exactly one selected real root using the existing rational Sturm machinery.
The returned common point owns that polynomial, selector and original target
graph; no midpoint becomes its definition. Its standard point/port/BRep replay
uses the original target geometry and exact clock. The source derivation does
not yet supply persistent construction history or topology lineage.

The current source carrier is an original deflated span graph. Source algebra
uses `OriginalSsCurveLimits.projection` with fixed 4096 pair / 128 basis bounds;
the clock has its separate explicit degree/operation/coefficient policy. No
univariate elimination consequence, degree above policy, ambiguous roots,
unsupported endpoint isolators, original membership failure or exhausted work
returns a point. Original cleared-equation components outside the real span may
prevent this sufficient elimination proof; no localized completeness is claimed.

an actual original SS circle, compares it with an independently authored exact
polynomial, and derives an equivalent x clock on return. The paired BRep test
now generates its y clock through this API, reconciles the independent cross-axis
