# Непрерывная проверка G1 между поверхностями

`nurbs_core::surface_g1::inspect(a, edge_a, b, edge_b, reverse, position_tolerance, normal_chord_tolerance, max_cells)` проверяет позиционное совпадение и регулярные касательные плоскости по всей паре выбранных границ. Соответствие параметров — нормализованное аффинное, с возможным разворотом второй границы.

Позиционные интервалы получаются из исходных рациональных поверхностей. Для нормалей используется внутренний `surface_measure::jets::calculate_partial_stable`: производные однородных коэффициентов строятся на исходном узловом пролёте, затем интервально оцениваются на нужном диапазоне. Одна координата фиксируется на нужном конце исходного узлового прямоугольника, другая ограничивается интервально. Это избегает потери точности при вычитании почти одинаковых коэффициентов слишком узкой ограниченной ячейки. Положительность знаменателя и convex-hull границы производных Bernstein-полиномов учитываются при пересечении оценок. Прежние calculate/calculate_partial сохраняют локальный масштаб параметров; stable возвращает производные в координатах исходного пролёта. Эти положительные масштабы сокращаются при нормализации нормали. Это производные на реальной границе, а не производные крайнего ряда контролов и не оценки по тонкой полосе около неё. Все пересечённые свободные узловые интервалы включаются.

Положительная нижняя граница нормы S_u×S_v подтверждает регулярность. После интервальной нормализации измеряется неориентированная chord-метрика касательных плоскостей: min(|n_a−n_b|,|n_a+n_b|). Противоположные нормали допустимы; равенство скоростей параметризации не требуется. Для острого угла θ между плоскостями эта метрика равна 2·sin(θ/2). API принимает допуск в chord-метрике; преобразование заданного углового допуска отдельно не сертифицируется.

WithinTolerance требует непрерывных верхних границ позиции и normal chord ниже обоих допусков и подтверждённой регулярности вдоль всей границы. Доказанный нижний предел в свидетельской точке может дать CorrespondenceExceedsTolerance для выбранного соответствия. Во всех иных случаях, включая лимит работы/представимой точности, возвращается Unresolved. Если регулярность не подтверждена, normal_chord_upper отсутствует; отсутствующая оценка не заменяется нулём. Нижние свидетельские границы и позиционные границы сохраняются. Неподтверждённая регулярность не является доказанной сингулярностью.

Поверхности должны быть валидными; свободный внутренний базис обеих границ должен быть C1. Дополнительная гладкость при C0-базисе автоматически не предполагается. Производные фиксированной координаты берутся с естественной внутренней стороны. Позиционный допуск конечный неотрицательный, normal chord конечный в [0,2], max_cells=1..100000. Бюджет считает все обработанные ячейки, включая заменённые родители. Неверные входы, C0 свободный базис и численное переполнение возвращают ошибку. При строгом нулевом допуске операция может остаться Unresolved из-за интервального округления. Исходники не меняются.

Это проверка G0 и касательных плоскостей с допусками. Она не подтверждает manifold-соседство, ориентацию оболочки, G2, общую топологию, одинаковые параметрические производные или C1 через периодический storage seam. Периодическая граница проверяется в естественном домене, без отдельного сертификата склейки концов свободной оси.

Шесть интеграционных тестов независимо проверяют плоские патчи с разными поперечными рациональными скоростями, противоположные нормали и reverse, транспонированные границы, аналитический normal-chord зазор при z=0.25x, полный криволинейный шов z=x²+y², сингулярную границу и скрытую сингулярность между начальными свидетельскими точками при y=(v−0.37)², скрытый normal-chord дефект для z=u·8v(v−1/2)(v−1) при совпадении нормалей в v=0,1/2,1, лимит работы, неверные допуски/бюджет/C0-базис и неизменность источника. Прошли также 4 теста surface_differential, 4 surface_regularity и 3 jets-теста, включая независимые рациональные производные до третьего порядка на интервалах шириной в несколько ulp.

```sh
cargo test --manifest-path crates/Cargo.toml -p nurbs-core --no-default-features --test surface_g1 --test surface_differential --test surface_regularity --quiet
cargo test --manifest-path crates/Cargo.toml -p nurbs-core --no-default-features --lib surface_measure::jets::tests --quiet
```

WASM, редактор и STEP для нового API отдельно не квалифицированы.

Полный нативный набор `cargo test --manifest-path crates/Cargo.toml -p nurbs-core --no-default-features --quiet` повторно прошёл после устойчивой оценки производных и новых регрессий: 578 тестов, 0 ошибок.

Контрпример с внутренним normal-chord дефектом первоначально оставался Unresolved: слишком узкая ограниченная ячейка теряла разрешающую способность производных. После перехода к differentiate-before-restrict он возвращает доказанный CorrespondenceExceedsTolerance. Искусственное ослабление допуска или расширение query-интервала не используется.
