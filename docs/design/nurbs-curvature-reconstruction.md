# Native planar reconstruction from sampled curvature

`nurbs_core::curve_reconstruction::reconstruct_from_curvature` defines signed curvature by linear interpolation between strictly increasing arc-length stations. It integrates the resulting quadratic tangent-angle polynomial on each source interval, then integrates position using two-half-panel Simpson quadrature. This fixes the old use of a linearly interpolated angle midpoint, which was incorrect for changing curvature.

The report separates reconstructed `sites` and `tangent_angles` from the NURBS fit. `fitted_site_max_deviation` and `fit_converged` describe the requested **data-site** fitting tolerance. They do not bound integration error or continuous error between sites. Three sites use a quadratic fit; larger sets use the existing cubic adaptive fitter and bounded fallback. An unconverged result is compared against the existing global 8/13/19/26-control candidates: only a smaller reported data-site deviation can replace it, and the original requested tolerance remains unchanged. A returned fit can be nonconverged and remains explicitly marked as such.

`quadrature_error_estimate` sums local fine/coarse Simpson differences divided by 15. Both resolutions cover exactly the same intervals, including an unpaired final source interval and unequal source spacing. It is a numerical estimate, not a guaranteed error bound. There is no unknown-source-curvature certificate: the supplied samples define the piecewise-linear curvature model.

Each numerical integration panel has at most 0.5 rad of estimated angular travel, using the maximum absolute endpoint curvature. All intervals share `MAX_INTEGRATION_PANELS = 4096`; exhaustion is an explicit resource refusal. The actual count is returned as `integration_panels`. Rotation that cannot be represented relative to the supplied tangent angle is refused. Input limits remain 3..4096 finite stations, |curvature| <= 1e12, increasing finite total length, finite start/angle and positive finite fitting tolerance. Reconstructed positions must respect the existing 1e9 coordinate limit. The input z coordinate is validated but the result is planar z=0.

`max_residual_curvature` is a diagnostic evaluated at parameters linearly mapped from source stations to the fitted curve domain. This mapping is not true arc-length inversion. `undefined_curvature_sites` counts unavailable, zero-speed or nonfinite curvature evaluations; a partial residual must not be interpreted as a global match. No G2, regularity, topology or B-rep authority is returned.

Tests use independent dense Fresnel quadrature, analytic signed circles and lines, nonuniform shifted stations, the three-station path, bounded phase refinement, invalid requests and explicit resource/precision refusals. JSON/WASM/Rush/editor/STEP qualification is not implied.
