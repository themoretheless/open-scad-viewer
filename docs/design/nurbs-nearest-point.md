# Ближайшая точка на NURBS-кривой

`nurbs_core::curve_distance::nearest_point(curve, point, tolerance, max_cells)` — типизированный Rust API без codec или адаптеров редактора. Ищет глобальный минимум расстояния до полного активного образа кривой, включая концы. Поддерживает валидные положительно взвешенные 2D/3D кривые, включая стационарные и периодические.

Запрос представлен постоянной кривой; общий алгоритм расстояния использует интервальный de Boor с внешним округлением и подразделение пар параметрических ячеек. `distance_interval` ограничивает глобальный минимум. `parameter`, `point` и `point_enclosure` описывают найденного кандидата. Это не доказательство единственности минимума и не граница ошибки параметра. При нескольких минимумах может быть возвращён любой кандидат.

`converged` означает достижение допуска по расстоянию. При остановке по бюджету или точности границы остаются действительными, но кандидат не объявляется окончательным. Начальная сетка, превышающая бюджет, возвращает ошибку. Допуск положительный конечный, бюджет 1..100000; координаты и размерность проходят обычную валидацию Curve. Единицы совпадают с координатами входа.

Независимые проверки в `crates/nurbs-core/tests/nearest_point.rs`: рациональная прямая на неединичном параметрическом интервале, аналитические внутренний и два концевых минимума, стационарная кривая с расстоянием по треугольнику 3-4-5, незавершённый поиск и некорректные параметры. Три теста прошли без default features.
