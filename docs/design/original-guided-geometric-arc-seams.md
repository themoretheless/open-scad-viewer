# Original guided geometric arc seams

This Rust extension concerns the ideal guided orthonormal frame before any
section approximation, rounding, sewing or STEP interchange. It extends the
existing closed-frame owner; public certificate scope does not change.

For each original regular curve X, the native arc map is the inverse of its
own exact normalized length integral. If s is normalized arc station and L is
total original length, X_s=L*T and X_ss=L²*dT/dlength. Thus periodic Ck of the
path unit tangent, periodic C(k-1) of the guide unit tangent, and exact C0
positions establish the required path tangent and guide position jets for a
closed Ck guided frame. Raw source speeds may differ at knots or the seam.
Path and guide may have different original parameter ranges and independent
arc clocks. Matching endpoint directions alone never establishes higher jets.

The owner freshly checks exact original position and direction identities at
all knots and both seam sides. Direction jets use physical arc length; each
curve's one global L converts them to its normalized station. Twist remains a
station law with its own exact Cartesian Ck identities. A complete original
positive-speed cover and a complete joint station cover then prove
T cross (G-P) is nonzero. Normalization and cross products are smooth on these
proved nonzero sets, so the untwisted frame and its station twist are Ck.

The previous sufficient Cartesian-jet route remains. Its stronger independent
Cartesian-product cover is a bounded proposal (4096 cells), not an admission
tolerance. If unrelated path/guide parameters prevent that proof, the owner
tries the actual joint arc correspondence with the remaining allowance.
Failed proposals, exact queries, map construction and every cover visit are
charged to the same caller ledger. Exhaustion and incomplete covers return
false without partial closure credit.

The joint owner reuses original ArcMap and frame phase jets. A literal exact
positive source homothety may prove a common normalized arc phase. An exact
coefficient difference may preserve the relative guide vector; failure falls
back to independent original jets/maps. No sampled inverse, fitted curve,
rounded guide subtraction or caller-supplied success flag supplies proof.

Native examples include an exact rational Mobius clock with a fourfold raw
speed seam, independent guide domains, one-ULP damaged second jets, geometric
tangent mismatch, zero/one-short budgets, and a case where the independent
Cartesian product is unresolved while the actual station cover succeeds.
The ideal-volume test separately proves a complete original moving-section
atlas and G2 differential compatibility for all four original profile joins.
That carrier is a reference filled section of a closed tube: it is not a
physical end cap. Material validity/binding, retained BRep regularity and
embedding, actual G2, boundary error, STEP and WASM remain separate gates.

Arbitrary physical end-cap joins, general affine/projective frame invariance,
pole fans and all general frame/cap source combinations are not completed by
this theorem. Sharp joins remain explicit C0. fullGoalComplete stays false.

The wall-error owner also uses fresh positive-homothety phase identity for
ordinary guidance, retaining the constructor's declared arc tolerance. Contact
fitting keeps its separate scale-sensitive clock policy. Complete original
arc-chord bounds cover translation, and exact orthonormality bounds the norm
of the local affine/scale/center/fit vector before adding world translation.
The norm ball intersects the existing directional interval enclosure; it does
not replace the frame nondegeneracy proof or accept rounded orthogonality.
Original shared length evidence now includes closed guide fields, while every
profile still charges its own actual/source displacement and decomposition.
