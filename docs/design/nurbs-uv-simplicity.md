# Достаточное доказательство простоты UV-контура

`trim_simplicity::inspect(curves, tolerance_uv, max_pairs, max_cells)`
принимает 2..256 рациональных 2D-кривых, положительный конечный
UV tolerance, бюджеты пар/cells в 1..100000. Report хранит точные joins,
признаки injective для сегментов, доказательства каждой пары и cells.
`Report::outcome()` раскрывает ProvenSimple, ClosureMismatch,
ClosureUnproven, InjectivityUnproven, PairBudgetExhausted,
SeparationUnproven. Это причины достаточной проверки, без утверждения
самопересечения при неудаче доказательства.

Текущая инъективность доказывается для clamped непериодических
Bezier-сегментов через строгую монотонность рациональной проекции.
Смежные сегменты проверяются достаточным разделением half-plane
у общего точного стыка; несмежные — положительной нижней границей
расстояния. Для True требуются точное замыкание, инъективность всех
сегментов и доказательства всех пар. Двухсегментные контуры требуют
более сильного доказательства, чем текущая single-join проверка.

BSpline с внутренним узлом, periodic/unclamped сегмент или неудачная
проекция дают unproven, а не ложное «контур пересекается».
Тесселяция и выборки не используются для объявления простоты.
Отчёт не возвращает точку пересечения, не выполняет ремонт/Boolean,
не гарантирует ориентацию или роли отверстий. Глобальная обработка
общих NURBS-сегментов и отдельный свидетель пересечения остаются задачами.

Три интеграционных теста проверяют положительно-взвешенный квадрат,
полный набор шести пар, маленький бюджет, независимо заданный bow-tie,
незамкнутый стык, unsupported BSpline и неверные параметры.
Все прошли с no-default-features. Native API без адаптеров.
