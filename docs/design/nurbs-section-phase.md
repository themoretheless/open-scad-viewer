# Согласование фаз замкнутых сечений по опорным точкам

`nurbs_core::section_phase::align(curves, anchors, search_tolerance, shape_tolerance, max_cells)` согласует начало каждого сечения с ближайшим к его заданной опорной точке участком. Требует 2..32 сечения и столько же опорных точек одинаковой размерности. Все входы должны быть валидными, с периодическим хранением либо точно совпадающими endpoints clamped-кривой. Окружности, замкнутые полилинии и clamped замкнутые сплайны поддерживаются наряду с периодическими кривыми.

Каждый поиск покрывает полный домен исходной рациональной кривой. Его distance_interval ограничивает глобальный минимум; converged подтверждает, что расстояние выбранного witness отличается от минимума не больше search_tolerance. Это допуск расстояния до опорной точки, а не угловая или параметрическая погрешность фазы. Равноценные минимумы допускаются: выбирается один свидетель без утверждения о его уникальности. Опорные точки задают соответствующие места сечений; автоматическое распознавание деталей, оптимизация скручивания loft и выбор ориентации не выполняются.

Перенос периодического шва использует periodic_seam. Замкнутая clamped-кривая разбивается на два рациональных фрагмента, которые соединяются в обратном порядке с сохранением степени. Веса одного фрагмента масштабируются целиком для совместимости общей однородной вершины; stored endpoint closure восстанавливается явно. Округление этих операций не считается нулевой ошибкой: каждый результат проверяется `periodic_seam::verify_curve` по непрерывному нормализованному фазовому соответствию и принимается только при error_upper<=shape_tolerance. Проверяющий API теперь принимает и точно закрытые clamped-кривые. Базис и флаг периодичности сохраняют свой тип; совместимость степеней/узлов для loft остаётся `sections::compatible`.

Для witness на последнем параметре домена первая фаза проверяется отдельно перед канонизацией: допущенная валидатором малая невязка периодического хранения не переносит расстояние последней точки на первую без проверки. Неподтверждённый поиск или форма дают SearchUnresolved/ShapeUnresolved. Только если все стадии всех сечений подтверждены, `curves` содержит новый набор. Иначе он отсутствует целиком; исходники не меняются. Отчёт сохраняет witness, параметр, дистанционные границы и сертификат формы каждого сечения.

`final_distance_interval` отдельно ограничивает расстояние от опорной точки до фактического начала принятого кандидата. Оно вычисляется непосредственно по интервальному образу новой кривой, а не копируется из результата поиска на исходнике. `final_minimum_gap_upper` ограничивает превышение этого расстояния над глобальным минимумом уже новой кривой: final_distance_upper − original_min_lower + shape_error_upper, с внешним округлением и нижним ограничением нулём. Полная Hausdorff-граница формы обосновывает перенос нижней границы минимума. Эти поля отсутствуют для неподтверждённого сечения. Search_tolerance сам по себе не гарантирует такой же близости возвращённой формы: ошибка редактирования учитывается отдельно.

Оба допуска положительные конечные. max_cells=1..100000 задаёт отдельный бюджет каждого поиска и каждой проверки формы, а не общий бюджет всех сечений. Опорные точки конечные и ограничены 1e9. Результат кривой должен помещаться в 256 контролов. Начальный бюджет, неверные данные, незамкнутый профиль, несовпадение размерности, превышение ограничений и недопустимая арифметика возвращают ошибку. Refine-limit после начального покрытия даёт явный unresolved. Сертификат позиционный: регулярность, G1/G2 через шов, отсутствие самопересечений и глобально минимальное скручивание не заявлены.

Четыре интеграционных теста проверяют аналитические ближайшие точки внутреннего ребра квадрата, сечения на разных высотах, рациональную окружность и непрерывную границу переноса, смешанные periodic/clamped-профили, равнозначные фазы постоянной кривой, атомарность неподтверждённого результата, неверные входы и неизменность источников. Все 12 целевых и существующих seam-проверок прошли.

Дополнительные утверждения проверяют финальную дистанцию 1 до аналитического ребра квадрата, границу превышения над минимумом нового профиля и отсутствие финальных сертификатов при неподтверждённой форме. После изменения отчёта все те же 12 проверок повторно прошли; полный нативный набор в этой правке повторно не запускался.

```sh
cargo test --manifest-path crates/Cargo.toml -p nurbs-core --no-default-features --test section_phase --test periodic_seam_candidates --test periodic_seam --quiet
```

WASM, редактор и STEP для нового API отдельно не квалифицированы.
