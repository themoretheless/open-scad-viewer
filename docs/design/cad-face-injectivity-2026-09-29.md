# Отсутствие самопересечения внутри одной грани

## Область результата

Добавлен нативный достаточный критерий `nurbs_core::surface_injectivity::certify`. Положительный результат доказывает однозначность параметризации всей естественной области поверхности, следовательно и любого её обрезанного подмножества. Критерий не сравнивает разные грани и не подтверждает корректность объёма.

Отрицательное заключение не выдаётся: если условие не выполнено, возвращается `proven=false`, то есть доказательства нет. Периодическая область возвращает `periodic-domain`; исчерпание бюджета — `work-limit`. Ни одно из этих состояний не означает обнаруженное пересечение.

## Основание доказательства

Берётся проекция F поверхности на одну из трёх координатных плоскостей. Для всех её узловых участков вычисляется единое интервальное ограждение матрицы производных J. Однородные коэффициенты извлекаются из исходных NURBS интервальным blossom; рациональная производная вычисляется как `(N' W − N W') / W²`. Положительные веса сохраняют отделённость знаменателя от нуля.

Из середины матрицы выбирается постоянная численная матрица Y. Её выбор сам по себе ничего не доказывает. Все произведения для остатка `I − YJ` затем вычисляются с наружным округлением. Если верхняя оценка его строковой нормы q строго меньше 1 на всей области, проекция инъективна.

Причина: вдоль отрезка между двумя параметрами x и y интеграл производной даёт `Y(F(x)−F(y)) = (I−E)(x−y)`, где норма E не превышает q. При `F(x)=F(y)` следует `||x−y|| ≤ q ||x−y||`, поэтому x=y. Естественная область — выпуклый прямоугольник; валидатор запрещает внутренние разрывы степени p+1. На внутренних узлах достаточно непрерывной, кусочно гладкой параметризации.

Важно использовать одну матрицу Y и общий диапазон J для всех узловых участков. Успешные локальные проверки разных участков не доказывают отсутствие пересечения между ними.

## Интеграция B-rep

`brep_core::face_injectivity::inspect` проверяет структурные предпосылки диагностическим валидатором и обходит все грани с общим бюджетом. Для каждой грани возвращается её индекс и результат; не посещённые грани получают `None`. `all_faces_injective` относится только к внутренней однозначности каждой грани. Счётчик проверенных попарных пересечений в `solid_audit` не менялся, и общий аудит самопересечений остаётся неполным.

## Проверки

- Нелинейная графовая поверхность и её поворот проходят глобальный критерий.
- Складка и вырожденная поверхность не получают доказательства.
- Два регулярных участка, складывающихся при объединении, не принимаются по отдельным локальным результатам.
- Бюджет не скрывает непосещённые участки/грани.
- Шесть граней куба проходят; при схлопывании одной грани она остаётся недоказанной, остальные пять подтверждены.
- Независимый Python/Fraction oracle проверил 72/72 рациональных графовых поверхности. Положительные разделимые веса дают строго монотонные взвешенные Bernstein-координаты; невырожденное аффинное преобразование сохраняет однозначность. Третья координата имеет произвольную кривизну. Проверка коэффициентов выполнена точно, без конечного набора геометрических проб.

Максимальная полученная верхняя оценка q в этом корпусе — 0,8486349519486938. Она не является универсальной границей для других моделей.

## Следующие зависимости

Критерий достаточный, поэтому часть корректных граней останется недоказанной. Нужны общая обработка таких граней, подтверждённые свидетельства пересечений и полный обход пар разных граней с UV-контуром, допустимыми общими рёбрами, касаниями и совпадениями. Численные ветви существующего surface/surface поиска не используются новым критерием как доказательство полноты. WASM/UI этого нового результата ещё не подключены. До этих этапов самопересечения исходного B-rep и пригодность заполненного объёма остаются открытыми.
