# Скругления между NURBS-поверхностями

`nurbs_core::offset::fillet_surfaces::rolling_ball_fillet(A,B,r,options)` и `variable_radius_fillet(A,B,law,options)` возвращают FilletReport. Поддержки — валидные NURBS Surfaces; знаки side_a/side_b выбирают стороны исходных oriented normals. По sampled offset seed и predictor/corrector tracing строится reference spine, затем размещаются rational circular sections, касательные к support normals в station contacts, и homogeneous natural loft skin. Обе операции — конструкторы приближённой поверхности сопряжения, не B-rep edge fillet.

Законы радиуса: Constant, Linear и natural-cubic Spline с 2..64 конечными `(t,r)` узлами, strictly increasing t и positive authored r. Queries splines clamped к authored range; Linear к [0,1]. `evaluate_checked(t)` возвращает typed error для неправильного закона, неконечного query или nonpositive/nonfinite результата. Совместимый `evaluate(t)` возвращает NaN для invalid authored data/query вместо panic. Положительные значения в узлах не гарантируют positivity natural cubic между узлами: checked query проверяет данную точку, не весь интервал. Builder оценивает range на 65 samples и отказывает при обнаруженном слишком малом/отрицательном радиусе; непрерывная positivity certificate не предоставляется.

`t` — normalized reference-spine arc parameter. Variable-law polishing перемещает centers, поэтому t не обязательно равно нормированной длине окончательной center curve. Report.spine содержит явные t, radius, contact/center и исходные UV. radius_range берётся по stations; skin_deviation_estimate — sampled оценка между circular sections, не continuous tolerance или G1/G2 proof. При general curved supports контакт skin с исходными supports между stations не сертифицирован; отдельный [surface_blend](nurbs-surface-blend.md) строит homogeneous jet bridges; он не сертифицирует данный fillet skin.

Параметры ресурсов: max_march_steps 1..4096, max_sections clamped к 2..11, Newton iterations ограничены 32, seed grids 9×9, радиусный range sampled в 65 точках. tolerance — положительный конечный пространственный Newton/section threshold, не итоговый Hausdorff certificate. Минимальный численный радиус зависит от support scale и tolerance. Неудачное seed/tracing/section/skinning отражается failure + surface=None; warnings сообщают sampled reachability и fallback. Некоторые ошибки численной представимости могут возвращаться как typed Result error. Reachability использует sampled curvature warning из surface_offset, а не глобальный fold-free certificate.

Операции не trim-ят исходные поддержки, не задают edge ownership/orientation и не создают manifold solid. Для closed spine возможен cut at seed с явным closed_spine flag; closing topology не подтверждается. Полное binary64 rounding, global self-intersection и непрерывное соблюдение заданного радиуса/касания между stations не квалифицированы.

Новые independent regressions используют translated perpendicular planes с authored UV=[2,7]×[-3,1]: constant radius checked against analytic cylinder, linear/spline radii checked at all reported stations, boundary contact positions и surface normals checked independently between stations. Invalid public spline data больше не panic; positive-node natural cubic с отрицательным overshoot получает checked query error и builder failure. Parallel separated supports дают явный failure. Существующие 11 unit tests также покрывают plane/cylinder analytic spine, chordal, G2, hold-line и failures. Проверка 2026-10-14: три integration regression groups и все 11 существующих unit tests прошли offline/locked, no-default-features; 1268 прочих unit tests не запускались. Итого 14 fillet tests. Source/test SHA-256 не изменились во время окончательного прогона. NURBS-0075/0076: native в описанном контракте приближённых конструкторов поверхностей; отдельные continuous G1/G2 qualification пункты не повышены.
