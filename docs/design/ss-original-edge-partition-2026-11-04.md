# Original SS edge partitions from exact face events

`QualifiedOriginalSsEdgePartition` splits an original root-valued edge at
ordered qualified ports on its LITERAL owned graph. Every child is a restriction
of that same original SS world curve and its two original UV projections.
Source start/end ports are preserved; adjacent child edges share the same exact
cut selector. Neither a fitted curve nor a midpoint vertex is introduced.

Cuts follow source traversal, including reversed edges. Exact existing endpoint
aliases and adjacent duplicate cuts map to existing vertex positions rather than
creating zero-length pieces. A singleton target-clock equality is exact position
authority on the same target graph; other overlapping aliases require native
original-point identity. Strict rational parameter bounds prove every interior
cut is ordered and inside the source endpoints. Unresolved overlap, out-of-order
cuts, foreign graph owners, inferred phases and exhausted policies are refused.
`cut_vertices` retains a local vertex mapping for EVERY input cut, including
aliases; these indices are not persistent global topology IDs.

`QualifiedSsEventEdgePartition` connects ordered face events to an actual source
edge. It handles source traversal and can select retained face events or all
candidates. Every event receives an explicit excluded-face, outside-edge or
partition-vertex decision. Only proved parameter separation can skip a cut as
outside. A cut overlapping an endpoint must acquire exact alias/interior authority.
Point-query reservations and cut/identity-query caps are explicit; failure never
returns a partial partition. Source graph, events, ports, choices and mappings
are retained and replayed.

Qualification uses two irrational cuts on an original circular SS arc, producing
three exact restrictions. Replacing that arc in its existing closed wire gives
a replayed paired BRep with ten edges/vertices, Euler characteristic two and no
boundary edges. This is geometric/incidence preservation, not a new solid-volume
or Boolean material proof. Reversed and restricted source edges, exact endpoint
aliases, hole exclusions, duplicate-cut mappings and deficient policies are
exercised.

Remaining work includes stronger symbolic ordering of projected endpoints,
periodic/lifted restrictions, cross-source physical junctions and mixed-pair
face arrangements, actual SURFACE/FACE region splitting and material selection.
Full intersecting Boolean/healing, persistent split/merge lineage/history,
bridge/WASM execution and the wider quad/offset/fillet/G2 scope remain open.
