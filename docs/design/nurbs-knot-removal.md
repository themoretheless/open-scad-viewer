# Удаление узла кривой с допуском

`nurbs_core::foundation::approximate_edits::remove_curve_knot_report(source, knot, max_error, tolerance)` — типизированный Rust API без codec. Строит кандидат с одним удалённым существующим внутренним узлом и той же степенью. Поддерживается непериодическое валидное положительно взвешенное 2D/3D представление, для которого refit и непрерывная проверка имеют допустимые данные и ресурсы.

Кандидат получается рациональной аппроксимацией; успешное построение не означает принятие. Непрерывная верхняя граница `curve_deviation::inspect` проверяет непосредственно возвращаемый кандидат относительно исходной кривой на общем активном параметрическом интервале. Проверка использует внешние интервалы исходных рациональных данных. Ранее сравнение с повторно вставленным узлом не учитывало отличие возвращаемого кандидата от округлённого результата вставки; этот путь заменён.

`accepted` выставляется только если верхняя граница не превышает конечный неотрицательный max_error. Иначе `curve` содержит исходную кривую без изменений. Удаление с нулевым допуском может быть отклонено даже при математически точном преобразовании, если точное равенство не доказано. `exact_zero_recognized` относится только к действительно нулевым границам, а не совпадению после округлённой вставки.

Проверка ограничена 4096 созданными интервалами с целевой шириной max(max_error*0.01,1e-12). Нехватка бюджета не разрешает принятие по выборочным точкам: используется сохранённая верхняя граница. При невозможности построить или проверить кандидат, неверных параметрах, несовместимой непрерывности или числовых ограничениях возвращается ошибка. Операция не гарантирует удаление любого узла и не поддерживает периодическое хранилище. Контекст допуска сохраняется в сертификате; решение определяется max_error в единицах входных координат.

Три независимых теста `crates/nurbs-core/tests/knot_removal.rs` прошли без default features: удаление вставленного узла рациональной прямой на неединичном домене с проверкой по аналитической формуле; неизменность источника и откат при нулевом допуске без доказанного равенства; неверные внутренние узлы и некорректные бюджеты ошибки.
