# Обрезка открытой NURBS-кривой по точке

## Контракт ядра

`curve_trim_point` принимает кривую, точку той же размерности, `keep: start | end` и положительное `maxDistance` в мм. Ядро ищет глобальную проекцию существующим методом изоляции стационарных кандидатов. Изменение разрешено только при `unique`, верхней границе расстояния не больше maxDistance и интервале параметра строго внутри исходного диапазона. Периодические и замкнутые по концам кривые не подходят этой команде.

Сохраняемая часть строится штатной NURBS trim через вставку узлов. Возвращаются кривая, параметр и его интервал, точка разреза, верхняя граница расстояния, оставленный диапазон и сертификат проекции. При неопределённой проекции геометрия не меняется. Параметр выбирается в середине изолированного интервала; это численное приближение внутри сообщённого интервала, а не обещание символьного решения.

## Выбор в проекции

`curve_trim_screen_point` получает CSS-координаты клика, две строки аффинной матрицы world → CSS, радиус захвата в пикселях и сохраняемый конец. Матрица включает текущий ортографический вид и SVG screen CTM. Rust преобразует контрольные точки в экранную плоскость, сохраняя узлы и веса; параметр единственной проекции затем обрезает исходную пространственную кривую. Глубина не берётся из плоскости экрана. Перспективная камера этим контрактом не покрывается.

Результат содержит `projectionSpace: css-pixels` и `distanceUpperPx`; вложенный сертификат проекции также использует экранные единицы (включая исторически названные поля допусков). `point` и `curve` остаются в координатах модели. Неоднозначность, схлопнутая проекция, концы и превышение радиуса не изменяют документ. Повтор команды сохраняет вычисленную точку модели, а не координаты предыдущего клика на экране.
