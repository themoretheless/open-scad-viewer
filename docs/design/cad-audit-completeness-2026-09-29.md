# Ограничения аудита B-rep

## Исправление статуса

`audit_solid` проверяет владение оболочками, топологическую связность, ориентации, ограниченные классы вложения/разделения тел и согласованность использования общего ребра. Успешный `ok` относится к этим проверкам.

Ранее `selfIntersectionPairsChecked` содержал `n*(n-1)/2`, хотя пересечения этих пар не вычислялись. Теперь:

- `selfIntersectionPairsCandidate` — число возможных пар граней, используемое для ограничения ресурсов;
- `selfIntersectionPairsChecked` — 0: этот аудит не выполняет поиск пересечений;
- `selfIntersectionComplete` — false для любой непустой модели, включая модель с одной гранью. У одной грани возможны собственные пересечения;
- заметка `self_intersection_not_checked` заменяет необоснованное сообщение об успешной проверке.

Поля передаются через все пять сериализаторов сертификата и описаны в типах TypeScript. Проверки операций shell/loft требуют явного незавершённого статуса. Геометрия операций этим изменением не меняется.

## Воспроизводимое ограничение замкнутости

Нативный тест `sampled_edge_agreement_does_not_establish_geometric_closure` заменяет прямое ребро куба кривой степени 9. Поперечная добавка равна произведению `(t-j/8)` по j от 0 до 8. Она равна нулю во всех девяти параметрах, используемых `Model::validate`, но отклоняется более чем на десять допусков при t=1/16.

Модель проходит текущие validate и sew/audit. Это показывает, что проверка по точкам и сравнение общего ребра с самим собой не доказывают соответствие `C(t)=S(pcurve(t))` на всём интервале. Новый статус не выдаёт такой результат за полную геометрическую проверку.

## Что остаётся

Для классификации заполненных объёмов необходимы отдельные доказательства:

1. Соответствие 3D-ребра и его представления на каждой поверхности на всём параметрическом интервале, включая рациональные многопролётные кривые, швы и вырожденные рёбра.
2. Отсутствие недопустимых собственных и попарных пересечений граней; допустимые общие границы нужно учитывать отдельно.
3. Ориентация, компоненты и отношения вложения после геометрической проверки.

Интервальный подсчёт пересечений луча уже существует как отдельный нативный этап. Он пока не получает разрешение классифицировать объёмы только на основании `audit.ok`.

## Проверка

Девять тестов solid_audit включают пустую модель, сферу, цилиндр, ошибки ориентации/владения/перекрытия, сферическую полость и описанный контрпример. Доказательства текущего запуска хранятся в `docs/qualification/cad-roadmap-2026-09-28/audit-completeness/`.

Полный набор B-rep: 588/588 тестов. Проверка TypeScript `vue-tsc --noEmit` прошла.

Production WASM пересобран: 9 064 098 байт. Проверки API shell/loft — 10/10; CAD — 544/544 в 50 файлах. Vite и verify-dist прошли: 7 000 039 байт ресурсов плюс 11 120 218 байт raw WASM. Общий лимит ресурсов изменён с 6 998 000 до 7 000 500 байт по измерению; прирост относительно предыдущей квалификации — 2165 байт. Браузерная матрица P0 этим изменением не расширялась.
