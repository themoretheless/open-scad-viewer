# Главные кривизны и направления поверхности

`nurbs_core::surface_differential::at(surface, [u,v], [Side;2])` — типизированный Rust API без codec. Вычисляет интервальные границы двух подписанных главных кривизн, гауссовой и средней кривизны, а при подтверждённом разделении собственных значений — боксы двух единичных главных направлений. Ориентация задаётся `S_u × S_v`; разворот одной параметрической оси меняет знаки кривизн. Направления определены с точностью до знака.

Используются рациональные интервальные производные исходной поверхности, а не производные округлённой копии или выборка рядом с точкой. Локальные положительные масштабы параметров сокращаются в формулах фундаментальных форм. Положительная нижняя граница нормы векторного произведения подтверждает регулярность; его квадрат задаёт определитель первой фундаментальной формы. Главные кривизны ограничены через `H ± sqrt(H²-K)` с внешним округлением и математически допустимым пересечением дискриминанта с неотрицательной полуосью. Направления получаются из ненулевой строки обобщённой задачи собственных значений и нормируются интервально.

Automatic требует C2 базиса в обеих внутренних параметрических координатах. Явные Left/Right возвращают соответствующий односторонний предел; сторона вне естественного домена запрещена. На концах периодического хранения применяется естественная внутренняя сторона без утверждения о C2 через периодический шов. Дополнительная гладкость формы при недостаточной гладкости базиса автоматически не предполагается.

Status различает Available, ContinuityNotProven и RegularityNotProven. DirectionStatus отдельно различает NotComputed, EigenvaluesNotSeparated, VectorNotSeparated и Available. В умбилической точке главные направления не уникальны. Если интервалы собственных значений пересекаются, направления также остаются неподтверждёнными, даже когда точная поверхность не умбилическая. Сингулярность не подменяется нулевой кривизной. Неверные данные, параметры и стороны, переполнение или недопустимая интервальная арифметика возвращают ошибку. Это локальный запрос; он не строит линии кривизны и не доказывает регулярность всей поверхности. Гарантии относятся к хранимым binary64 данным, без неизвестной ошибки измерений.

Четыре независимых интеграционных теста покрывают квадратичный параболоид (кривизны 2 и 4, оси X/Y, K=8, H=3), разворот ориентации, седло (−4 и 2), плоскость, умбилик, коллапс поверхности, рациональный цилиндр радиуса 2, разные параметрические домены, односторонние пределы на добавленном узле, неверные запросы и неизменность источника. Для цилиндра учтено отличие хранимого среднего веса от идеального sqrt(1/2): сравнение использует явно заданный узкий диапазон, а не ложное равенство идеальной окружности.

```sh
cargo test --manifest-path crates/Cargo.toml -p nurbs-core --no-default-features --test surface_differential --test surface_regularity --quiet
```

Полный нативный набор `cargo test --manifest-path crates/Cargo.toml -p nurbs-core --no-default-features --quiet` также прошёл: 541 тест (371 unit, 168 integration, 2 doctest), без ошибок. Это проверка текущего Rust-снимка; WASM/редактор для нового API отдельно не проверены.
