# Перенос периодического шва и кандидаты для произвольного параметра

`periodic_seam::curve_at_knot(source, parameter)` циклически переставляет
контролы/веса и периодический базис без refit. Нужна валидная periodic
кривая и существующий узел в полуоткрытом активном домене [a,b).
Выходной домен [parameter,parameter+(b-a)], periodic-флаг сохраняется,
конечные degree копий контролов/весов материализуются явно.
Исходные повторы узлов обязаны совпадать с выражением knot+period
при binary64 вычислении; допущенный валидацией небольшой невязочный
периодический базис этот API отклоняет. Переполнение диапазонов
или нарушение порядка/кратностей обнаруживает итоговая validate.

`surface_at_knot(source, Axis::U/V, parameter)` применяет перенос
ко всем кривым выбранной periodic-оси через native edit_axis.
Другая ось сохраняется. Непериодическая ось отклоняется.

Контролы и веса переставляются без изменения численных значений;
внешние узлы нового периода вычисляются с добавлением period.
Непрерывный сертификат ошибки этого binary64 вычисления не заявлен.
В точной периодической арифметике геометрия сопоставляется старому
параметру с wrap по периоду. Число контролов, степень и их ограничения
сохраняются. Исходник не меняется при ошибке.

`curve_candidate(source, parameter)` теперь поддерживает seam внутри
пролёта: сначала циклически переносит начало на его нижний узел, затем
выполняет одну периодическую вставку Boehm в однородных координатах и
переносит начало на добавленный узел. Сохраняет степень и периодическое
хранение с явными degree копиями контролов и весов. Для существующего
узла выполняется прежний перенос без добавления контролов. Для нового
узла добавляется один контрол. Повторяющиеся узлы учитываются в индексе
затронутого блока, без искусственного повышения их кратности.

`surface_candidate(source, Axis::U/V, parameter)` выполняет тот же
перенос по выбранной оси. Другая ось сохраняется; результат должен
помещаться в сетку 32x32. Кривые ограничены 256 контролами. Некорректный
параметр, непериодическая ось, превышение бюджета, недопустимый базис,
численное переполнение и нарушение валидации результата возвращают
ошибку без изменения источника. Ограничение на авторские повторы
узлов исходника сохраняется.

Кандидат строится без refit и без выборки; в точной арифметике вставка
сохраняет форму. Но арифметика контролов и внешних узлов выполняется
в binary64. Непрерывная граница отклонения для результата и wrap-
соответствия ещё не подтверждена. Поэтому название candidate намеренно
не обещает выполнение допуска, Для кривой NURBS-0135 завершён отдельный непрерывный контракт
`curve_report` (см. `nurbs-periodic-seam-verification.md`), а для
поверхности NURBS-0148 — `surface_report` (см.
`nurbs-periodic-surface-verification.md`). Совпадение фаз замкнутых сечений
и автоматический выбор шва также остаются отдельными задачами.

Три теста проверяют все шесть существующих швов рациональной кривой,
параметрическое wrap-сопоставление, periodic-хранение, неверные
параметры/тип хранения и периодическую экструзию поверхности.
Все прошли с no-default-features.

Ещё три независимых интеграционных теста в
`crates/nurbs-core/tests/periodic_seam_candidates.rs` проверяют произвольные
параметры для степеней 1–3, рациональные веса, неравномерные и повторные
узлы через самостоятельную рекурсивную формулу Cox–de Boor; периодическую
экструзию по U и транспонированную по V; явные копии контролов; параметры,
лимиты 256/32 и атомарность отказов. Все шесть старых и новых тестов
прошли. Выборочная проверка формулы не заменяет непрерывный сертификат.

```sh
cargo test --manifest-path crates/Cargo.toml -p nurbs-core --no-default-features --test periodic_seam_candidates --test periodic_seam --quiet
```
