# Кривизна, кручение и фрейм кривой в Rust

`curve_differential::at(curve, parameter, Side)` возвращает интервальные границы кривизны, знакового кручения и компонентов фрейма Френе. Результат использует исходное рациональное определение; контрольные данные не заменяются округлённой аппроксимацией. 2D-кривые рассматриваются в плоскости z=0. Кривизна и кручение имеют размерность, обратную модельной длине.

## Формулы и границы

Интервальные производные v/a/j до третьего порядка извлекаются из исходного knot span в локальной возрастающей координате. На запросе выбирается более длинная из допустимых endpoint-restrictions, чтобы запрос около узла не требовал искусственно малого локального масштаба производных. Все операции нормирования и арифметика выполняются интервально с outward rounding.

При положительной нижней границе скорости:

```
s = |v|
T = v / s
Q = T × (a / s)
curvature = |Q| / s
B = Q / |Q|
N = B × T
torsion = (B · (j / s)) / |Q| / s
```

Это стандартные формулы `|v×a|/|v|³` и `(v×a)·j/|v×a|²`, записанные без промежуточного куба скорости. Поэтому проверенный масштаб 1e-110 не требует вычислять underflowing speed³. Формулы инвариантны при положительной линейной перепараметризации. При смене направления кривые сохраняют скалярные кривизну/кручение, а T/B меняют направление.

Границы заключают истинные значения рациональной кривой, определённой записанными binary64 данными как вещественными числами. Они включают округление вычислений, но не оценивают отличие этих данных от идеальной аналитической фигуры. Ширина интервала возвращается пользователю; отдельный допуск/обещание ширины API не задаёт.

## Узлы и вырождение

- `Automatic` внутри span использует двусторонние производные. Внутри домена на узле проверяется консервативная гарантия degree-multiplicity: C2 для кривизны/фрейма и C3 для кручения. Дополнительная гладкость конкретно авторской формы из контрольных точек не предполагается.
- `ContinuityNotProven` означает недостаток гарантии по knot structure, не доказанный геометрический разрыв. Например, кривая после точной вставки узла может быть гладкой, но без отдельного свидетельства запрашивается Left/Right.
- `Left`/`Right` используют соответствующие односторонние пределы исходного span. На концах естественного домена Automatic выбирает внутреннюю сторону; противоположная сторона отклоняется. Периодическая геометрия не создаёт неявного переноса параметра через seam.
- Если скорость не отделена от нуля, возвращается SpeedNotSeparatedFromZero и соответствующие поля отсутствуют. Это не доказательство точного нуля производной.
- Кривизна может быть доступна и равна нулю, как у прямой. Если cross-product не отделён от нуля, кручение и нормаль/binormal не придумываются; причина CurvatureNotSeparatedFromZero.
- curvature_status, torsion_status и frame_status отдельны: C2 достаточно для фрейма, даже если кручение на узле требует третьих производных. Tangent может быть доступен при гарантии только C1.
- Сохраняются ограничения Curve. Некорректный параметр/сторона/данные и численный overflow возвращают ошибку. Экстремально малые или плохо обусловленные данные могут дать широкие интервалы или unresolved-поля.

## Проверки

9 нативных интеграционных тестов `tests/curve_differential.rs` проверяют:

- точный полином [3t,3t²,t³], независимые формулы curvature/torsion и всех осей фрейма;
- окружность радиуса 4, плоскую параболу и нулевое планарное кручение;
- инвариантность при смене направления/домена;
- прямую, постоянную кривую и cusp;
- C0-угол с разными односторонними касательными;
- C2-узел, где кривизна/фрейм доступны, а третья производная требует явной стороны;
- периодические концы и недопустимые внешние стороны;
- масштаб 1e-110 и некорректные запросы.

```
cargo test --manifest-path crates/Cargo.toml -p nurbs-core --no-default-features --test curve_differential --quiet
cargo run --manifest-path crates/Cargo.toml -p nurbs-core --no-default-features --example curve_differential
```

Нативное использование не зависит от JSON, WASM, TypeScript или Rush. Bindings в этом пакете не добавляются.

Полная проверка пакета после добавления API: no-default-features — 284 unit, 42 integration, 2 doctest; default — 385 unit, 42 integration, 2 doctest. Нативный example curve_differential выполнен успешно.
