# Расстояние между двумя NURBS-кривыми

`nurbs_core::curve_distance::distance(a, b, tolerance_mm, max_cells)` возвращает типизированный `CurveDistance`, не требует codec и рассматривает полные активные образы двух валидных 2D/3D кривых одинаковой размерности. Положительные рациональные веса, периодические и стационарные участки проходят стандартную валидацию Curve.

Интервальный de Boor с внешним округлением ограничивает каждый непустой узловой интервал; поиск подразделяет пары интервалов. `distance_interval_mm` ограничивает глобальный минимум, а `parameters`, `points`, `point_enclosures` задают найденную пару кандидатов. Единицы соответствуют входным координатам несмотря на исторический суффикс mm. `converged` означает достаточную ширину границ расстояния, а не единственность или точность параметров минимизаторов. При пересечении положительная верхняя граница не доказывает отсутствие пересечения.

Допуск конечный положительный, бюджет 1..100000. Начальное число пар непустых интервалов должно помещаться в бюджет, иначе ошибка. Остановки по бюджету и точности сохраняют глобальные границы; числовое переполнение возвращает ошибку. Операция не вычисляет расстояние между trimmed B-rep гранями и не является решателем пересечений.

`crates/nurbs-core/tests/curve_pair_distance.rs` проверяет независимые аналитические расстояния между рациональными отрезками с неединичным параметрическим интервалом: параллельные (3), разнесённые концы (5), пересекающиеся (0), скрещивающиеся (2), оба порядка аргументов; неверную размерность, допуск и бюджет. Два теста прошли без default features.
