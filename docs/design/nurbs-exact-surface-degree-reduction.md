# Exact one-degree reduction of a tensor surface

`nurbs_core::editing::exact_surface_degree_reduction::reduce(source, axis, max_work)` lowers U or V degree by one only after exact original-definition equality of the complete tensor law. The selected axis must have nonperiodic clamped piecewise rational Bezier storage, degree2..25, with interior knot multiplicity equal to that degree. The unedited basis, UV domain, other-axis periodic representation and all original break values remain unchanged. Existing Surface degree/control/positive-weight/conditioning limits are retained.

The private `editing::exact_tensor_edit` engine is shared with the existing exact surface knot-removal API. It spends one caller ledger1..=1,000,000 across all row proposals, complete Cartesian row identities and scalar polynomial denominator identities. One-degree proposals use the bounded inverse Bernstein operation and independently check actual emitted binary64 poles/weights; rounded constructions carry no exact-source authority. A successful Cartesian row identity alone is insufficient: a row with changed homogeneous gauge can change tensor blending. Literal denominator functions must also be equal. Equal positive denominators and Cartesian row laws imply equal homogeneous rows; the unchanged transverse tensor basis therefore preserves the whole nominal surface.

All rows must produce compatible degrees, knots, periodicity and counts before assembly, and the complete resulting net is validated. Any failed row, altered denominator, resource/precision refusal or invalid output returns the complete unchanged source, even after preceding rows passed. Invalid input layouts/budgets return an error. There is no per-row reset or partly edited surface. Validation, bounded copies, knot assembly and arena setup remain outside the arithmetic ledger. One candidate per row is not exhaustive representation search or a minimality certificate.

Public `exact_surface_knot_removal::remove` paths, fields and refusal variants remain available; only their internal row-proof implementation is shared. Successful reductions preserve real nominal UV geometry; machine evaluator rounding, source bindings, B-rep identities, quotient sewing, regularity, embedding, material and volume certificates are separate. JSON/WASM/Rush/editor and exchange integration are not supplied.

Independent contracts cover a true degree2-by2 polynomial stored as bicubic data on nonunit UV domains, a nonconstant rational tensor clock, unchanged transverse periodic storage, late-row rollback, the shared work boundary and degree25 exhaustion. An adversarial constant-row tensor has y=2/5 at its center, while accepting only independently reduced row curves would change it to y=1/2; the mandatory denominator proof rejects that edit.
