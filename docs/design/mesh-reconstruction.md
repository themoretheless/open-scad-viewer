# Обратные преобразования из полигональной сетки

Преобразования явные: исходная сетка не заменяется автоматически. Все алгоритмы
на собственном Rust, доступны нативно и через `src/services/meshReconstruction.ts`.
Сетка может быть результатом любого ядра или загруженными треугольниками.
Совпадающие координаты свариваются точно, неиспользуемые вершины удаляются;
вырожденные треугольники отклоняются. Самопересечения не сертифицируются.

## Сетка → SDF

`meshToSdf(mesh, signed=true)` возвращает поле `mesh_distance`, которое можно
вычислять, комбинировать с примитивами, смещать и снова преобразовывать в сетку.
Расстояние — минимум до треугольников. Знак определяется суммой ориентированных
телесных углов. Для знакового поля нужна замкнутая ориентированная граница тела;
для открытой сетки используйте `signed=false`. Беззнаковое поле можно сместить,
чтобы получить оболочку, но само по себе оно не задаёт внутренность.
Вложенные оболочки полостей должны иметь противоположную ориентацию.
Пересекающиеся/неправильно вложенные оболочки не превращаются автоматически в
корректное тело. Нулевая поверхность поля соответствует исходным треугольникам;
повторная дискретизация приближённая и может пропускать мелкие детали.

Пределы: 4096 треугольников источника, 4096 единиц работы одного значения поля
(треугольник или примитив), 8 млн единиц для извлечения сетки. Разрешение сетки
ограничено также прежними лимитами SDF. Ускоряющего BVH пока нет.
Основа знака: [Generalized Winding Numbers](https://users.cs.utah.edu/~ladislav/jacobson13robust/jacobson13robust.html).

## Сетка → subdivision

`meshToSubdivision(mesh, iterations=8)` сохраняет треугольную топологию в
управляющей сетке. При `iterations=0` это прямое преобразование; native
`Cage::from_mesh` также доступен отдельно. Итерационный режим подбирает
управляющие точки, уменьшая RMS-отклонение исходных вершин после **одного** шага
Catmull–Clark. Принимаются только шаги, уменьшающие эту невязку.

Отчёт содержит начальную/конечную невязку, число принятых итераций и отдельно
максимальное/RMS геометрическое отклонение, измеренное в обе стороны по вершинам
и центрам треугольников. Уменьшение невязки не гарантирует уменьшение всех
геометрических отклонений. Это не восстановление неизвестной авторской
малополигональной quad-сетки или точной предельной поверхности.

Пределы: 2048 исходных треугольников, 0–32 итерации; сравнительное измерение
ограничено 8 млн проверок треугольников, поэтому большая сетка может потребовать
упрощения до вызова. Открытые ориентированные манифолдные сетки допустимы.

## Сетка → NURBS

`meshToNurbs(mesh, 'faceted', 0)` точно представляет каждый треугольник
билинейным рациональным патчем с единичными весами и одной схлопнутой границей.
Это сохраняет геометрию треугольников, не добавляя гладкости или неизвестной точности.

`meshToNurbs(mesh, 'point_normal', maxDeviationMm)` строит кубические
point-normal треугольные патчи по взвешенным площадью нормалям вершин и
переводит их в бикубические NURBS через параметризацию квадрата на треугольник.
Это выбранное приближение гладкой формы, не распознавание исходного CAD.
Острые углы также сглаживаются. Совпадающие границы патчей согласованы по
положению; глобальная C1-гладкость, отсутствие складок и самопересечений не
гарантируются. Алгоритм: [Curved PN triangles](https://doi.org/10.1145/364338.364387).

Допуск проверяется на сетке 9×9 точек каждого патча относительно его исходного
треугольника. Это **выборочная проверка**, не гарантированная граница Hausdorff.
Возвращаются патчи, исходные номера треугольников и измеренный максимум.
`tessellateNurbsPatches` строит общую сетку и возвращает отчёт её топологии.
Пределы: 2048 патча, 1–16 сегментов, 20000 треугольников результата.
При сшивке используется масштабируемый численный допуск; топологию проверяйте
по результату, особенно для почти совпадающих независимых деталей.

`meshToNurbsBrep(mesh)` отдельно строит **точный плоский B-rep**: общие вершины,
прямые рёбра, ориентированные pcurve, треугольные UV-контуры на невырожденных
плоских NURBS-поверхностях, оболочки и тела. Применяются существующие ограничения
B-rep, включая 256 граней. Общая геометрическая корректность тел не сертифицируется.

## Язык описания

```text
// @modelgraph-text/1
mesh = brep_box([-10,-10,-10],[10,10,10]).brep_tessellate(1)
show mesh.mesh_to_sdf().sdf_offset(1mm).sdf_tessellate([-15,-15,-15],[15,15,15],[12,12,12])
```

Другие цепочки:

- `mesh.mesh_to_subdivision(8).subdivision_tessellate(1)`
- `mesh.mesh_to_nurbs().nurbs_patches_tessellate(2)`
- `mesh.mesh_fit_nurbs(2mm).nurbs_patches_tessellate(2)`
- `mesh.mesh_to_nurbs_brep().brep_tessellate(2)`

Для произвольных данных есть `triangle_mesh(vertices,triangles)` — массивы
трёхмерных координат и троек индексов. Полные исходные определения сохраняются
в документе. Подключение к существующему пути ModelGraph не меняет backend
старых программ и спиннера.
