# Точная проверка замыкания UV-контура

`trim_domain::exact_loop_joins(&[Curve]) -> Result<Option<bool>>`
проверяет 1..256 валидных 2D-кривых в заданном порядке, включая
стык последней с первой. Для непериодических clamped-концов координаты
точной рациональной кривой равны авторским крайним контролам независимо
от весов: сравнение выполняется точным равенством значений координат,
без evaluate, выборок, округлённой нормы или допуска стыковки.

Some(true) — все стыки точно совпадают; Some(false) — хотя бы один
доступный точный стык не совпал; None — несовпадения не доказаны,
но один или несколько концов periodic/unclamped не имеют точного
доказательства в этом API. Даже если другой стык неизвестен,
доказанное несовпадение достаточно для Some(false).
Некорректная геометрия, размерность или число кривых возвращают ошибку.
Ограничение списка предотвращает неограниченную обработку контуров.

Эта операция не склеивает края, не допускает зазор по допуску,
не проверяет простоту, winding, ориентацию, внутренние отверстия
или принадлежность trim-области. Замкнутая кривая может возвращаться
по собственному следу или самопересекаться. Отдельные trim-операции
проверяют эти свойства отдельно. Простые значения +0 и -0 считаются
равными по Rust f64 ==; NaN запрещён валидацией.

Четыре интеграционных теста проверяют рациональные стыки с разными
весами, неединичные домены, ненулевой зазор, замкнутую возвратную
кривую, periodic/unclamped None, размерность, неправильные веса
и лимит 256. Все прошли с no-default-features. API нативный.
