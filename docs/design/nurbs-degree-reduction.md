# Понижение степени кривой с допуском

`nurbs_core::foundation::approximate_edits::reduce_curve_degree_report(source, degree, max_error, tolerance)` — типизированный Rust API без codec. Строит рациональный кандидат в меньшей степени, удаляя по одному экземпляру каждого различного узла за каждый шаг понижения. Поддерживается непериодическое валидное положительно взвешенное 2D/3D представление, для которого полученная база, refit и непрерывная проверка допустимы. Невозможная база или вычисление возвращает ошибку, а не обещание результата для любого входа.

Кандидат проверяется непосредственно относительно исходной кривой через `curve_deviation::inspect`, на полном общем активном параметрическом интервале, с учётом округления интервальной арифметики относительно входных binary64 данных. Промежуточное округлённое повышение степени больше не используется как заменитель возвращаемого кандидата.

Сертификат принимает кандидат только если непрерывная верхняя граница `error_upper` не превышает конечный неотрицательный max_error в единицах входных координат. При отказе `curve` содержит исходную кривую. Нулевой допуск не гарантирует принятия даже математически точного понижения: требуется доказанная нулевая граница. Контекст допуска сохраняется в отчёте; решение определяется max_error.

Проверка ограничена 4096 созданными интервалами и целевой шириной max(max_error*0.01,1e-12). При нехватке бюджета сохранённая верхняя граница по-прежнему определяет принятие или откат. Отсутствие сходимости не разрешает принятие по выбранным точкам. Кандидаты с недопустимой базой, несовместимой непрерывностью, числовым переполнением и другими ограничениями проверки отклоняются ошибкой. Периодическое хранилище не поддерживается этой операцией.

Три независимых теста `crates/nurbs-core/tests/degree_reduction.rs` прошли без default features: повышенная до второй степени рациональная прямая на неединичном домене успешно упрощается с проверкой по аналитической формуле; параболический профиль откатывается при малом допуске; неверные степени, бюджеты ошибки и веса отклоняются. Дополнительно прошли три теста удаления узла.
