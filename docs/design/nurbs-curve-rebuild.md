# Rebuild кривой с допуском

`nurbs_core::foundation::approximate_edits::rebuild_curve_report(source, degree, control_count, max_error, tolerance)` — типизированный Rust API без codec. Строит рациональный кандидат заданной степени и числа контролей с равномерным внутренним разбиением, сохраняя активный параметрический интервал. Поддерживает валидные положительно взвешенные 2D/3D кривые и периодическое wrapped-хранилище; невозможные базы, fit и численные ограничения возвращают ошибку.

Принятие определяется непрерывной верхней границей отклонения самого кандидата от исходной кривой через `curve_deviation::inspect`. Проверка использует исходное рациональное представление и внешнее округление. Старый Lipschitz-путь с округлённым предварительным разложением больше не определяет принятие rebuild. `accepted` требует error_upper<=max_error; иначе возвращается исходная кривая. Нулевой допуск может отклонить математически точный rebuild без доказанной нулевой границы.

Проверка ограничена 4096 созданными интервалами с целевой шириной max(max_error*0.01,1e-12). При нехватке бюджета решение использует сохранённую верхнюю границу, а не выборочную оценку. Неконечный или отрицательный допуск, недопустимые степень/число контролей, неверные веса, несовместимая непрерывность и арифметическое переполнение отклоняются. Геометрические размеры и ошибки выражены в единицах входа. Проверка не ищет оптимальную фазу или перепараметризацию.

Периодический кандидат сохраняет повторённые контролы и веса; evidence содержит seam_certificate. Наличие wrapped-хранилища не является общим доказательством геометрической гладкости любого порядка на шве. Семантика этой отдельной проверки остаётся в её отчёте.

Четыре независимых теста `crates/nurbs-core/tests/curve_rebuild.rs` прошли без default features: rebuild рациональной прямой с проверкой по аналитической формуле; откат для недостаточного линейного представления параболы; неверные степени, число контролей и допуски; периодический рациональный квадратичный источник, проверенный по независимым равномерным B-spline базисам и исходным весам, с контролем wrapped-хранилища. Дополнительно прошли 11 существующих unit-тестов rebuild с default features.
