# Адаптивная тесселяция поверхности

`nurbs_core::surface_tessellation::tessellate(surface, tolerance, max_cells)` возвращает вершины, их UV-параметры, ориентированные треугольники, непрерывные границы отклонения и статус достижения допуска. Это типизированный Rust API без codec.

Начальная сетка покрывает все активные узловые прямоугольники. Для каждого прямоугольника интервальная оценка исходной рациональной поверхности сравнивается с AABB фактически возвращённых binary64 вершин двух треугольников. Верхняя граница расстояния между этими боксами ограничивает соответствующее позиционное отклонение и симметричное Hausdorff-отклонение внутри ячейки. Это консервативная оценка: она теряет параметрическую корреляцию и может требовать много ячеек даже для плоскости. Оптимальное число треугольников не гарантируется.

Наибольшая ошибочная ячейка задаёт следующий разрез. Делится целая полоса прямоугольной сетки, поэтому внутри одного патча нет T-junctions, а общие вершины используют один индекс. Положительная ориентация UV-треугольников соответствует ориентации параметрического домена. Это не подтверждает регулярность, отсутствие складок, самопересечений или правильность ориентации физической оболочки. Периодический домен покрывается с разрезанным швом; его граничные вершины не склеиваются. Согласование сеток разных патчей относится к NURBS-0193.

Допуск должен быть положительным конечным, max_cells — 1..100000. Бюджет считает все проверенные прямоугольники, включая заменённые родительские. Если начальные узловые прямоугольники не помещаются в бюджет, возвращается ошибка. После начала refinement лимит работы или представимой точности возвращает полную сетку, reason=WorkLimit/PrecisionLimit и явные within_tolerance как для результата, так и для треугольников. Допуск не ослабляется. Непрерывность внутренних узловых границ обязательна; разрывы базиса, неверные входы и арифметическое переполнение возвращают ошибку. Источник не меняется. Trim-обрезка не выполняется.

Четыре интеграционных теста независимо проверяют рациональную билинейную формулу XYZ, отклонение внутри всех треугольников, суммарную UV-площадь полного домена, положительную UV-ориентацию, отсутствие несогласованных внутренних рёбер, достижение допуска, сохранение покрытия при бюджете 1, несколько исходных узловых пролётов, ошибки входа/лимитов/разрывов и разрезанный периодический шов.

```sh
cargo test --manifest-path crates/Cargo.toml -p nurbs-core --no-default-features --test surface_tessellation --quiet
```

Все 4 проверки прошли. WASM, редактор и экспорт новой сетки отдельно не квалифицированы.

Дополнительные регрессии прошли: 11 unit-тестов `surface_distance::tests` для общего интервального ядра и 4 интеграционных теста `curve_tessellation`. Всего в этом изменении проверены 19 тестов; полный набор повторно не запускался.
