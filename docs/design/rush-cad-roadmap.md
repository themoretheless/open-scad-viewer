# RushGraph CAD development sequence

Updated 2026-11-13: no items removed; corrected the outdated stage 5 statement about B-rep, sweeps, fillets and implicit fields in rush/nurbs-1 (see `src/language/rushGraphNurbs.ts`).

The requested order is preserved. This document distinguishes implemented behavior from planned work.

1. **Profiles, extrusion and revolution — implemented foundation.** Rectangle, circle and simple polygon XY profiles; profile booleans for holes; positive-height extrusion and partial/full revolution; profile/solid checks propagated through functions, closures and repetitions. Straight-segment sketch solving is available; arcs remain pending. Polygon limits and planar-transform checks run before kernel execution. Real worker tests verify hollow extrusion, polygon winding and revolved volume.
2. **Semantic references and image report — implemented operation-level foundation.** `rush_report` returns actual analysis, up to 2048 provenance runs mapped to node/instance paths, and front/top/isometric 192px PNG views. CPU z-buffer snapshots respect mesh transforms. Previews are bounded; failures retain measurements and report images_status=unavailable. Provenance does not guarantee persistent face identity. Edge/face queries and highlighted selections remain future work.
3. **Sketch constraint solver — implemented bounded straight-segment foundation.** Named points and segments support fixed points, horizontal/vertical, coincident, distance, parallel/perpendicular and equal length constraints. Reports distinguish numerical local freedom, linear inconsistency and nonlinear nonconvergence. Solved polygon profiles feed extrusion/revolution. Arc/circle/tangency solving remains pending. Existing expression constraints remain separate checks.
4. **Assemblies and joints — nested kinematic assemblies implemented.** Root assemblies preserve separate component meshes and named rigid attachment frames. Acyclic mates align anchors with a signed local Z gap and explicit rotation. Compile/check/report expose world transforms. Direct nested components retain instance paths and world transforms. Limited revolute/slider joints accept parameter expressions. rush_interference measures actual Manifold volume intersections for up to 8 leaf components at the current pose; failures return unknown. Contact, swept-motion checks, physics and closed-loop solving remain pending. Frame offsets do not certify actual surface clearance.
5. **Complex surfaces and implicit geometry — bounded mesh loft implemented.** Strictly convex XY profiles with parallel sections support positive axis scales and offsets, explicit triangulation and capped solids. Section heights must strictly increase. The actual worker verifies volume and closed topology for a tapered offset adapter. This is a piecewise planar mesh, with no spline accuracy claim. Own rational NURBS math is now available in explicit rush/nurbs-1: curves/surfaces, derivatives, editing, iso-curves, ruled/extruded/revolved surfaces, polygonal UV trim tessellation and fixed-vector mesh thickening. See rush-nurbs-own-kernel.md for the precise numerical contract. rush/nurbs-1 now also exposes the own Rust B-rep route: B-rep primitives, extrusion of polygon and line/arc curve loops, revolution, bounded planar Booleans and limited curved Booleans of parallel line/arc extrusions, chamfers and faceted fillets on convex planar edge chains, profile/progressive/framed/two-guide sweeps (with B-rep caps for progressive sweeps) and bounded signed distance fields (`sdf_*`). Still pending: general curved B-rep Booleans (sphere/torus/NURBS intersections), exact surface/surface trimming, STEP export from Rush, analytic fillets, offset shells, changing profile topology and certified sweep regularity. No external NURBS kernel is used.

The language prompt and schema are generated with `node --import tsx scripts/export-rush-language.mjs`. A hollow extruded profile is shown in `docs/languages/rush-1.profile.example.json`. Use rush_report to inspect it. These previews and expression constraints do not certify printability.
