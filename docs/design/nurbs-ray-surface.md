# Пересечение луча и поверхности

`nurbs_core::ray_surface::ray_intersections(surface, origin, direction, tolerance_uv, max_cells)` — типизированный Rust API без codec для полного активного образа валидной положительно взвешенной 3D поверхности и полупрямой P(t)=origin+t*direction, t>=0. Направление не обязано быть единичным; параметр масштабируется обратно длине направления. Trim-области не учитываются.

Базовый `intersections` решает пересечение полной прямой с поверхностью, покрывая исходную узловую сетку. Только строгое интервальное включение Krawczyk с обратимым предобусловливателем и доказанным сжатием даёт корень. Возвращаются UV-прямоугольник и интервальная граница параметра t с внешним округлением. API луча сохраняет корни с нижней границей t>=0, удаляет корни с верхней границей t<0, а интервалы, пересекающие t=0, оставляет неразрешёнными. Неразрешённые UV-области удаляются только если их целая интервальная оболочка доказанно позади начала луча.

`complete` означает отсутствие оставшихся неразрешённых областей для луча. Неполный отчёт не является доказательством отсутствия других корней. Корни на внешних границах, касания, совпадающие участки и корни на границах подразделения могут оставаться неразрешёнными. В частности, внутренний рациональный корень с локальным U=1/4 в тестовой панели не сертифицируется за 1000 ячеек, но остаётся покрытым отчётом. Это явное ограничение решателя; midpoint не используется для выдуманного решения. Отчёт не классифицирует объём тела, не обещает точный подсчёт корней в неразрешённых случаях и не строит кривые совпадения.

Начало и направление конечные, направление ненулевое; допуск UV положительный конечный, бюджет 1..100000. Исходная узловая сетка должна помещаться в бюджет. Неверные данные, переполнение и превышение начального бюджета возвращают ошибку; остановка дальнейшего поиска сохраняет покрытие неразрешённых областей.

Пять независимых тестов `crates/nurbs-core/tests/ray_surface.rs`: рациональная панель с неединичными UV-доменами и независимой обратной формулой; масштабированное положительное и отрицательное направление; исключение корней позади начала; t=0, граница поверхности и совпадение остаются неразрешёнными; неверные направления, допуски и бюджеты; покрытие внутреннего корня на границе подразделения. Дополнительно запускаются существующие интервальные тесты прямой: несколько корней, касание, рациональные веса, несколько узловых интервалов и внешние границы.
