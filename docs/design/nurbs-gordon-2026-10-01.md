# Gordon по рациональной сети кривых: NURBS-0057

Статус: integrated. WASM/TypeScript/Rush, пример и export regression
подключены. Визуальная и STEP-квалификация ещё ожидают выполнения.

`gordon::patch(u_curves,v_curves,parameters_u,parameters_v)` принимает
две семьи по 2..11 непериодических рациональных 3D-кривых. U-кривые
расположены по V-станциям, V-кривые — по U-станциям. Параметры конечны,
строго возрастают, безразмерны. Число parameters_u равно числу V-кривых;
число parameters_v — числу U-кривых. Кривые и станции нормируются на [0,1].

На каждом пересечении вычисленные однородные (XW,YW,ZW,W) должны совпасть
точно. Геометрического совпадения XYZ недостаточно при несовместимых
весовых функциях. Нормализация общих масштабов весов, перепараметризация,
поиск неизвестных параметров пересечения, tolerance snapping и автоматическое
изменение ориентации не выполняются. Даже вещественно совместимая сеть
может быть отвергнута из-за binary64-различий вычисленных пересечений.

Две натуральные однородные кубические loft-поверхности интерполируют
семьи кривых. Тензорная натуральная кубическая поверхность интерполирует
однородную сетку пересечений. Их степени и узлы согласуются по обеим осям;
результат складывается в однородных координатах как Su + Sv - Suv.
В вещественной арифметике такой результат сохраняет каждую кривую сети.
Это не только интерполяция точек её пересечений.

Все промежуточные и итоговые контрольные веса должны быть положительными.
В противном случае конструктор отказывает, хотя другое представление
возможно. Итоговый бюджет — 32 контроля по каждой оси; согласование может
превысить его и завершиться отказом. Binary64-ошибка, регулярность и
инъективность не сертифицированы. Вырождения, overshoot, самопересечения
и несовместимые угловые/касательные условия не исправляются автоматически.

JSON: `surface_gordon`, поля `u_curves`, `v_curves`, `parameters_u`,
`parameters_v`.

Native geometry tests проверяют независимый билинейный эталон;
нелинейную квадратичную сеть с независимой формулой Gordon между линиями
сети; сохранение каждой линии сети; рациональные дуги между пересечениями;
отказы несовместимых однородных пересечений и параметров. JSON-тест отдельно
проверяет ориентацию семейств.

`cargo test --manifest-path crates/nurbs-core/Cargo.toml --features transport`
— 288 тестов и 2 doctest прошли до добавления отдельного JSON-теста.
Последующий `cargo test --manifest-path crates/nurbs-core/Cargo.toml --features transport gordon`
— все 5 проверок Gordon прошли, включая JSON. Для сборки восстановлен
отсутствующий импорт TRANSVERSE_SINE в ss_intersection/continuation.rs.

TypeScript: `gordonNurbsSurface`. Rush: `gordon_surface` с именованными
массивами ссылок `u_curves`, `v_curves` и параметров `parameters_u`,
`parameters_v`. Обход зависимостей и выбор узлов графа учитывают обе семьи.
Пример: `examples/rush/gordon-surface.r`.
