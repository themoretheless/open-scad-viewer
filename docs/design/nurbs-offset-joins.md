# Стыки плоского offset-контура

Типизированные Rust API `nurbs_core::curve_offset_join::bevel`, `miter` и `miter_at_knot` не требуют codec.

Bevel сохраняет два переданных конечных 2D конца точно, с error_upper_mm=0 относительно этих представленных данных. Miter пересекает две представленные касательные прямые, проверяет верхнюю границу расстояния от пересечения до обоих концов против max_extension, возвращает три точки и верхнюю границу ошибки их построения. Направления не должны быть единичными; масштабирование касательных не меняет геометрические прямые.

`miter_at_knot` строит стык двух точных односторонних нормальных offset-касательных исходной кривой в существующем непрерывном внутреннем узле. Производные вычисляются на исходных узловых интервалах с внешним округлением, включая рациональные веса. Нормальные смещения и пересечение также ограничиваются интервальной арифметикой. Стыкуемые сечения не подменяются концами предварительно округлённых аппроксимаций.

error_upper_mm ограничивает позиционное отличие возвращаемых binary64 вершин от представленного или исходного идеального стыка в единицах координат. Это не граница отклонения всего offset-контура, не угловая гарантия и не доказательство топологии. Параллельность, недоказанный ненулевой определитель, превышение max_extension, недостаточный tolerance и арифметическое переполнение возвращают ошибку; callers явно выбирают bevel или иной лимит. Никакой автоматической замены miter на bevel нет.

`miter_at_knot` требует валидную положительно взвешенную непериодическую 2D кривую и существующий внутренний узел с кратностью не выше степени. Distance может быть отрицательным или нулевым, max_extension и tolerance положительные конечные. Другие API принимают конечные 2D точки и касательные. API не обрезает соседние offset-кривые, не добавляет round join, не удаляет самопересечения и не создаёт корректную machining-region автоматически. Эти задачи остаются отдельными операциями.

Три независимых интеграционных теста `crates/nurbs-core/tests/offset_join.rs` и пять существующих unit-тестов прошли без default features. Проверены аналитическое пересечение (2,1), различные масштабы касательных, точный bevel, рациональный угол с обоими знаками distance на неединичном исходном домене, неизменность источника, отсутствующий узел, параллельность, чрезмерное продолжение и неверные запросы.
