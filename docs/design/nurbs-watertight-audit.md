# Аудит водонепроницаемости авторенных патчей в Rust

`brep_core::watertight::inspect(&Model, max_cells)` проверяет все оболочки модели независимо от флага `Shell.closed`, без изменения источника. Вход требует валидной топологии, идентификаторов, определений NURBS, связности вершин и UV-контуров. API не восстанавливает соответствия между раздельными несшитыми патчами.

Для каждого недегенеративного ребра внутри оболочки нужны ровно два использования с противоположными направлениями после учёта FaceUse. Одиночные использования перечисляются как boundary_edges, несовместимые — как incompatible_edges. Дегенеративные полюса не требуют второго использования, но их границы также проходят непрерывную проверку.

Для каждого использования всей параметрической области проверяется согласование pcurve/surface с общей пространственной кривой ребра через outward interval verifier. Бюджет 1..1_000_000 cells общий для всех использований; внутренний вызов ограничен 100_000 cells. Необработанные использования явно unresolved. Геометрические ограничения и неподдержанные случаи наследуются от curve_surface_agreement; исчерпание бюджета не доказывает отсутствие щели.

Результаты: WithinTolerance — все швы согласованы с общими рёбрами в пределах tolerance_mm; OpenBoundary — есть открытые рёбра; Mismatch — несовместимая парность/ориентация или доказанное несогласование; Unresolved — неполная непрерывная проверка либо пустой набор оболочек. При нескольких проблемах полный отчёт сохраняется независимо от итоговой категории. Две поверхности при соответствующих параметрах одного общего ребра отличаются не более чем на 2*tolerance_mm по неравенству треугольника. Это не точное равенство и не сертификат простоты trim, отсутствия самопересечений, глобальной ориентации или корректного solid.

Проверки `crates/brep-core/tests/watertight.rs`: куб с отключённым closed и без Body проходит; 24 использования проверяются непрерывно, источник сохраняется; бюджет 1 даёт Unresolved; 0 и сверхлимитный бюджет отклоняются; изменение только внутренних контролей ребра при сохранённых концах даёт Mismatch; плоская открытая грань сообщает 4 boundary edges; пустой набор unresolved; NaN в весах отклоняется. Все 4 теста прошли.

NURBS-0197 пока planned: добавлен аудит уже авторенной топологии; автоматическое восстановление соответствий независимых патчей и общий контракт квалификации набора ещё не закрыты.

## Независимые патчи

`inspect_patch_set(&[Model], max_pairs, max_cells)` сопоставляет свободные недегенеративные границы разных моделей с одинаковым tolerance_mm. Поддерживаются 1..256 моделей и не более 1024 свободных границ. Для каждого источника непрерывно проверяются все edge/lift uses; потом пространственная кривая левой границы сравнивается с lift правой границы в противоположном эффективном направлении с учётом FaceUse. Нормализованное аффинное соответствие параметров явно фиксировано. Нелинейная перепараметризация, частичные совпадения и разбиение длинного ребра на несколько пока не восстанавливаются.

Партнёр принимается только при взаимно единственном доказанном соответствии и отсутствии неопределённых альтернатив. Все cross-model пары рассматриваются; после исчерпания pair budget оставшиеся пары остаются возможными и блокируют уникальность. Хранятся не более max_pairs подробных отчётов, число остальных — untested_pairs. Общий cell budget 1..1_000_000 включает исходное согласование и сравнения; pair budget 1..100_000. Источники неизменны, сшивка не выполняется. matches индексирует boundaries, unresolved перечисляет все свободные границы без взаимно уникального доказанного партнёра. all_boundaries_paired относится только к непустому набору свободных границ и не является solid-сертификатом.

Проверены два соседних квадрата: единственная общая граница найдена в противоположном направлении, шесть остальных unresolved. Дублированный сосед делает совпадение неоднозначным; pair budget=1 не даёт ложного совпадения. Источники сохраняются. Все 5 тестов watertight прошли после подключения. N197 остаётся planned до общего контракта восстановления нелинейных и частичных соответствий.

## Частичные границы

`inspect_boundary_portions(models, [source,target], [[a,b],[c,d]], max_cells)` квалифицирует явно заданные части двух свободных границ разных моделей. Нормализованные дроби следуют обходу pcurve, обязательно 0<=a<b<=1; адреса должны принадлежать указанной грани, недегенеративному свободному ребру и двум моделям с одинаковым tolerance_mm. Поддерживается budget 1..1_000_000 cells, общий для обеих непрерывных проверок (per-call ceiling 100_000).

Ориентация source coedge определяет подынтервал world curve; обе pcurves обрезаются собственными диапазонами. Возвращённая world curve независимо проверяется на исходных поверхностях source и target. Knot insertion выполняется в binary64: не заявляется exact identity математическому ограничению исходной кривой; выдаётся полное непрерывное согласование авторенных определений с поверхностями. Нулевая/обратная длина интервала и невалидные адреса дают ошибку; неполные verifier reports не дают within_tolerance. При исчерпании общего budget список agreements может содержать только первую проверку, within_tolerance=false.

Реальный тест: средняя половина ребра единичного квадрата сопоставлена с целым ребром соседнего прямоугольника высотой 0.5; проверены оба original surfaces, противоположные обходы, ожидаемые мировые endpoints [1,0.25,0]/[1,0.75,0], неизменность источников. Неверное смещение интервала, недостаточный budget и обратный диапазон не принимаются. Все 6 watertight тестов прошли. Автоматический поиск границ этих интервалов, их разбиение/сшивка в топологии и нелинейная перепараметризация остаются.
