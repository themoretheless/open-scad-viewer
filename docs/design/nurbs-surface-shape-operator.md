# Пространственный тензор кривизны для геометрической проверки G2

`nurbs_core::surface_shape_operator::at(surface, [u,v], [Side;2])` возвращает интервальную нормаль и пространственный тензор кривизны 3x3 в заданной точке. Это локальная операция для развития NURBS-0182; полного сертификата G2 вдоль шва она не выдаёт, поэтому пункт остаётся planned.

`boundary_bounds(surface, Boundary, [t0,t1], reverse)` непрерывно ограничивает нормаль и тензор на выбранном участке края. Интервал нормализован в [0,1], возможно обратное направление. Все пересечённые исходные пролёты включаются; интервальные коэффициенты тензора объединяются без выборочной подмены. Производные получают через общий с G1 внутренний boundary_jets. Для покрытого внутреннего узла свободной оси требуется C2 базиса; иначе возвращается ContinuityNotProven. Неподтверждённая регулярность любого участка даёт RegularityNotProven без тензора. Запрос вдали от недостаточно гладкого узла может быть доступен. Периодический storage seam и сравнение двух границ этой операцией не сертифицируются.

Пусть A содержит столбцы S_u,S_v, G=AᵀA — первая фундаментальная форма, II — вторая. Вычисляется A·G⁻¹·II·G⁻¹·Aᵀ, с нулевым действием на нормальное направление. Его собственные значения на касательной плоскости — подписанные главные кривизны, а направления живут в общей пространственной системе координат. При развороте нормали знак тензора меняется. Размерность — обратная длина. Два патча с одинаковыми главными значениями, но разными главными направлениями, получают разные тензоры: сравнение одних собственных значений для G2 недостаточно.

Используются интервальные производные исходной рациональной поверхности в координатах исходного пролёта, без численного дифференцирования выборки. Все операции выполняются с внешним округлением. Положительная нижняя граница |S_u×S_v| подтверждает регулярность; её квадрат задаёт положительный определитель G. Инверсия метрики, нормализация и умножение тензоров сохраняют интервальную границу. Дополнительные касательные члены вторых производных от нелинейной перепараметризации не меняют II в точной геометрии; интервальные границы сохраняют это соответствие без ложного утверждения нулевой ошибки.

Automatic требует C2 базиса в обеих внутренних координатах; Left/Right дают явные односторонние запросы. Status различает Available, ContinuityNotProven и RegularityNotProven. При неподтверждённой непрерывности/регулярности тензор отсутствует. Неверные параметры, стороны, входы и недопустимая арифметика возвращают ошибку. Применяются ограничения Surface::validate. Точность на плохо обусловленных входах может быть недостаточной; отсутствие оценки не подменяется нулевой кривизной.

Независимые проверки покрывают параболоид с тензором diag(2,4,0), перестановку главных направлений diag(4,2,0), разворот ориентации, плоскость, сингулярность, узловые односторонние пределы и неверные запросы. Отдельная аналитическая проверка использует z=x²+2y² с параметризацией x=2u+v+3u²,y=3v: разная скорость, касательный сдвиг и нелинейный член сохраняют пространственный тензор diag(2,4,0). Все 7 проверок прошли: 1 аналитический unit, 2 новых integration и 4 существующих surface_differential.

```sh
cargo test --manifest-path crates/Cargo.toml -p nurbs-core --no-default-features --lib surface_shape_operator::tests --quiet
cargo test --manifest-path crates/Cargo.toml -p nurbs-core --no-default-features --test surface_shape_operator --test surface_differential --quiet
```

Остаются непрерывное сравнение тензоров вдоль общей границы, согласование знаков нормалей с G1, управление соответствием границ и полный отчёт G2 с unresolved. WASM, редактор и STEP для нового API отдельно не квалифицированы.

Дополнительные проверки используют рациональный цилиндр с нелинейной параметризацией. Подписанная кривизна и вращающийся тангенциальный проектор вычисляются независимыми формулами производных рационального частного, с учётом хранимого binary64 веса. Также проверен полный участок края z=x²+2y² при x=−1 через явные аналитические компоненты пространственного тензора: проверяются непрерывные боксы, локальный запрос вдали от C1-узла, отказ при пересечении такого узла и неверный диапазон. Последний целевой прогон прошёл 14 тестов: 4 shape_operator, 6 G1 и 4 surface_differential. Полный нативный набор в этой правке повторно не запускался.

```sh
cargo test --manifest-path crates/Cargo.toml -p nurbs-core --no-default-features --test surface_shape_operator --test surface_g1 --test surface_differential --quiet
```
