# Original rational affine fibers and filled physical caps

Rust owns source geometry, proof budgets, exact construction, model binding and
Solid admission. JSON is transport. No caller-provided success flag participates.
`brep_fibered_source_construct` and `brep_fibered_source_audit` invoke the same
native owner. An unresolved stage returns no model and no final certificate.

## Sufficient original-source class

The original map is F(u,v,t) = T(t) + A(t)(Q(u,v)-origin). Q is a globally
injective regular NURBS carrier in one exact source plane. Original positive
rational Bezier affine poses define A and T on equal normalized time pieces.
A fixed world height covector n has n A parallel to the source plane normal
for every original control. Thus n F = n T for every material point.

The projected original translation controls must be consistently ordered, with
at least one strict difference per piece. For positive weights, the rational
height derivative has positive pairwise terms proportional to
(j-i) wi wj (hj-hi) Bi Bj / (t(1-t)); hence it is strictly signed inside each
piece even with flat endpoint jets. Exact raw endpoint matching joins pieces.
Adaptive outward interval covers prove A restricted to the source plane has
rank two throughout every complete piece. These facts and global carrier
injectivity prove global F injectivity. Compactness gives a homeomorphism of
any separately validated material region and its image, preserving topology.
The Jacobian is nonzero on open carrier-knot/time pieces.

This is a stratified parameter claim. `spanwiseInteriorRegular` does not assert
closed-cube Jacobian regularity. `knownSingularParameterEnds` explicitly records
flat height jets; independent all-face regularity proves the actual boundary.

## Complete original/actual boundary

The material owner checks the simple outer trim, disjoint correctly oriented
holes, carrier domain inclusion, each original profile's regularity and exact
profile/pcurve/carrier correspondence. It builds all original wall tensor
patches and both complete filled planar cap faces, including holes. All affine
coefficient images and weight products must be exactly binary64 representable;
otherwise construction refuses. No fitted source, sampled frame or rounded
proxy obtains original geometry credit. Successful source error is exactly zero.

The immutable supplied-model auditor reproduces expected source coefficients
and incidence, under a row budget. It permits a bijective exact vertex/edge
renumbering and exact Bezier U-chart reflections with their corresponding UV
wire reversal and face-use orientation change. Every point, curve, surface,
weight, loop, shell and body is then compared. Face and loop reordering, other
D4 gauges, edge clock reversal and positive projective weight rescaling remain
unsupported. Topology names and tolerance metadata carry no geometric credit.
The auditor returns the supplied model unchanged; it never repairs it.
Independent complete edge/face identities, vertex links and face regularity
are mandatory even after original binding succeeds.

## Applicable G1/G2, including physical cap/wall joins

Order 1 or 2 requires every cyclic original profile join to have the requested
positive geometric endpoint jets. Every original motion join must have exact
common Cartesian affine jets of that order, over all twelve fields. Equal
logical piece durations cancel, so nonbinary global station coordinates do not
supply rounded derivative factors. Common affine motion preserves the original
profile geometric speed/acceleration relations, including mixed jets.

The original height has flat endpoint jets to the requested order. All actual
wall/end-cap normals are bounded over the complete boundaries and must have
the same outward coorientation. Nonzero actual wall normal implies a regular
local in-plane graph; zero first/second height jets match planar cap normal
jets. Complete incidence and vertex fans include every cap/profile/time seam.
An inner-wall tangent cusp has opposite coorientation: C0 may be admitted,
but strict G1/G2 refuses. Sharp profile corners likewise keep C0.

## Budget and evidence boundaries

One exact coefficient ledger covers the whole original input. Carrier/frame
cells share the volume ledger; original traces, profile regularity, binding,
actual edge agreement, actual regularity, normal covers and smoothness each
have explicit shared owner budgets. All malformed original inputs are checked
before zero-budget/unsupported refusals. One-short tests cover each stage.

Native fixtures include flat-cap G2, nonbinary rational weights, oblique planes,
both height directions, three original motion pieces at logical 1/3 and 2/3,
a true G1-only knot, a tangent cusp, sharp C0 corners and one-bit mutations.
Native STEP audit and independent OCCT checks are separate gates. Floating
original-volume quadrature and source-point samples are supplemental checks,
not continuous-bound proofs.

This class does **not** complete arbitrary tilting/moving normalized frames,
nonplanar physical end-cap atlases, closed spatial source clock jets, arbitrary
pole fans or inexactly encodable retained maps. Existing independently qualified
sphere and closed annular-cap owners remain separate sufficient classes. Public
WASM/package fingerprints, browser/UI, full semantic G1 and fresh main/CI must
not be inferred from these new native checks. The full goal remains open.
