# CST construction and inverse fitting

The model is `v(u) = u^n1 * (1-u)^n2 * sum a_i B_i(u)`, for normalized station `u` in [0,1]. `CstProfile` coefficients are dimensionless. This checkpoint counts two capabilities: a checked NURBS constructor (`cst_airfoil`) and inverse fitting with world placement (`cst_fit`, `cst_fit_in_frame`, `cst_fit_sides`). Input variants and frame helpers are not separate capabilities.

`cst_airfoil` uses checked analytic samples and the existing least-squares airfoil fitter. Degree 1..25, at most 64 controls and 4096 fit sites remain unchanged. Raw `cst_points` allows 8..2048 stations per side, but a 2048-station loop has 4097 sites and is refused by the NURBS fitter. Profile exponents are finite and positive, matching coefficient rows have 2..12 finite values with absolute value <=1. Sampling checks for floating-point overflow. The unchecked scalar `cst_shape` returns NaN for an empty coefficient list instead of panicking.

`CstFrame` carries a finite origin, nonzero finite physical chord vector and a nonzero finite orthogonal ordinate direction. Directions are numerically normalized; near-orthogonality is checked at 64 machine epsilons. This is not an exact frame certificate. `point(u,v)` maps dimensionless coordinates into that world plane. Physical chord length must be finite and representable. Frame axes may be authored in any 3D orientation, including a vertical chord.

The legacy inverse path previously normalized X but kept physical Y as coefficients and partitioned by global Y. Thus nonunit chord changed the recovered profile and translating both sides above Y=0 lost the lower surface. The corrected solver normalizes both coordinates, partitions relative to the inferred chord frame and returns that frame. Its default inference averages the extreme-X tip data and assumes both closed tips are present; it is a heuristic and is not a general chord detector. Use an authored frame when orientation or endpoints are ambiguous. All input stations must lie within that authored chord, up to a fixed floating-point endpoint allowance.

`cst_fit_in_frame` infers sides from the sign of the in-plane ordinate. `cst_fit_sides` instead accepts explicitly labeled side samples, supporting cambered profiles whose upper and lower ordinates have the same sign. Both paths share the existing 16..4096 total-site limit, order 1..11 and lambda in [0,1]. Tikhonov regularization is applied to dimensionless coordinates and is invariant to uniform world scaling. The normal-equation solver may refuse rank deficiency. Inverse coefficients are numerical fit results and may fall outside the forward sampler's coefficient bounds; checked sampling/construction of such a result can refuse.

`max_residual` measures the physical in-plane ordinate residual at fitted stations. `max_out_of_plane` separately reports source deviation outside the authored plane. `hausdorff_residual` is a one-way 3D data-site-to-discrete-sample distance using the existing 512 sampling intervals per side; it is neither symmetric nor a continuous Hausdorff certificate. Out-of-plane input is not silently asserted to be exactly planar. `CstFitResult::points` and `curve` reconstruct in the returned world frame.

NURBS construction is approximate. Neither constructors nor inverse fits certify continuous error, simplicity, regularity, closure smoothness, B-rep ownership or aerodynamic performance. Independent tests cover polynomial profile equations, nonunit/translated inversion, vertical 3D placement, labeled cambered sides, world-scale regularization, explicit out-of-plane residuals, finite/invalid requests and unchanged limits. WASM, JSON, Rush, editor and STEP integration remain separate.
