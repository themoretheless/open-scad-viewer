# Нативное редактирование рациональной геометрии

Квалифицированы до статуса native 15 самостоятельных операций приоритетного набора 200. Это не 15 новых примитивов: шесть существующих Curve методов, существующие Surface::trim и Surface::iso получили независимые нативные проверки; шесть операций поверхности получили прямые типизированные функции в surface_edit. Нативный статус не означает непрерывный сертификат округления или полную промышленную квалификацию.

## API и ограничения

- Curve::insert: параметр в активном домене, положительное число вставок, контроль кратности узла; не больше 256 контрольных точек.
- Curve::elevate: степень не ниже исходной и не выше 25; результирующий бюджет 256 точек. Вещественная геометрия сохраняется; внутренняя кратность может возрасти, автоматическое сглаживание не выполняется.
- Curve::split: строго внутренний параметр; два результата сохраняют исходные интервалы.
- Curve::trim: конечный непустой возрастающий подинтервал исходного домена.
- Curve::reverse: отражение параметра относительно суммы концов домена.
- Curve::decompose: один clamped сегмент Безье на каждый ненулевой активный knot span; исходные параметры сохраняются.
- surface_edit::insert/elevate: те же операции по указанной оси U/V; результирующая сетка не более 32x32 точек.
- surface_edit::split: две поверхности с общей изопараметрической границей, исходные домены, строго внутренний конечный параметр.
- Surface::trim: прямоугольный поддомен U/V; произвольные trim-петли этой операцией не обрабатываются.
- surface_edit::transpose: новая S(u,v) = исходная S(v,u), обмен степеней, узлов, весов и признаков периодичности. Направление нормали меняется.
- surface_edit::reverse: отражение одной координаты параметра; направление нормали меняется.
- surface_edit::decompose: разбиение по всем активным U/V-узлам на clamped патчи Безье, порядок U-major, исходные параметрические интервалы, максимум 1024 патча.
- Surface::iso: указанная ось фиксируется, другая остаётся параметром рациональной кривой.

Линейная перепараметризация кривой доступна через foundation::reparameterize_curve_report. Новые домены конечны и возрастают, масштаб положителен; все различные исходные узлы должны оставаться различными после округления. Это также распространяется на внешние периодические узлы.

Все операции сначала валидируют входные определения. Не допускаются некорректные сетки, непропорциональные веса, нечисловые запросы и превышение действующих численных/ресурсных лимитов ядра. Эти операции не добавляют топологию B-rep и не выполняют sewing.

## Независимые проверки

`crates/nurbs-core/tests/native_edits.rs`: 12 тестов, выполнены успешно командой:

```
cargo test --manifest-path crates/Cargo.toml -p nurbs-core --no-default-features --test native_edits --quiet
```

Контрольная кривая — рациональная квадратичная форма с весами 1,2,1 и доменом [2,5]; ожидаемые координаты вычисляются непосредственно из полиномов Бернштейна и знаменателя, без повторного вызова исходной кривой. Контрольная поверхность — рациональный несимметричный билинейный патч с четырьмя разными весами, доменами [2,5] и [-4,2]; проверка использует отдельную явную формулу.

Проверяются геометрия после редактирования, исходные домены, общие границы разрезов, размеры сегментов Безье, изолинии, инволюция транспонирования, знак нормали и отказ на некорректных данных. Эта конечная выборка не является непрерывной границей ошибки. Добавлены проверки периодического цилиндрического патча: обмен осей, отражение параметра, сохранение seam и storage; проверены периодическая перепараметризация и отказы при превышении бюджетов 256 точек кривой и 32x32 точек поверхности. Экстремально обусловленные входы требуют дальнейшего расширения проверок.

Нативный пример `native_edits` строит дугу, повышает степень, разделяет её, экструдирует и разбивает поверхность. JSON, WASM и TypeScript не нужны для использования API.

## Исправленный дефект перепараметризации

Исходная степень 2, узлы [2,2,2,3,3+2e-9,5,5,5] и новый домен [1e8,1e8+1] воспроизводили склеивание разных внутренних узлов. Ранее итоговая кратность 2 была допустима для степени 2, поэтому обычная валидация пропускала изменение. Тест affine_reparameterization_refuses_collapsed_distinct_knots воспроизвёл ошибку до изменения и прошёл после проверки строгого порядка для всех различных исходных узлов. Операция теперь возвращает ошибку, а не выдаёт изменённую кривую.

Аналогичный дефект устранён в Curve::reverse: [0,0,0,1,1+2e-9,1e8,1e8,1e8] ранее давал допустимое склеивание двух разных узлов после отражения. Регрессионный тест сначала падал и затем прошёл после явной проверки строгого порядка. Отказ безопасно применяется и к surface_edit::reverse через общую операцию Curve.

Полный нативный прогон `cargo test --manifest-path crates/Cargo.toml -p nurbs-core --no-default-features --quiet`: 282 unit-теста, 12 интеграционных тестов, 2 doctest прошли. Пример native_edits выполнен: 2 части кривой и 4 патча Безье поверхности. Каталог содержит 96 реализованных возможностей и 104 planned в приоритетном наборе 200; дальняя цель 1200 остаётся незавершённой.

Полный прогон с transport после исправлений: `cargo test --manifest-path crates/Cargo.toml -p nurbs-core --quiet` — 383 unit-теста, 12 интеграционных тестов, 2 doctest прошли. rustfmt проверен для изменённых Rust файлов; целевой git diff --check прошёл. Новая сборка WASM в этом пакете не выполнялась.
