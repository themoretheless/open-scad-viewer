# Корпус по рациональным сечениям: аудит существующего Rust API

`brep_core::rational_section_loft(sections)` строит сохранённую B-rep модель с боковыми NURBS-патчами, двумя planar trim caps, общей топологией рёбер, замкнутой shell и Body. Сечения задаются как `[section][loop][curve]`: внешний контур и до 15 отверстий. Линейный loft сохраняет каждое исходное сечение; это самостоятельное построение корпуса с отверстиями и крышками, а не только открытой поверхности loft.

Соответствие контуров задаёт автор. Автоматическая фазировка, изменение числа отверстий и ветвление корпуса не выполняются. Кривые разделяются на Bezier spans; соответствующие spans должны иметь одинаковые степени и веса. Поддерживается до 64 spans суммарно на сечение, 2..1025 исходных сечений при соблюдении лимита 1024 faces, 1..16 loops, 1..64 curves на loop. Координаты controls ограничены 1e6. Точные совпадения authored endpoints обязательны; незамкнутые контуры отвергаются.

Концевые сечения должны иметь подтверждённые planar trim regions. Caps проверяют winding, вложенность holes, регулярность и injectivity planar chart, а также непрерывное согласование сохранённых UV/world boundaries. Начальное направление loft должно пересекать плоскость первой крышки. Численные неопределённости, несогласованное соответствие, выход из лимитов и неправильные отверстия дают отказ.

`natural_section_loft` дополнительно интерполирует 2..11 сечений кубическими стенками при явно заданных возрастающих параметрах. `capped_loft_surfaces` сохраняет явно переданные боковые патчи. Эти режимы не заменяют квалификацию базового `rational_section_loft`.

Замкнутая incidence сама по себе не доказывает geometric embedding, отсутствие самопересечений, outward orientation всей поверхности или корректность solid. Они проверяются отдельным solid audit. Нет общего rounding-inclusive сертификата относительно идеального design intent. STEP round-trip конкретных fixtures не является универсальной квалификацией CAD-обмена.

Аудит использует существующие независимые тесты `crates/brep-core/tests/rational_section_loft.rs`: аналитические конические внешние/внутренние стенки, отверстия в caps, двухсторонняя incidence, 33 сечения, обратное направление, curved middle section, supplied seams, invalid input и native STEP fixtures. Актуальный прогон завершился: 19 tests passed, 0 failed. SHA-256 реализации и тестового файла совпали до и после запуска. NURBS-0094 имеет статус native для указанного контракта построения сохранённой модели; это не общий solid-сертификат. Команда, hashes и полный результат сохранены в `docs/qualification/nurbs-body-sections-2026-10-15/`.
