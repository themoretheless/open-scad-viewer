# Удаление узлов и понижение степени поверхности

Типизированные Rust API без codec:

- `nurbs_core::foundation::approximate_edits::remove_surface_knot_report(source, axis, knot, max_error, tolerance)` удаляет один экземпляр существующего внутреннего узла.
- `nurbs_core::foundation::approximate_edits::reduce_surface_degree_report(source, axis, degree, max_error, tolerance)` понижает степень выбранной оси.

Оба используют существующий `reduce_surface_axis_report` с типизированной операцией, строят рациональный кандидат по контрольным сечениям и проверяют сам возвращаемый кандидат через `continuity::deviation::positional_upper`. Эта непрерывная граница учитывает исходные веса и внешнее округление. Прежние повторная вставка/повышение и диагональ общей коробки больше не заменяют ошибку возвращаемой поверхности.

`accepted` требует верхней границы не больше конечного неотрицательного max_error в единицах координат. При отказе возвращается исходная поверхность. Нулевой допуск может быть отклонён даже для математически точного преобразования, если равенство не доказано; округлённая реконструкция не является таким доказательством. Контекст допуска сохраняется в отчёте.

Поддерживаются валидные положительно взвешенные 3D поверхности с непериодической редактируемой осью. Периодическую ось необходимо редактировать специализированным API. Кандидат должен иметь допустимую базу, веса и общий активный UV-прямоугольник. Неверные данные, отсутствие узла, удаление граничного узла, неправильная степень, невозможная аппроксимация, превышение лимитов непрерывной проверки и арифметическое переполнение возвращают ошибку. Нет обещания успешного удаления/понижения для любого валидного входа, оптимального соответствия UV или сохранения trim-топологии.

Четыре независимых теста `crates/nurbs-core/tests/surface_simplification.rs` прошли без default features: удаление вставленного узла и понижение повышенной степени по обеим осям рациональной панели, проверенной по независимой разделимой формуле; откат для z=u²+v² с малым бюджетом; неверные узлы, степени и допуски. Старый тест, принимавший нулевую ошибку по округлённой реконструкции, заменён проверкой отката при недоказанном нуле и принятия при доказанном положительном бюджете.
