# Адаптивная тесселяция кривой с непрерывной границей

`nurbs_core::curve_tessellation::tessellate(curve, tolerance, max_cells)` — типизированный Rust API без codec. Покрывает весь активный домен валидной положительно взвешенной 2D/3D NURBS-кривой хордами, начиная с каждого непустого исходного узлового интервала. Возвращает отсортированные Segment с доменом, двумя фактическими binary64 концами, error_upper и within_tolerance, а также общий Report.

Интервальный de Boor с внешним округлением ограничивает исходный рациональный образ каждого интервала. Контрольная коробка хорды строится по самим возвращаемым концам. Верхняя граница расстояния между двумя коробками ограничивает отклонение соответствующих точек кривой и линейной интерполяции хорды на всём интервале, а не только в выбранных точках. Она также ограничивает симметричное расстояние Хаусдорфа двух образов, поскольку оба полностью покрываются этим соответствием. Ошибка вычисленных концов включена через коробку фактических возвращаемых координат.

Эта оценка консервативна: теряется корреляция параметров между двумя коробками, поэтому даже прямая может потребовать много подразделений. Нет обещания оптимального числа сегментов или оценки кривизны. Дробление происходит в среднем параметре, если граница превышает допуск; общие границы соседних сегментов имеют одинаковые параметры и вычисленные точки.

Допуск положительный конечный в единицах координат. Бюджет 1..100000 считает все созданные интервалы, включая исходные. Если исходное разбиение превышает бюджет, ошибка. При дальнейшей остановке по бюджету или отсутствию представимого промежуточного параметра сохраняется весь активный домен: сегменты с недоказанным допуском остаются в результате с within_tolerance=false. Общий флаг true требует доказательства допуска для каждого сегмента; error_upper — максимум сохранённых границ. Неверные данные и арифметическое переполнение возвращают ошибку.

Полностью повторённые внутренние узлы отклоняются консервативным требованием непрерывности базиса. Периодический активный домен покрывается за один период; швы не получают отдельной топологической квалификации. Тесселяция не сохраняет trims, не доказывает отсутствие самопересечений и не является STEP-конвертацией. Доказательство относится к переданным binary64 данным, без ошибок измерения неизвестной идеальной кривой.

Четыре независимых теста `crates/nurbs-core/tests/curve_tessellation.rs` прошли без default features: рациональная квадратичная кривая на неединичном домене, проверенная по аналитической формуле против каждой хорды; отсутствие разрывов параметрического покрытия и общих концов; сохранение полного домена при бюджетной остановке; неверные допуски, лимиты и веса; замкнутая рациональная окружность с проверкой аналитической радиальной полосы для всех хорд. Дополнительно прошли четыре теста непрерывного отклонения кривой.
