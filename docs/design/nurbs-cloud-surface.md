# Поверхность по облаку точек

`nurbs_core::foundation::fitting::fit_surface_cloud_certified_report(points,controls_u,controls_v,tolerance)` строит polynomial tensor Bézier surface степени controls_u-1 × controls_v-1 с положительными unit weights. Облако 4..4096 конечных XYZ sites; controls каждой оси 2..8. Сначала создаётся PCA chart исходного облака, затем least-squares Bernstein fit с numerical rank/pivot diagnostics. Возвращается один Surface с UV=[0,1]²; optional tolerance хранится в evidence и не означает гарантированного достижения заданной ошибки.

PCA вычисляется на масштабированных координатах, covariance нормируется перед power iteration. Первая ось стартует с максимального covariance diagonal. Вторая выбирается по наибольшему covariance spread в ортогональном дополнении первой, затем ортогонализуется на каждом из 24 шагов. Фиксированная perpendicular coordinate axis могла совпадать с нормалью вертикальной плоскости; теперь проверены все три axis-aligned orientations. Для rank-one/coincident или численно неразделимого облака возвращается typed numeric error: threshold 1e-14 в нормированной covariance. Normal equations имеют отдельный numerical rank cutoff 1e-12. Это не exact rank/uniqueness certificate.

`data_site_error_upper` — outward bound расстояния между каждым authored binary64 site и polynomial Surface в назначенной binary64 UV-точке. Используется interval tensor de Casteljau и outward Euclidean box distance, без unwrap оценщика. Граница относится к математической поверхности с возвращёнными controls, а не к ошибке отдельного floating-point Surface::evaluate.

`hausdorff_error_upper` — строгая, но грубая двусторонняя граница расстояния между всей возвращённой mathematical surface и **конечным** облаком. Positive Bernstein basis держит Surface внутри control box. Максимальное outward расстояние между control/data boxes ограничивает все пары точек, значит обе directed nearest distances. Число sites не считается fill distance: прежнее diameter/sqrt(N) не имело основания для unstructured/duplicated data и удалено. Повторение одинаковых sites не создаёт нового покрытия или меньшей границы. Граница не характеризует неизвестную непрерывную исходную форму между sites.

PCA chart не реконструирует автоматически topology, folds, holes, multiple sheets или solid. Количество controls и отсутствие устойчивого chart могут ограничивать качество/применимость; caller должен читать site residual и numerical rank. Основные ресурсы ограничены 4096 sites, 64 controls, 48 power iterations, конечным pivot solve и interval evaluation по sites. Surface validation ограничивает численную представимость возвращаемых controls.

Независимые regressions: correlated rotated plane с analytic implicit equation, все три coordinate-plane orientations, сохранение coarse bound при дублировании sites, degenerate/coincident/invalid clouds. Также выполняются dependent surface-offset и fillet public regression groups. Проверка 2026-10-14: четыре cloud integration groups, шесть dependent offset/fillet groups и все пять существующих fitting unit tests прошли offline/locked, no-default-features. Итого 15 профильных tests; 1274 других unit tests не запускались. Три source/test файла совпали по SHA-256 до/после. NURBS-0060: native с описанным finite-cloud контрактом; неизвестная исходная форма и topology не квалифицированы.
