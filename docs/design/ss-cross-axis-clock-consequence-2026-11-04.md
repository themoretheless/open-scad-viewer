# SS endpoint identity across different free axes

The common point/port reconciliation path now has an exact cross-axis proof.
For a source deflated graph, it takes the ORIGINAL rational SS span equations,
adds that point's owned scalar-clock polynomial, and computes a bounded exact
Groebner basis. The other clock polynomial is pulled back through the exact
original knot-span frames to the source span's coordinate system. Zero normal
form proves that the original point satisfies the other clock polynomial.

This implication alone is insufficient. Native original membership must also
place the entire point enclosure in the target graph. For a nonlinear target
clock the target-parameter enclosure must lie wholly in its original unique-root
isolator. A linear target polynomial has a single root globally. Together with
native graph uniqueness these checks identify the same original UV4/world point.
Neither fitted curves, box overlap nor a midpoint authorizes the join.

Ideal implication is directional: the reverse constraint may include additional
factors. Up to two directed attempts are allowed; either positive proof is
sufficient. Each attempt has a separate explicit source algebra budget from
`OriginalSsCurveLimits.projection`, with 4096 pair / 128 basis limits. Clock
validation has its existing explicit clock budget; geometry membership retains
its native policy. Exhaustion is an error, not a welding fallback. A failed
normal-form proof is absence of authority, not proof that the physical points
are unequal. Nonlinear blowdown/other unsupported source carriers stay refused.

Qualification uses a real original circle with an irrational x clock and an
independently authored quartic y clock, across different free axes. It checks
both query directions, port rebinding, the wrong selected root of the same
quartic, a perturbed polynomial, and deficient algebra work. A BRep regression
splits an original edge using these independent owners, reconciles the cross-axis
junction and replays the resulting nine-edge paired BRep and its original UV
projections. Existing affine, repeated-root, node/pole, periodic-path, native
port and mixed-topology regressions remain part of qualification.

This is a sufficient original-equation consequence proof. It does not enumerate
all branch intersections, generate all third-face constraints, prove arbitrary
localized/radical consequences or solve cross-source face junctions. Complete
singular/periodic arrangements and winding, finite trim/material selection,
general intersecting Boolean/healing, lineage/history, bridge/WASM execution
and the wider quad/offset/fillet/G2 requirements remain open.
