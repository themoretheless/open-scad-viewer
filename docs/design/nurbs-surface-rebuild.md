# Rebuild поверхности с допуском

`nurbs_core::foundation::approximate_edits::rebuild_surface_report(source, axis, degree, control_count, max_error, tolerance)` — типизированный Rust API без codec. Перестраивает выбранную ось валидной положительно взвешенной 3D NURBS-поверхности в равномерное представление заданной степени и числа контролей, сохраняя активный UV-домен. Вторая ось сохраняется. Непериодическое и периодическое wrapped-хранилище поддерживаются через существующий rebuild_candidate; невозможное представление или fit возвращает ошибку.

Сертификат сравнивает исходную поверхность с возвращаемым кандидатом через непрерывную `continuity::deviation::positional_upper`. Однородное интервальное преобразование, согласование узлов и Bernstein-произведения учитывают арифметическое округление относительно binary64 входов. Точно одинаковое представление имеет нулевую ошибку. Принятие требует error_upper<=max_error; иначе возвращается исходная поверхность.

max_error конечный неотрицательный в единицах входных координат. Большая консервативная оценка не доказывает фактического нарушения допуска; она не разрешает принятие. Нулевой допуск может отклонять математически точную перестройку без доказанного равенства. Степень 1..25, поверхность ограничена 32 контролями по каждой оси; периодический rebuild дополнительно требует достаточного числа уникальных контролей. Действуют ограничения непрерывной проверки: коэффициентная работа 2000000, сетка уточнения 262144, внутреннее уточнение кривой 8192 контролей. Некорректные данные, переполнение и невозможность сертификата возвращают ошибку.

Wrapped-хранилище сохраняется; этот API не заявляет общего доказательства гладкости любого порядка на периодическом шве. Нет поиска оптимальной фазы, trim-топологии или многопатчевого соответствия. Ошибка измерений и предшествующие изменения неизвестной идеальной геометрии не включены в сертификат.

Четыре независимых теста `crates/nurbs-core/tests/surface_rebuild.rs` прошли без default features: рациональная панель по обеим осям с проверкой по разделимой формуле; откат для z=u²+v² при недостаточном линейном представлении; периодическая экструзия с проверкой по независимым равномерным квадратичным базисам и исходным весам, а также wrapped-контролям; неверные степени, число контролей и допуски.
