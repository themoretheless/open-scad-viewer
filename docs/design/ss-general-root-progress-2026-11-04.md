# General original-source SS root geometry — 2026-11-04

Work continues from `450605cef`. This is a source implementation checkpoint,
not completion of general trim, healing, closed bodies, Boolean or WASM delivery.
No Plasticity implementation code is copied into these algorithms.

## Implemented

- Original rational Cox knot-patch equations over exact Q, including native
  periodic seam and original C0 admission. Arbitrary polynomial coefficients,
  not graph/plane/cone recognition, define the algebraic backend.
- Bounded Buchberger basis with exact original ideal equality; general recursive
  multivariate GCD deflation. Both zero-set directions are certified by exact
  divisibility, preserving roots of multiple contacts.
- Exact collapsed-pole strata and five-variable saturation; isolated original
  pole contact is distinguished from an off-pole continuation. A uniform radial
  root arc includes its actual original pole endpoint.
- Regular periodic quotient charts, exact phase membership and original seam
  identities. Full original parameter-product census and generic numerical
  chart proposals with native original-source acceptance and budgeted repair.
- Shared fixed-preconditioner Krawczyk math. Uniform deflated root operators use
  exact projection and centered polynomial translation before outward interval
  evaluation; integer powers retain their even-power nonnegative range.
- Exact root-valued world/UV carriers, rather than fitted rational geometry.
  Queries return bounded original-source enclosures. Exact affine span clocks,
  endpoint selectors, mixed-axis port binding and reverse edge restrictions.
- Closed root-wire incidence requires the same exact root selectors at joins.
  It deliberately admits a doubled edge as closed incidence without calling it
  a Jordan boundary or material solid.
- Planar UV winding by convex interval homotopies from entire original arcs to
  a temporary polygon. The polygon is only a witness, not stored geometry.
  Shared endpoint enclosures are cached, exact Q orientation predicates are used,
  and subdivision/source work budgets are global across attempts.

## Still required — original full scope remains open

1. Global algebraic real-root stratification, squarefree singular crossings,
   arbitrary multiple branch networks and isolated strata. Current deflated
   fiber accepts three equivalent equations; larger bases require certified
   residual ideal membership, not ignoring surplus equations.
2. Glue the whole source census into physical branches. Parameter coverage is
   not a proof of world embedding, physical branch count or nonzero speed.
3. Exact implicit BRep storage and full finite-face arrangement. Current planar
   winding excludes phased and collapsed-pole junctions. General periodic
   homology, UV seam/pole bridges, Jordan/embedding proofs, holes and clipped
   finite-face endpoints remain necessary.
4. Material selection from both operands, complete split-face topology, exact
   shared edge ownership and source lineage. Subdivision retaining both sectors
   remains `materialClassified=false`.
5. Closed-body qualification: oriented embedded shells, nesting/cavities,
   self-intersections, bounded healing and complete re-admission after repair.
6. General union/intersection/difference/XOR with independent volume validation.
   None of the new root/winding owners is a closed-material-body certificate.
7. Native bridge/WASM and actual host/Worker qualification for the new APIs.
   Installed module remains the previously qualified 65158c6c... build; these
   source additions have not been delivered in that module.
