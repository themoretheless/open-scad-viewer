# Exact compatible curve concatenation

`nurbs_core::editing::exact_curve_merge::merge(left,right)` returns one Curve covering both original absolute parameter intervals. Both input curves must validate, have the same degree and dimension, be clamped and nonperiodic, and satisfy exact interval adjacency. Their shared endpoint Cartesian control and stored weight must be identical. Equal images with different endpoint gauges, nearby points, reversed or overlapping domains, and different degrees are refused without guessing or snapping.

For degree p the result copies the left knots without p+1 end repetitions, inserts p seam repetitions, then copies the right knots without p+1 start repetitions. All left controls/weights and all right controls/weights except the common endpoint are copied unchanged. This is structural C0 concatenation: on each side the original clamped B-spline basis and complete rational law are retained, and both limits at the seam equal the common homogeneous endpoint. No parameter or geometry arithmetic is used. The existing256-control limit, dimensions2/3, degree1..25, coordinates, positive weights and global conditioning limits remain unchanged; the completed output is validated. No extra predicate/work budget is introduced for bounded equality/index/copy operations.

The report contains no curve on refusal; invalid input returns an error. Both inputs are borrowed and remain unchanged. A successful result makes no G1/G2, simplicity, closed-wire, B-rep, material, STEP or evaluator-bit-identity claim. Existing source-bound downstream certificates must be rebuilt. The seam may be necessary, for example at a genuine profile corner. The existing exact curve-knot simplification pass can independently prove and remove redundant seam knots; its budget and refusals remain separate.

Tests retain both absolute rational clocks on nonunit domains in3D; recover an independent quadratic law through split→merge→exact simplification; preserve a necessary right-angle corner; reject a different endpoint weight gauge or one-ULP mismatch; distinguish periodic, unclamped, degree, dimension and domain incompatibilities; reject invalid data; and keep the existing control limit. An independent Fraction Cox-de Boor coefficient oracle proves complete rational and polynomial parameter laws on each source interval and detects inconsistent gauge concatenation. Native Rust only: transport, WASM, Rush, editor and exchange are not qualified by these tests.
