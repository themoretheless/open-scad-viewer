# Exact compatible tensor-patch concatenation

`nurbs_core::editing::exact_surface_merge::merge(left,right,axis)` combines two adjacent parameter rectangles into one tensor NURBS definition. The original absolute U/V coordinates are retained on both rectangles. There is no parameter normalization, fitting, tolerance, snapping, degree elevation, knot unification or weight rescaling.

Inputs must validate under the existing Surface limits. The selected axes must be nonperiodic and clamped, have the same degree, and meet exactly at `left.max == right.min`. The unedited basis tuple (degree, complete knots, control count, periodic flag) must be identical. Each corresponding seam Cartesian control and stored weight must be numerically equal. Equal boundary images represented with different gauges/bases are deliberately refused rather than guessed. The unedited axis may retain its existing periodic storage, without a new quotient or regularity certificate.

For selected degree p, the output copies the left knot vector without its p+1 end repetitions, inserts p seam repetitions, and appends the right knots without their p+1 start repetitions. It retains all left controls/weights and appends all right controls/weights except the shared boundary row/column. This is the standard C0 concatenation of identical endpoint homogeneous coefficients: on each open side, the B-spline basis is the original clamped basis; at the seam, both one-sided limits equal the shared positive-weight rational boundary. Combining unchanged homogeneous rows in the unchanged other-axis basis preserves the complete nominal tensor law, including its denominator. No floating geometry arithmetic is performed during this structural operation. Equality comparisons, bounded indexing/copying and validation operate within the unchanged256 controls per axis and existing degree/weight/coordinate limits. The result is validated again, including global weight conditioning.

`Report.surface` is `None` on every refusal. Reasons distinguish periodic selected axes, degree mismatch, other basis mismatch, unclamped input, nonadjacent domains, seam mismatch with its row index, control limit and invalid final output. Invalid source data returns an input error. Both inputs are borrowed and never changed. A successful merge proves no G1/G2 seam smoothness, injectivity, absence of overlapping image regions, B-rep sewing, trim preservation, material/volume or solid authority. Floating evaluator rounding may differ. Source-bound downstream certificates must be rebuilt.

The resulting C0 seam may remain necessary. If it is redundant, the existing exact surface-knot simplification pass can remove it with its own shared predicate budget and independent row/denominator proofs. Tests exercise this complete split→merge→simplify path on both axes against an independent polynomial law, a rational two-clock tensor on nonunit domains, incompatible gauges and one-ULP seam differences, invalid and incompatible bases/domains, other-axis periodic storage and the unchanged control cap. A separate Fraction Cox-de Boor polynomial oracle checks complete rational functions over each source rectangle, without importing the CAD implementation. Native-only capability; WASM, Rush, editor and exchange are not qualified by these tests.
