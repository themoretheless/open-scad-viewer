coverage fiber supplies an actual root selector, bound by native original-source
membership strictly inside a supplied edge. Ordered original supports must
match. A chart-overlap box or sampled world point cannot act as an anchor.

Each continuous unique graph fiber is connected. An admitted interior Jordan
loop is a relatively open and closed regular source-root component, so a proved
anchor puts the entire graph in that component. The original coverage forest
owns all source roots by exclusion or its source-equivalent fiber atlas. Every
fiber must have a verified anchor and every supplied loop must be owned. This
establishes exhaustiveness for the accepted original pair, without asserting
that arbitrary pairs can yet be admitted.

For each pair of supplied loop owners, one exact selector of the first is
excluded from every arc of the second with complete bounded UV4 subdivision.

duplicated contour never increases physical branch count. Failure to separate
or to anchor any graph is unresolved, not an omitted branch. Search count and
per-query geometry budgets explicitly bound this work.

Boolean admission. General singular/coincident strata, knot unions, seam/pole
loop owners, open-rim arrangements, region selection, sewing/healing, independent
