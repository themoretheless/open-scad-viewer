# Проверка G0 границ поверхностей

`nurbs_core::surface_join::inspect_g0(a, boundary_a, b, boundary_b, reverse, tolerance, max_cells)` — типизированный Rust API без codec. Проверяет полные выбранные параметрические границы валидных положительно взвешенных 3D NURBS-поверхностей с заданным аффинным соответствием нормализованного параметра [0,1]. Boundary: UMin, UMax, VMin, VMax. Домен каждой границы может отличаться, параметр второй можно обратить.

Оболочки вычисляются для фактического рационального образа исходной поверхности через `surface_distance::rectangle_bounds`, с фиксированным граничным параметром. Поэтому unclamped-представления не заменяются крайним рядом контролей. Аффинный перевод нормализованного параметра также вычисляется интервально с внешним округлением. Подразделение адаптивно сужает верхнюю границу супремума расстояния между соответствующими точками; точечные интервальные кандидаты дают нижнюю границу.

Decision::WithinTolerance — доказанное достаточное условие G0 в выбранном допуске. CorrespondenceExceedsTolerance — доказанное превышение ошибки конкретного аффинного соответствия, а не отказ геометрического G0 при любой возможной перепараметризации. Unresolved — бюджета или численной разрешимости не хватило. Нижняя граница относится к заданному соответствию; верхняя также ограничивает симметричное расстояние Хаусдорфа полных граничных образов. Не вычисляются оптимальная перепараметризация, автоматическое направление, G1/G2, blend, trim-границы или топология оболочки.

Допуск конечный неотрицательный, бюджет 1..100000 считает все созданные нормализованные интервалы. При остановке сохраняются глобальные границы. Нулевой допуск может оставаться неразрешённым даже для совпадающих границ из-за интервальной неопределённости. Неверные поверхности и арифметическое переполнение возвращают ошибку. Выбор максимальной ячейки линейный; бюджет не гарантирует время выполнения. Периодические оси рассматриваются на своих активных доменах без поиска фазы.

Три независимых теста `crates/nurbs-core/tests/surface_join.rs` прошли без default features: рациональные соседние панели с общим швом; обращённое направление и ошибочное соответствие; аналитический зазор 0.25, бюджетная остановка, неверные параметры; unclamped квадратичная поверхность, чья фактическая граница лежит при x=3, хотя крайний ряд контролей x=4, и совпадающая граница на другом параметрическом домене. Дополнительно прошли три проверки расстояний поверхности.
