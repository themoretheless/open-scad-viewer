# Смещение NURBS-поверхности по нормали

`nurbs_core::surface_offset::offset(surface,distance,tolerance)` строит приближение S(u,v)+distance*n(u,v), где n соответствует S_u×S_v. Surface и конечные distance/tolerance проверяются, tolerance>0. Нулевая distance возвращает исходный Surface без изменений и exact=true. Для ненулевой distance exact=false: распознавание plane/sphere/cylinder по сетке jets — гипотеза, не доказательство исходной формы. Ускоренные affine primitive transformations сохранены, но не выдают сертификат точности.

`OffsetReport::assurance()` различает ExactIdentity и SampledDeviation. Поле max_deviation — максимум численно оценённого отклонения на сетке исходного UV domain (не непрерывная ошибка и не rounding-inclusive certificate). Формула сравнивает both normal distance error и lateral drift, эквивалентно расстоянию между output point и исходным normal-offset target в той же UV точке. Размер каждой оси sample grid — clamp(2*control_count,4,64); это не доказательство отсутствия узких особенностей между samples. Degenerate regions/плохие normals записываются отдельно; малое max_deviation при непустых degenerate_regions не квалифицирует всю поверхность.

Общий путь смещает controls по Greville normals, при превышении tolerance пробует один knot-refinement pass, затем cloud fitting по максимум 25×25 targets с не более 8×8 controls. Ошибка fit certificate относительно конечного облака не подменяет ошибку смещения. Кандидат fit получает исходные authored UV domains и повторно измеряется против S+dn; он принимается только если sampled deviation улучшился. При недопустимом fit/parameter mapping сохраняется предыдущий кандидат. Успешный Result не означает max_deviation<=tolerance: caller должен проверить численную оценку и все предупреждения.

`offset_validity` оценивает ограничивающий principal-curvature radius на сетке с дополнительным локальным refinement. requested_ok/max_offset — sampled warnings; округление вниз sampled minimum не даёт нижней границы непрерывного minimum между samples. При принятом здесь знаке кривизны focal crossing возникает, когда distance*k>=1: для положительной distance ограничивают положительные k, для отрицательной — отрицательные. B-rep self-trimming, global injectivity, manifold/solid и постоянная толщина оболочки не создаются.

Новые независимые regressions: слегка искривлённый saddle z=1e-10*u*v, который plane recognizer принимает по sample tolerance, не получает exact=true; нулевая distance сохраняет все исходные данные; invalid inputs; общий saddle с authored U=[2,7], V=[-3,1] сохраняет domains, его reported error проверяется независимым Euclidean target S+dn на всей исходной sample grid. Исходные unit tests покрывают plane/sphere/cylinder, torus, focal/degenerate случаи и validity warnings. Проверка 2026-10-14: три integration regression groups и все 15 surface_offset unit tests прошли offline/locked, no-default-features (1263 прочих unit tests не запускались). Дополнительно прошли 11 dependent fillet tests (1268 прочих unit tests не запускались). Итого 29 профильных tests; четыре source/test файла не изменились во время прогонов (SHA-256). NURBS-0079: native в контракте приближённого surface-offset constructor с явной sampled assurance. Постоянная толщина shell/B-rep и continuous error certificate этим не квалифицированы.
