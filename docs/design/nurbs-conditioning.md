# Численные показатели рациональной геометрии

`conditioning::{curve,surface}` валидируют геометрию и возвращают Report:
weight_ratio — max(weight)/min(weight), у поверхности по всей сети;
min_relative_knot_span — минимум положительных интервалов активного
домена, делённый на его длину, отдельно для U/V;
coordinate_offset_ratio — максимум абсолютной контрольной координаты
к максимальному extent контрольного AABB; zero_extent — точечный AABB.
Для точечного AABB offset_ratio=None; у экстремально малой протяжённости
ratio может переполниться в infinity. Повторные узлы не считаются
положительными интервалами; periodic exterior knots вне активного
домена не входят в минимум.

Это непосредственные binary64 показатели масштаба данных, без
произвольной границы «хорошо/плохо». Отношение весов инвариантно к
общему множителю весов; относительные интервалы инвариантны к
положительной аффинной смене домена с точностью binary64.
Большой перенос повышает coordinate_offset_ratio без изменения
размеров детали. Эти показатели не являются числом обусловленности
всего NURBS evaluator, сертификатом ошибки, регулярности или топологии.
Валидность и допустимые веса/координаты/узлы проверяются существующими
Curve/Surface; диагностика не обходит их ограничения.

Три теста проверяют независимые ожидаемые показатели, смену домена,
общий масштаб весов, перенос, обе оси поверхности, всю сеть весов,
точечную геометрию и отказ на недопустимые веса. Все прошли нативно
с no-default-features. Адаптеры JSON/WASM/TypeScript/Rush не требуются.
