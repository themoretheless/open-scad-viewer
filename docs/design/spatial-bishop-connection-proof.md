# Spatial Bishop connection and periodic surface proof

This Rust certificate uses a fixed Cartesian unit axis A as a regular chart on the tangent sphere. Let D=C'(v), T=D/|D|, q=A·T, N=(A−qT)/sqrt(1−q²), and B=T×N. The Bishop phase satisfies

    theta' = q ((T×A)·T') / (1−q²)
           = (A·D) ((D×A)·D') / (|D| |D×A|²).

The second identity eliminates parallel acceleration before interval evaluation.       + (alpha sin(theta) + beta cos(theta)) B.
