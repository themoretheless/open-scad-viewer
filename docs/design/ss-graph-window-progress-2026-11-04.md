# Original SS graph-window membership

Implemented native exact affine window containment on sealed original SS root
carriers. A qualified window is bound to its original ordered surface pair,
owned graph and exact rational original/local coordinates. Optional whole-subarc
qualification retains the source carrier, interval and query policy and repeats
that query on re-verification. The root enclosure is never a replacement curve.
An arbitrary window proves conditional root membership, not root existence.

Nonlinear blowdown, excluded pole strata, invalid/reversed windows and windows
outside the qualified graph are refused. Periodic deck shifts are not silently
introduced. This does not prove Jordan simplicity or general Boolean admission.
