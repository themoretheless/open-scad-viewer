# Непрерывный сертификат отклонения с учётом округления

`nurbs_core::curve_surface_agreement::verify` проверяет отклонение 3D NURBS C(t) от композиции tensor NURBS S(P(t)) на всей нормализованной области 0..1. P — рациональная 2D pcurve; допускаются произвольные активные домены, multi-span definitions, reversal C, периодические оси поверхности и переходы между charts. Это композиционный сертификат границы, отличающийся от измерения отклонения двух отредактированных кривых (N184) или поверхностей (N185).

Все промежуточные arithmetic bounds outward binary64: affine domain mapping, original-curve rational hulls, original-surface chart enclosure и box distance. Correlated homogeneous Bernstein composition сохраняет общий параметр и уменьшает interval dependency; недоступная/неопределённая оптимизация заменяется консервативным interval traversal, не успехом. WithinTolerance получается только после покрытия всей области; Mismatch содержит параметр и outward distance interval, нижняя граница которого превышает tolerance. Unresolved — budget/precision/domain ambiguity, не доказательство совпадения или различия.

Вход требует валидных positive-weight NURBS, C dimension 3, P dimension 2, положительного конечного tolerance и budget 1..100_000 cells. Счётчик включает все проверенные интервалы. Bounds относятся к математическим NURBS по переданным binary64 данным и вычислениям самого verifier; неизвестная погрешность измерений и предшествующего получения этих данных не включается. Exact identity имеет отдельный verify_exact API и не смешивается с tolerance certificate. Trim simplicity, injectivity и solid validation — отдельные проверки.

Все 14 целевых тестов curve_surface_agreement прошли: рациональные независимые веса, независимые домены, multi-span определения, криволинейная поддержка, rational pcurve composition, reversal, переходы periodic seams по обеим осям и отрицательные периоды; enclosed witness для known offset, exhaustion и invalid tolerance/domain. Это проверяет полный continuous contract композиции относительно исходных авторенных определений.
