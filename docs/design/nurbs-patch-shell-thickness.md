# NURBS patch skins with declared thickness assurance

`brep_core::shell_thickness::thicken_patch` builds a closed candidate skin around one full rectangular rational Bezier patch. It preserves the original source cap exactly, adds a same-basis normal-offset approximation and four ruled sides, and checks every saved face and seam. NURBS-0080 is native within this scope; general solid shelling and certified ideal constant thickness are separate.

The typed kernel owns offset geometry. The builder first uses the normal surface-offset constructor if its result retains the exact source degrees, knot domains and positive weights. Otherwise `surface_offset::offset_preserving_basis` provides the existing Greville-normal control-net approximation and records the fallback reason. Both report sampled deviation and degeneracy/focal warnings. No sampled primitive recognition or numerical normal grants an exact ideal-thickness certificate.

The source and offset boundaries are copied by the shared B-rep boundary owner. The four side nets use these same rational controls and weights, so their exact geometric boundaries match the two caps. Full original interval regularity must succeed on all six saved surfaces. Exact owned sewing requires opposite edge uses, one cyclic vertex link and one connected closed shell. Complete independent original edge/pcurve/surface agreement is also mandatory. No incomplete geometric check returns a model.

`ConstructedSampledThickness` explicitly describes the result. `max_sampled_thickness_deviation` is sampled; `continuous_thickness_error_upper` remains None and `rounding_inclusive_thickness_certified` and `solid_geometry_certified` remain false. A combinatorially closed Body candidate is not an embedded-solid certificate. General self-intersection, material orientation and volume validity need independent admission. The requested tolerance gates the sampled offset deviation and saved seam verification; it does not turn the sampled metric into a continuous guarantee.

Inputs: one nonperiodic full single-Bezier chart per axis, degree 1..16, finite 3D controls <=1e6, nonzero signed thickness with magnitude <=1e6, tolerance 1e-10..1e-2. Positive thickness follows source orientation, negative uses the opposite side. Trims, multi-span charts, pole/seam-degenerate layouts, multiple source patches and general closed-solid face removal need other constructors. The input is immutable.

Independent shared budgets: 1..1000000 regularity cells (per-face cap 100000), 1..1000000 agreement cells and 1..1000000 exact correspondence work. The existing offset kernel retains its own bounded fitting/sampling guards. Unsupported/invalid inputs return typed errors; unresolved face regularity, offset degeneracy, insufficient sampled fit or incomplete agreement return explicit stops and no model.

Three independent tests cover signed planar thickness and numerical volume, exact original-cap retention, all six regular faces and closed owned incidence; a rational cylinder with an independent radial oracle and continuous saved seams; and a noncircular freeform chart whose too-tight sampled fit is refused. Invalid sizes, unsupported periodic input, singular source and both shared proof budgets refuse a body. Adapter/export and global ideal-thickness qualification remain separate.
