# Геодезическая исходной NURBS-поверхности

`nurbs_core::geodesic::trace_geodesic_report(surface,start_uv,direction_uv,length,max_steps)` интегрирует геодезическое уравнение в surface metric методом RK4 с сравнением полного и двух половинных шагов. Это initial-value tracing, не решение глобально кратчайшего пути между двумя точками. Направление UV нормируется по первой фундаментальной форме; предварительное деление на максимальную компоненту сохраняет результат при масштабах направления 1e300/1e-300 и исключает переполнение/обнуление квадрата направления.

Старт внутри исходного UV domain, конечная положительная length, конечное ненулевое direction и max_steps=1..4096. Слишком малая длина, чей initial step length/64 не представим, отклоняется. Учитываются исходные knots, weights и параметрические размеры. Бюджет ограничивает принятые шаги; адаптивное деление ограничено h_min=length*1e-10. На границе возвращается последний удержанный отрезок: direct rectangular clipping определяет его долю и length_achieved учитывает только эту долю последнего шага. Это приближение локального пути UV-chord, не сертифицированное интегрирование точной boundary event. Прямое отсечение сохраняет очень малые доли, которые фиксированные 64 bisections не разрешали.

Report различает LengthReached, BoundaryHit, BudgetExhausted, DegenerateMetric. При вырожденной/плохо обусловленной метрике (включая poles) интеграция прекращается; численная непредставимость также может дать typed numeric error. Полигон UV и length_achieved — результаты численной интеграции. max_residual_geodesic_curvature вычисляется не более чем на восьми локальных samples из jets/ODE; он проверяет локальную согласованность, не ограничивает накопленный drift или global endpoint error. Его малость не является геометрическим сертификатом.

На C0 knot lines first jets могут быть взяты после one-sided относительного смещения 1e-7; second jets при отсутствии заменяются конечными разностями метрики с относительным шагом 1e-6. Пересечение таких knot lines и seams не является точной топологической операцией; непрерывная global qualification отсутствует. Периодический seam автоматически не разворачивается, граница параметрического chart завершает tracing. Self-intersection, shortest path и геодезическая полнота поверхности не проверяются.

Независимые regressions: affine plane с метрикой diag(4,9), известный world straight-line endpoint для direction scales 1,1e300,1e-300; прямые и обратные boundary paths с известной длиной; очень длинный запрос с коротким boundary segment; budget, zero/nonfinite directions, length/step underflow, invalid start/budgets. Внутренние tests включают cylinder helix и sphere great circle. Проверка 2026-10-14: четыре integration regression groups и все пять существующих unit tests прошли offline/locked, no-default-features (1273 прочих unit tests не запускались). Итого 9 geodesic tests. Source/test SHA-256 не изменились во время прогона. NURBS-0029: native в контракте численного initial-value tracing с перечисленными ограничениями; это не global shortest-path или error certificate.
