# Непрерывная проверка переноса периодического шва поверхности

`periodic_seam::surface_report(source, axis, parameter, tolerance, max_cells)` переносит шов выбранной периодической оси и возвращает новую поверхность только после подтверждения непрерывной верхней границы ошибки. `verify_surface` независимо проверяет готовый кандидат. Ошибка измеряется по полному двумерному tensor-product образу, без подмены проверками отдельных рядов или сечений.

На выбранной оси используется нормализованная фаза нового домена и wrap по исходному периоду, как в `curve_report`. На другой оси параметр остаётся исходным, поэтому её естественные домены должны точно совпадать. Размеры control net, степени и веса кандидата могут отличаться: проверяются его фактические рациональные образы, а не совпадение исходных данных.

Все активные узловые прямоугольники кандидата образуют начальное полное покрытие. Интервальный образ каждого прямоугольника сравнивается с интервалами исходной поверхности на соответствующем фазовом диапазоне. Обе ветви wrap включаются, если фазовый интервал пересекает шов. Вся арифметика преобразования фазы и рационального образа учитывает внешнее binary64 округление. Refine делит наиболее неопределённый прямоугольник по относительно более широкой параметрической оси. Верхняя граница по всем живым ячейкам непрерывно ограничивает соответствующие позиции и симметричное Hausdorff-отклонение полных необрезанных образов.

Tolerance положительный конечный; max_cells 1..100000 считает все оценённые ячейки, включая заменённые родители. Если начальное покрытие не помещается в бюджет, возвращается ошибка. WorkLimit/PrecisionLimit дают accepted=false и глобальную error_upper; surface в отчёте отсутствует. Непринятие не доказывает превышение допуска. Оценка консервативна и может требовать большой бюджет. Неверные ось/периодичность/домен/допуск/бюджет и численное переполнение возвращают ошибку без изменения источника. Для построения сохраняются ограничения авторского периодического базиса и control net 32x32.

Это позиционный сертификат для выбранного соответствия. Он не доказывает сохранение топологии, регулярность, G1/G2 через шов, совпадение фаз с другими сечениями или валидность произвольных trims. Перенос trim-контуров через шов остаётся NURBS-0173. Нулевой допуск и точное binary64 равенство формы не заявлены.

Три независимых интеграционных теста используют поверхность с неразделимыми рациональными весами, самостоятельную двумерную формулу Cox–de Boor, обе оси и дробный seam=3.333. Покрыты непрерывная граница, неизменность источника, отказ для сдвига всего кандидата на 2 единицы, отсутствие поверхности при малом бюджете, начальный бюджет, непериодическая ось, разные домены другой оси, неверные допуски и лимиты. Все 11 новых и существующих seam-проверок прошли.

```sh
cargo test --manifest-path crates/Cargo.toml -p nurbs-core --no-default-features --test periodic_surface_verification --test periodic_seam_candidates --test periodic_seam --quiet
```

WASM, редактор и STEP для нового API отдельно не квалифицированы.

Полный нативный набор `cargo test --manifest-path crates/Cargo.toml -p nurbs-core --no-default-features --quiet` прошёл: 560 тестов, 0 ошибок. Это проверка текущего Rust-снимка; квалификация адаптеров отдельно не выполнялась.
