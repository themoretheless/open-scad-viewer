# Modular exact original gear profile embedding

`brep_core::gear::certify_profile_embedding` produces independently checked witnesses for the original planar profile. It supports the existing 3..256-tooth layout without raising the generic profile checker's 128-span/256-piece limits. `verify_profile_embedding` rechecks supplied witnesses against current source definitions and returns an opaque `VerifiedGearProfile` owning an immutable copy of those definitions.

Every cyclic pair of adjacent tooth groups is closed to the origin with two auxiliary radial segments. The existing exact rational profile owner verifies all original knot spans, individual injectivity and within/adjacent-group curve pairs. Nonadjacent groups have a complete lexicographic census of strict origin-line control-hull separators. Their signs are recomputed from original binary64 coordinates using exact rational arithmetic. Positive NURBS basis coefficients put the entire original curves in those hulls. Thus every original source span/pair is covered; no sampled polygon or point evaluator grants geometric authority.

Clockwise source fans and bore circles retain every original pole, knot, weight and direction. They are checked as holes of an auxiliary enclosing CCW rectangle. The reused checker independently verifies that extra rectangle and its relation to the source; it is a witness only and is absent from the returned gear profile.

Every original curve additionally has a strict positive control-hull projection away from the winding anchor. The original curve-to-endpoint-chord homotopy therefore avoids the origin. Exact endpoint-polygon winding transfers to the original curves even without assuming a simultaneous simple-polygon homotopy. Winding must be +1 for the outer wire and -1 for a hole. Positive radial gaps, original circle-wire Bernstein radius bounds and tooth control-hull radius bounds then prove nesting and cross-wire separation. Circle wires also have complete exact profile certificates. This is original-profile embedding, orientation and material-role evidence.

Proof limits: at most 257 local witnesses and 32768 far-pair witnesses. Search and independent verification each have a separate exact-sign cap, at most 20000000; failed candidate signs consume work too. Each reused local checker retains its own fixed source/span/piece/depth and arithmetic limits. Original curves have degree 1..8, at most 256 controls, clamped knots, positive weights and bounded finite planar coordinates. Auxiliary circle wires have at most 128 original curves. Missing/extra witnesses, changed source bits, false rays, insufficient limits or unresolved radial gaps refuse a verified result. No partial success returns an opaque verified object. Exact qualification is deliberately more expensive than ordinary candidate generation.

`gear_with_verified_profile` constructs all four gear families and binds their actual base model edges to the immutable verified profile, comparing original degrees, knots, weights and all saved XY poles exactly. The owned model must have one closed body candidate with zero free edges. All nominal profile and wall accuracy bounds must be available. `ProfileVerifiedGear` exposes read-only model, geometry and verified profile accessors. `solid_geometry_certified()` remains false: cap/wall embedding and complete owned-solid admission are separate qualifications.

The native milestone uses its existing criterion: a real typed Rust implementation, independent geometric checks, invalid-data refusals and declared assurance/limits. The four gear families now meet that constructor/profile criterion; they are not globally qualified solids or packaged editor/export features. Geometry remains Rust-owned. The fast `gear_with_report` candidate API remains available separately from this strict proof path.

Tests cover the default 20-tooth profile beyond 128 original spans, a bore, a 40-tooth internal ring, the 256-tooth limit, complete witness counts, interior-pole source mutation, finite false rays, zero rays and proof limits. A separate native constructor test binds spur, signed helical, mirrored herringbone and internal-ring models to their verified original profiles and checks inclusive nominal profile/wall bounds.
