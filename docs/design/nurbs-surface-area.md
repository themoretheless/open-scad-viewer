# Площадь NURBS-поверхности в нативном Rust

`surface_measure::area(&Surface, tolerance, max_cells)` возвращает площадь полного параметрического домена с нижней/верхней границами и максимальной погрешностью среднего значения. Допуск измеряется в квадрате модельных единиц. WASM, JSON, TypeScript и редактор для вызова не нужны.

## Гарантия

Измеряется интеграл `|S_u × S_v|` по всем ненулевым исходным knot rectangles. Складки и повторные покрытия учитываются с кратностью. Это не площадь объединения образов, не площадь замкнутого тела и не удаление внутренних trim-петель. Для сборки площадей нескольких граней необходимо дополнительно учитывать их топологию и перекрытия.

Из оригинального однородного контрольного net извлекается интервальное рациональное представление ограниченной ячейки, без округления новой поверхности до точечных контрольных данных. Частные и смешанные производные до суммарного третьего порядка вычисляются по формуле производной произведения `H = W*S` с outward rounding. Они относятся к локальным x/y в [0,1]^2, поэтому норма `N = S_x × S_y` уже содержит масштаб исходной параметрической ячейки.

Первая граница — интервальная норма N на всей ячейке. Если норма отделена от нуля, дополнительно применяется четырёхугловая двумерная трапециевидная формула. Для каждой оси:

```
|(|N|)''| <= |N''| + |N'|² / min |N|
```

Производные нормали вычисляются интервально из третьих и смешанных производных поверхности, например:

```
N_x  = S_xx × S_y + S_x × S_xy
N_xx = S_xxx × S_y + 2 S_xx × S_xy + S_x × S_xxy
```

Для двумерной трапециевидной формулы остаток ограничивается суммой `M_x/12 + M_y/12`: последовательно применяются одномерные операторы интеграла/трапеций с положительными весами. В вырожденной или неотделённой от нуля ячейке остаётся первая интервальная граница; регулярность не предполагается.

Интервальные границы заключают истинную площадь рационального определения, заданного записанными binary64 данными как вещественными числами. Они включают ошибку интегрирования и округления вычислений. Они не оценивают отличие этих данных от идеальной аналитической фигуры, по которой данные были построены.

## Бюджеты и отказы

- `max_cells` — 1..100000 построений интервальной ячейки; учитываются также заменённые родители и отброшенные пробные деления.
- На каждом шаге выбирается активная ячейка с наибольшим диапазоном площади. По возможности пробуются обе оси и выбирается более узкая сумма дочерних диапазонов.
- Границы суммы округляются наружу; перед возвратом активные ячейки суммируются заново.
- `within_tolerance` проверяется отдельно от возвращённого значения. WorkLimit/PrecisionLimit оставляют достоверный интервал без заявления о достигнутой точности.
- Если начальных активных knot rectangles больше бюджета, возвращается ресурсная ошибка. Некорректные поверхности/допуски, overflow и потеря положительности интервального знаменателя возвращают ошибку.
- Сохраняются ограничения Surface: не более 32x32 контрольных точек и действующие пределы степеней, узлов, координат и кондиционирования весов. Тонкие, высокостепенные и плохо обусловленные ячейки могут потребовать большого бюджета либо закончиться численным отказом.

## Независимые проверки

8 интеграционных тестов `tests/surface_measure.rs` прошли без default features. Проверены:

- наклонная плоская панель с аналитической площадью 14, неединичными доменами и изменениями ориентации;
- боковая поверхность цилиндра радиуса 2/высоты 3 с площадью 12π;
- параболическая экструзия с замкнутой формулой площади;
- рациональный плоский прямоугольник с неравными весами и площадью 12;
- складка с параметрической площадью 2 и площадью образа 1;
- конус с вырожденной вершиной, нулевая поверхность;
- исчерпание бюджета и некорректные запросы.

Дополнительно 2 unit-теста проверяют смешанные/третьи интервальные производные и производные на углах по независимым полиномиальным и рациональным формулам. Первоначальная простая интервальная сумма не достигла требуемых допусков на цилиндре и рациональном прямоугольнике. После добавления доказанного остатка трапециевидной формулы оба теста прошли при прежних допусках и бюджетах.

Команды:

```
cargo test --manifest-path crates/Cargo.toml -p nurbs-core --no-default-features --test surface_measure --quiet
cargo test --manifest-path crates/Cargo.toml -p nurbs-core --no-default-features surface_measure --quiet
cargo run --manifest-path crates/Cargo.toml -p nurbs-core --no-default-features --example surface_measure
```
