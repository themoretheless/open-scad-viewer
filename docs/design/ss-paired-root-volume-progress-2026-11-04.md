# Independent paired-root volume and closed material ownership

Native `volume_bounds` integrates original `surface_flux` on the actual selected
root-only face domains, using new shell face uses and original UV clocks.
A complete conservative enclosure of each outer root loop bounds its entire
Jordan disk. All selected boundary arcs are enclosed with an explicit band-query
allowance; an incomplete band cannot authorize root-free cells.

A closed UV rectangle disjoint from that COMPLETE band is boundary-free.
Native original winding qualifies seed signatures. Classification propagates
only through intersecting/touching closed boundary-free rectangles on the SAME
support. Parent indices record those propagation links. A midpoint without
this separation/connectedness proof never authorizes a mask.

Inside cells use full original flux integral, outside cells zero. Unknown cells
keep the full pointwise density times [0,1] trim mask and original UV area.
A full signed integral times [0,1] would be unsound for sign-changing density.
Priority refinement updates an interval summation tree. If a sibling evaluation
fails, the complete old parent bound stays in the total. Cells, original spans,
band queries, native winding attempts, seeds and propagation counts are explicit.
Geometry allowances are per enclosure/query; global query counts bound them.
Fixed bands can impose an accuracy floor; work exhaustion remains unproved.

`admit_material` recomputes volume from the immutable source-qualified embedded
boundary. Requested accuracy and a signed interval excluding zero are required.
Negative signed flux flips ALL shell face uses. `QualifiedPairedRootSolid` owns
the resulting outward mixed topology, positive volume enclosure, original signed
proof and replay policy. No caller scalar or input-body volume can grant this
owner. The original boundary object retains `material_admitted() == false`;
the separately qualified solid owns the material proof.

The positive cases are inner genus-zero and annular genus-one quartic lenses,
with analytic reference volumes independent of the algorithm. Original U
reflection must preserve positive volume and select the same global physical
outward orientation. Zero band work and failed-child work cannot grant material.
The latter regression compares a two-cell parent sum with a three-cell attempt
whose second child cannot run, and checks it still encloses the full volume.

The default target is 1e-4 with 16,384 cells and 32,768 source-span allowance.
The prior 8,192-cell default stopped at width 0.0001555 on the annulus and was
correctly refused; the accuracy criterion was not relaxed.

This admits ONE paired root-only closed shell. General mixed models with authored
rims/holes, arbitrary face counts, all-face-pair coverage, open-rim splitting,
singular/coincident strata, seams/poles, nested cavity shells, healing, complete
lineage and bridge/WASM delivery remain in the full original goal. This owner
is not a general Boolean-result certificate or a legacy fitted-Curve conversion.

Measured positive evidence: annular signed flux bounds with the default 1e-4
target are [0.007361217983925333, 0.007461213243135177], using 10,690 cells,
2,048 original band queries, 14 native winding queries and 5,272 proved
classification propagations. The inner lens initially has negative signed
bounds and its material owner reverses the complete shell. Both reference
volumes lie inside the independently computed intervals. Frozen logs retain
all mirrored/nonmirrored reports and replay outcomes.
