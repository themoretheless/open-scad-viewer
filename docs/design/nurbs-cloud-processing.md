# Обработка облаков перед восстановлением NURBS

NURBS-0211–0213 — три разных контракта Rust:

| ID | API в `nurbs_core::analysis` | Результат |
| --- | --- | --- |
| 0211 | `ransac_primitives::detect_primitives` | Найденные модели с параметрами, исходными индексами инлаеров и RMS |
| 0212 | `cloud_normals::orient_normals_consistent` | Согласованные направления заданных нормалей, число переворотов и компонент графа |
| 0213 | `cloud_segmentation::segment_cloud` | Регионы исходных индексов, средние нормали и приближённый тип |

Алгоритмы уже существовали. Этот этап исправляет численные/граничные ошибки,
проверяет публичный API и добавляет индивидуальные записи в каталог.
Четыре вида RANSAC-моделей не считаются четырьмя дополнительными возможностями.

## Общие входы

Не более 65536 конечных 3D-точек. Исходные массивы не изменяются, индексы
относятся к их первоначальному порядку. Длины и допуски используют единицы
исходных координат; единицы и преобразование в NURBS не добавляются.
Геометрические метрики выборочные, без сертификата непрерывной ошибки,
полноты реконструкции или допустимости B-rep.

## RANSAC

Вход непустой. Настройки задают положительный конечный порог, минимальное
число инлаеров, число итераций, максимум моделей, долю раннего выхода в [0,1],
seed и включённые виды. Поддерживаются плоскость, сфера, круговые цилиндр и
конус; хотя бы один вид должен быть включён. Малое облако может не содержать
минимальной выборки/нужного числа инлаеров и дать пустой результат.

Итерационный бюджет применяется к виду модели, бюджет раундов — к извлечению
моделей. Число итераций задаёт вызывающий код; единого ограничения числа всех
арифметических операций и гарантированного wall-clock deadline здесь нет.
После выбора кандидата используется least-squares уточнение. При неудаче
уточнения возможен грубый кандидат; глобальная оптимальность не заявлена.
Если уточнение теряет необходимую поддержку, алгоритм может пропустить
грубые инлаеры при дальнейшем поиске. Поэтому найденные модели не означают
полного разбиения исходного облака. Исходные точки остаются у вызывающей стороны.

Инлаеры возвращённых моделей не пересекаются. RMS относится к ним, а не ко
всем точкам и не к непрерывной поверхности. Конус использует одну
ориентированную полость. Дополнительные конечные нормали должны соответствовать
точкам; для цилиндрических гипотез направления нормализуются устойчиво.
Нулевая/слишком малая нормаль не даёт цилиндрической гипотезы, но может
не мешать другим включённым видам. Сходимость поиска не гарантирована;
фиксированный seed задаёт последовательность выборок, без обещания
побитового совпадения всех вычислений между платформами.

## Ориентация нормалей

Минимум одна точка; число заданных нормалей совпадает с числом точек.
Нормали конечны, их длина больше 1e-12. Нормализация через масштабирование
сохраняет направление даже при компонентах порядка `f64::MAX`, не превращая
его в нулевой вектор из-за переполнения суммы квадратов.

Используется симметризованное объединение k-соседства (k <= 12), остовный лес
и распространение знаков. Это не пересечение взаимных kNN-списков. Число
компонент относится к полученному графу, а не к доказанной топологии поверхности.
Общий знак выбирается эвристикой относительно центроида компоненты; результат
не сертифицирует внешнюю сторону произвольного тела. На плоскости или
вырожденной выборке общий знак может оставаться неоднозначным.

Сетка использует насыщаемые целочисленные ключи. Непредставимые соседние
ячейки пропускаются проверяемым сложением, исключая panic при большом общем
сдвиге совпадающих точек. Коллизии ключей могут ухудшать производительность;
радиус фильтруется по исходным расстояниям. Переполнение масштаба индекса
или другие численные вырождения могут дать ошибку. Это не сертификат точного kNN.

## Сегментация

Минимум четыре точки и столько же конечных ненулевых нормалей с длиной >1e-12.
Угол в радианах лежит в (0,pi), порог кривизны положительный и конечный,
минимальный размер региона >=1, число соседей >=3 (фактически ограничено n-1).
Нормали желательно заранее согласовать по знаку.

Граница может быть принята в регион без продолжения роста через неё.
Средняя нормаль теперь учитывает **всех принятых членов** региона, включая
такие границы. Если среднее направление вырождено, поле может быть нулевым.
Регионы меньше минимального размера не возвращаются; возвращённые индексы
не пересекаются, но не обязаны покрывать все точки.

`Planar` определяется выборочным fit плоскости с RMS/размером региона <0.01;
`Unknown` используется для маленьких регионов. Это эвристика, а не точное
распознавание аффинного носителя из NURBS-0205.

включая все четыре RANSAC-модели, выбросы, исходные индексы, масштаб нормалей,
целочисленное переполнение ячеек, среднюю нормаль по полному региону и отказы
для неверных входов/превышения лимита. Вместе с предыдущими контрактами:
**34 passed, 0 failed, 0 ignored**. Библиотека проходит проверку без default features.
