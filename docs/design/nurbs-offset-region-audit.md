# Границы заполненного региона представленных хорд

`chord_fill_selection::boundaries` объединяет выбранные грани представленного плоского графа: удаляет внутренние рёбра между заполненными гранями и обходит оставшиеся направленные границы. `boundary_curves` материализует каждую границу отдельной замкнутой цепочкой degree-one NURBS-кривых. Правила NonZero и EvenOdd сохраняют кратность исходных обходов. Эти API уже существуют в ядре; новый дублирующий модуль не требуется.

Независимые интеграционные проверки в `crates/nurbs-core/tests/chord_region.rs` подтверждают объединение двух областей с общим ребром (площадь 20, периметр 20), два треугольных компонента пересечённого контура (суммарная площадь 8), различие NonZero/EvenOdd для двойного обхода квадрата, соединение и замыкание материализованных кривых и отказ при нулевом бюджете. Все 3 теста прошли без default features; также прошли 10 существующих тестов `chord_fill_selection::tests`.

Это доказательства для представленного графа хорд. Непрерывная граница позиционной ошибки аппроксимации сама по себе не доказывает сохранение топологии исходного NURBS-offset: близкие ветви, касания и совпадения могут изменить число областей. До доказательства переноса топологии и end-to-end контракта пункт NURBS-0188 остаётся planned. При сомнительной топологии результат должен явно сообщать unresolved, а не выдавать очистку ломаной за гарантированную очистку исходного offset.

Команды проверки:

```sh
cargo test --manifest-path crates/Cargo.toml -p nurbs-core --no-default-features --test chord_region --quiet
cargo test --manifest-path crates/Cargo.toml -p nurbs-core --no-default-features --lib chord_fill_selection::tests --quiet
```
