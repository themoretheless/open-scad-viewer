# Complete root relations and an admitted shell forest

`QualifiedPairedRootSolid::qualify_relation` proves both directed original
boundary covers before returning Disjoint, FirstInsideSecond or
SecondInsideFirst. A source-owned exact root selector supplies a signature
only after its entire native world enclosure has a target material proof.
Every retained source boundary point must subsequently have that same signature
in a whole-original-surface-image material certificate. Every natural source
span intersects the complete outer Jordan enclosure; unresolved cells subdivide
breadth first and only whole-cell source-domain exclusion can discard a cell.
Contact, incomplete coverage, inconsistent signatures or insufficient work
cannot construct the immutable relation. A seed alone never grants containment.
The reverse cover rules out hidden enclosed target boundaries and cavities.

`QualifiedRootShellForest::qualify` consumes 2..64 admitted paired root owners
and exactly one sealed relation for every unordered source pair. Relations must
refer to those exact immutable owners. Duplicate/foreign/missing pairs are
rejected. The containment matrix must be strict and transitively consistent;
each node must have a unique immediate container. Depth determines alternating
material: even-depth shells own bodies, their immediate odd children are
cavities, and deeper even shells are material islands. This is even/odd material
(XOR of the finite root regions), not union semantics for nested input solids.

All source topology transfers through snapshot-bound maps. Cavity shell uses
reverse together, body ownership is rebuilt explicitly, and source maps retain
body ancestry and operation-relative shell orientation. Original root curves,
selectors, UV clocks and world-edge bindings remain intact. Final mixed
bindings/topology are validated. Independent original root-volume enclosures
are combined with outward interval arithmetic and alternating signs; a positive
result within the caller's absolute error is required. Caller flags or scalar
volumes cannot create this material owner. Point membership evaluates the same
root-region parity. Replay freshly verifies each root once, replays every pair
cover, then rebuilds nesting, volume and lineage.

Coverage cells/domain queries are shared per directed cover. Target material
attempts have their own declared per-query budgets; complete source band/winding
work is shared across the source cover. The source-geometry seed has its own
original curve enclosure allowance. Total target work is bounded by the number
of cover cells times the explicit target policy. Forest construction reuses
immutable relation proofs and adds no unproved geometry decisions.

Root world-box separation now explores breadth first and can reject immediately
when a whole retained original face patch lies in the query box. The UV domain
must first be certified Inside; an untrimmed support patch in a hole is not
contact authority. This detects actual obstruction and avoids following one
trim-boundary chain to the precision limit while other useful cells wait.

admitted smaller interior lens and a separate translated lens. All original

The full goal still includes arbitrary intersecting/singular/coincident SS
strata, periodic/pole material, full finite-face trim and cross-source rims,
general mixed legacy/root shell inputs and touching/healing, intersecting
Boolean operations, split-edge lineage and persistent history, actual
bridge/WASM calls, and the separate quad/offset/fillet/G2 parity audit. This
forest operates on already admitted paired root shells; it does not grant
missing source-intersection or trim proofs.
