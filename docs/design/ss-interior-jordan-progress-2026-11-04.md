## Topological argument used by the admission

The image of every edge is a continuous injective graph in original UV4.
Interior graph membership supplies an open source-root neighborhood about each
point. The proved opposite order at each joint provides both sides of that
neighborhood and excludes reversal. The compact connected wire image is
therefore a connected compact one-dimensional manifold without boundary, hence
a circle. Distinct root parameters cannot project to the same first UV point:
first surface evaluation gives the same world point, and injectivity of the
second support forces identical second UV too. The same argument applies with
roles exchanged. Each UV image is consequently an embedded circle.

The traversal is a local homeomorphism from its parameter circle onto that
image and hence a finite covering. Its winding at either admitted seed is the
signed covering degree times the embedded circle winding (zero or plus/minus
one). Unit winding proves degree one. This excludes multiple traversal, while
local joint proofs separately exclude net-unit forward/backtracking walks.
