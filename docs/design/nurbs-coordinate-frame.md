# Координатная нормализация и единицы в Rust

`coordinate_frame::Frame::from_bounds(&Bounds)` принимает упорядоченный
конечный 2D/3D box, переносит начало в его центр и выбирает scale=2/extent,
где extent — максимальная протяжённость. Нулевая протяжённость использует
scale=1. Переполнение протяжённости или масштаба отклоняется.
Для геометрии box получают через проверяющие Curve::bounds/Surface::bounds.

`coordinate_frame::{curve,surface}(source, frame, to_world)` возвращают
новую геометрию, меняя только координаты контролов. to_world=false:
local=(world-origin)*scale; true: world=local/scale+origin.
Вычитание origin выполняется перед умножением, без большой матричной
константы переноса. Требуются конечное начало соответствующей размерности
и положительный конечный scale. Исходная и выходная геометрия валидируются;
действуют её ограничения координат, весов и периодического хранения.
2D-кривые поддерживаются; поверхности остаются 3D.

`scale_curve(source,factor)` и `scale_surface(source,factor)` переводят
единицы положительным конечным множителем относительно мирового нуля.
Например, factor=1000 переводит метры в миллиметры. Метаданные единиц
автоматически не угадываются и допуски вызывающего кода не изменяются.

Все операции сохраняют веса, степени, узлы, флаги periodic, исходник
при ошибке не меняется. Точная рациональная геометрия преобразуется
аффинно; binary64 округляет контролы. Полное побитовое восстановление
для любых исходников, непрерывный сертификат ошибки и автоматическое
исправление обусловленности не обещаются. Чрезмерный масштаб может
превысить численные пределы, а слишком малый — схлопнуть геометрию;
валидность NURBS не доказывает сохранение топологии или регулярности.

Три теста проверяют независимую рациональную формулу 2D-кривой,
контрольное восстановление, билинейную поверхность, перевод m/mm,
точечную коробку, масштаб 1e-110 и недопустимые рамки/масштабы.
Все три прошли с no-default-features. API нативный.
