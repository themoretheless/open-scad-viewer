# Непрерывная проверка переноса периодического шва кривой

`periodic_seam::curve_report(source, parameter, tolerance, max_cells)` строит периодический кандидат, затем проверяет непрерывную верхнюю границу его отклонения. `curve` в результате присутствует только при verification.accepted=true. Неподтверждённый результат не выдаётся как выполненное редактирование; исходник не меняется. `verify_curve` позволяет независимо проверить существующий периодический кандидат, включая кандидат с изменёнными контролами.

Сопоставление параметров определено явно: для нового домена [start,end] сравнивается C_new(t) с C_old(wrap(start + ((t−start)/(end−start))·old_period)). Это соответствие покрывает полный старый период даже тогда, когда округлённый новый endpoint не сохраняет его точную длину. Wrap делается относительно естественного исходного домена; пересекающий его конец интервал разделяется на обе ветви, с включением граничных пределов.

Деление, сдвиг фазы, исходная длина периода и оценки рациональных кривых вычисляются интервально с внешним округлением. Каждый параметрический интервал ограничивает образ исходника и фактически построенного кандидата; верхняя граница расстояния между боксами ограничивает все соответствующие точки этого интервала. Refinement делит наибольшую границу ошибки. Принятие требует максимальную границу по всему новому домену не выше допуска. Оно также даёт достаточную верхнюю границу симметричного Hausdorff-отклонения для полного периода. Это не оптимальное соответствие, не доказательство сохранения топологии и не доказательство равенства формы при нулевом допуске.

Допуск положительный конечный; бюджет 1..100000 считает все оценённые ячейки, включая заменённые родители. Все исходные активные пролёты кандидата должны помещаться в начальный бюджет. WorkLimit/PrecisionLimit сохраняют глобальную error_upper и accepted=false; непринятие не доказывает превышение допуска. Потеря параметрической корреляции делает оценки консервативными. Некорректные входы, стороны домена, размерность, непериодические данные, нарушение численных ограничений и переполнение возвращают ошибку. Для построения сохраняются ограничения curve_candidate на авторские повторы узлов и 256 контролов.

Независимые проверки покрывают произвольные дробные швы, степени 1–3, неравномерные и повторные узлы, рациональные веса, формулу Cox–de Boor, непрерывную фазовую границу, обязательное отклонение сдвинутой на 2 единицы кривой, малый бюджет, неверные допуски/размер бюджета и отсутствие результата при неподтверждённом допуске. Это завершает нативный контракт NURBS-0135. Проверка полного tensor-product образа поверхности выполняется отдельным `surface_report` для NURBS-0148 (см. `nurbs-periodic-surface-verification.md`): сертификаты отдельных параметрических кривых не подменяют её.

```sh
cargo test --manifest-path crates/Cargo.toml -p nurbs-core --no-default-features --test periodic_seam_candidates --test periodic_seam --test curve_deviation --quiet
```

Все 12 целевых и регрессионных проверок прошли (5 seam candidates, 3 existing seam, 4 curve deviation). WASM и редактор для нового API отдельно не квалифицированы.

`verify_curve` также поддерживает точно замкнутые clamped-кривые, где крайние узлы имеют кратность degree+1 и первые/последние контролы совпадают. Это используется в `section_phase::align`; `curve_report` сохраняет исходный контракт периодического построения.
