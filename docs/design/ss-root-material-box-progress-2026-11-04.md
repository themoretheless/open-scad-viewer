# Uniform material in original root-solid enclosures

`QualifiedPairedRootSolid::qualify_material_box` builds an immutable proof for
EVERY point of a closed Cartesian box. A native parity witness is used only
after a complete original retained-boundary separation forest is exhausted.
The connected box cannot change material without intersecting that boundary.

All original nonempty knot spans are intersected with the qualified outer
Jordan disk enclosure on each support. These roots cover every retained face.
Each cell is discarded only when its complete original surface interval image
is strictly disjoint from the world box, or its entire UV rectangle is proved
outside the selected root-trim domain. Remaining cells split with a shared
cell budget and explicit representability/depth gates. An unfinished forest,
contact, missing root bands or unresolved witness cannot create an owner.
Native whole-box winding now refuses immediately when a complete original
endpoint selector enclosure is contained in the query: actual boundary contact
is already certain, so subdivision cannot establish separation. This preserves
the geometric proof condition and avoids wasting the entire segment allowance.

The separation forest has its own cell/domain allowances. Band/winding work
is shared across that forest; witness parity has a separate explicit policy.

The owner retains the immutable admitted source solid, complete closed bounds,
witness, material parity, directions and work policy. Replay freshly verifies
the source solid and recomputes the full enclosure proof. A caller-provided
inside flag, distance or volume cannot construct this certificate.

Tests exercise inner and annular quartic solids, original U reflection, a box
inside material, a box through the untrimmed support in the actual central hole,
actual boundary crossing, and insufficient work. Enclosure replay replaces an
existing source-solid replay, retaining its full source/census/volume checks.

This prepares material selection for mixed Boolean and shell nesting. It does
not itself assemble cavities: complete boundary-to-boundary separation and
nesting coverage still need to be established. The full goal also retains
general SS singular/coincident strata, periodic/pole arrangements, finite-face
trim/rim stitching, all-face-pair coverage, healing, general Boolean, lineage,
and actual bridge/WASM delivery.

The next assembly gate must cover every retained boundary patch of each shell
by certified material enclosures against the other shell. A single classified
vertex or witness does not establish boundary-to-boundary separation. Only
complete consistent directed material signatures may establish containment
and authorize shell-forest depth, cavity orientation and material-volume sums.
