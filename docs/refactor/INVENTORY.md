# Инвентаризация кодовой базы

Дата среза: 2026-11-10, рабочее дерево на коммите `453710cff`. Все числа получены инструментами из `tools/refactor-audit` и воспроизводимы одной командой (см. `tools/refactor-audit/README.md`).

Что измерено:

- Rust: каждый из 4541 файлов `.rs` разобран `syn`, построено дерево модулей каждой цели Cargo, измерена каждая из 36724 функций (длина, параметры, цикломатическая и когнитивная сложность, вложенность, `unwrap`/`expect`/`panic`, клонирования, аллокации в циклах, `unsafe`).
- TypeScript и Svet: 2282 файлов, 16169 функций, граф импортов с динамическими импортами и воркерами.
- Дубли: точные клоны по нормализованным строкам; функции, совпадающие текстуально; файлы вне дерева модулей.
- История: число коммитов по каждому файлу за 60 дней.

Чего здесь нет: качественного чтения каждого из 21581 продакшен-методов глазами. Это 828 тыс. строк, такой проход не помещается в одну сессию. Вместо него каждая функция измерена, а разбор по чеклисту идёт в порядке приоритета (см. `PLAN.md`).
