## Rust implementation

This supports inverse rational functions not expressible by the former independently prescribed constant/linear coordinate charts. An exact univariate Euclidean algorithm cancels common numerator/denominator factors, including removable endpoint factors. Genuine poles remain poles.

Every attempted chart, cancellation and identity shares the same existing exact-work ledger. The public native `nurbs_surface_seam_audit` takes no authored `parameterMap`; it reports exact local seam evidence, never a global body or Solid certificate. ## Scope and refusals

Automatic discovery is bounded to the searched linear/quadratic homogeneous inverse charts, ordered local chart coverage and existing exact arithmetic budgets. General source-knot crossings that need additional chart decomposition remain outside this result. It is not a universal rational-curve inversion algorithm. Reversed covering, altered original coefficients/weights, missing proof work, curvature jumps and genuine poles retain their applicable refusals. A local seam certificate does not supply original global validity.

The new direct global class covers correlated translations of a moving affine axis. It does not certify every possible source motion or trimmed material. The diagnostic center shift -0.875 is valid over the material's radial profile but causes the larger carrier rectangle [0.75,5.25] to cross the rotation axis. The existing whole-carrier atlas correctly leaves that proof unresolved (`ideal-volume-atlas-precision-limit`); its failed log is retained. The positive complete-body fixture uses shift -0.5, whose entire carrier remains away from the axis. This changes the fixture, never the acceptance rule, tolerance, or resource limit. A separate lower-level case with carrier [1,5] proves shift -0.875 directly, and genuinely folded and double-covered originals remain refused.

No browser, UI/focus interaction, WASM publication, Git cleanup or peer-source modification is part of this run. Native STEP round trips do not replace independent external OpenCascade or a full public UI/STEP matrix. Failed attempts and frozen source inputs are retained.
