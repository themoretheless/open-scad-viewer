It does not measure the rounded fitted/constructed curve. Coefficientwise side ordering is a sufficient conservative admission, not a general sign solver.

Resource limits, collapsed/crossed/unsupported side order and unrepresentable area are refused. A budget of the reported work succeeds; one less refuses.
