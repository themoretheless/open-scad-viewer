# Exact whole-pole tangent-plane limits

This Rust milestone proves uniform limiting normal LINES on complete collapsed
original Bezier boundaries. It is not a quotient-regularity or G2 certificate.

The exact predicate compares every leading Bernstein normal coefficient with
one original coefficient using expansion arithmetic. No rounded normal candidate
or endpoint-direction agreement substitutes for this identity. First nonzero
normal rows are found from exact signs, all removed powers are proved zero, and
one component of the leading normal field must stay uniformly away from zero.
Continuity on the compact boundary then gives the same limiting plane along
all chart approaches to the collapsed point.

U/V minima/maxima, different vanishing orders and positive rational weights use
exact coefficient index permutations. The legacy public U-squared factor
certificate keeps its distinct type and recipe; a general plane-limit token
cannot be passed off as a regular normal, a quadratic chord certificate or G2.

The BRep binding accepts an actual privately admitted collapsed restriction.
The body binding recomputes every pole proof, checks coverage of EVERY incident
face at each owned pole vertex, and freshly proves exact cross-chart plane
agreement at that same point. One exact-work budget spans all pole and fan
checks. Failed identities, incomplete fans and one-short budgets return no
partial certificate. Original surfaces, root restrictions and topology remain
unchanged.

Native checks include independent rational sources, all four boundary axes,
vanishing orders 1/3/5, affine non-axis-aligned planes, different pole charts,
source provenance, exact-work exhaustion, and a counterexample whose two
meridian endpoint normals agree while interior limiting planes differ.
`verification.json` records completed tests and source-bound logs.

## Full goal still open

Unique tangent-plane limits alone do NOT establish regular quotient graph
neighborhoods, finite/common curvature at poles, G2 vertex strata, or complete
ideal loft/sweep guarantees. The ordinary seam collection still explicitly
refuses collapsed poles. The new token does not bypass that refusal or global
embedding/regularity/topology gates. Single clamped positive-weight Bezier chart
and finite arithmetic/work hypotheses are explicit; unsupported layouts refuse.
The full frame/cap/closed-seam matrix, WASM/browser/STEP delivery and complete
semantic G1 release qualification are not closed by this finite native receipt.
