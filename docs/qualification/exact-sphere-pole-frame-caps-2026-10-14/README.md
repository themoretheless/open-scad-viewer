# Exact sphere, owned pole charts and frame/cap qualification

Rust now supplies `brep_core::analytic::sphere_exact(radius)` and the JSON operation `brep_nurbs_sphere_exact`. A radius with a binary significand divisible by 3 admits the existing regular stereographic layout with exact thirds. Other radii, including 2, use eight exact tensor-product spherical patches with explicitly authored collapsed pole edges and weights 1, 2 and 4. No tolerance accepts a different boundary polynomial.

The legacy `analytic::sphere` / `brep_nurbs_sphere` remains the stereographic layout expected by existing intersection UV routines. It does **not** acquire an exact-boundary guarantee for rounded radius/3 coefficients. A direct replacement was tested and rejected because those routines are layout-specific. The new pole layout is deliberately not falsely recognized as stereographic. Porting arbitrary intersection UV lifts to that layout remains separate work.

Face injectivity gains a bounded polar blow-up alternative with shared work accounting and explicit pole ownership. Supporting-plane contacts permit a collapsed edge only at an endpoint of the exact owned shared edge; additional zero corners or zero edges do not pass. Whole-boundary regularity exposes ordinary `all_faces_regular` separately from `all_faces_regular_modulo_poles`. A collapsed Jacobian is never called nonzero, and pole quotient regularity is not a G1/G2 assertion. Zero work and a budget one cell below the completed proof refuse the joint result.

`brep_sweep_volume_audit` returns the independently recomputed joint result in `regularBoundarySolidCertified`. Its pole diagnostics identify the actual face, edge and vertex; caller certificate flags confer no authority. The embedding diagnostic uses the same native injectivity decision for its unresolved-face list.

The finite frame/cap Cartesian matrix contains **192 cells**, all with explicit expectations: six frame modes (`fixed`, `rmf`, `authored`, `fixed_normal`, `corrected_frenet`, `frenet`), guide on/off, affine laws on/off, parameter/arc-length spacing, endpoint correction on/off, and solid/annular profiles with unequal rational weights. There are 144 positive certificates and 48 typed refusals: incompatible fixed/authored guides and zero-curvature unguided Frenet. This matrix uses straight source trajectories; the existing full Rust suites supply the additional curved, moving-frame, corrected-cap, closed and spatial cases. It is not an assertion about every possible freeform input.

The matrix reproduced a conservative `FixedNormal + arc_length` line error. The source-owned exact normalized-length image of a two-pole line is now used consistently for both value and trajectory proofs, including unequal source weights. Curved paths retain their original enclosure path. Original endpoint displacements and required cell work remain charged; a Bezier profile legitimately consumes zero decomposition products.

Production WASM and G1 v96 are historical artifacts tied to their frozen source. A WASM target check is compilation evidence, not a rebuilt or browser-qualified artifact. See report.json and the preserved terminal logs for exact validation status.
