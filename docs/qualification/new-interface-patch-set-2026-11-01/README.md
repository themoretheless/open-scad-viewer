# Пакетная сшивка с новыми внутренними интерфейсами — 2026-11-01

Добавлен `region_replacement::sew_g2_patch_set`. В отличие от последовательной замены по уже существующим рёбрам, он может создать новые рёбра и центральные вершины между несколькими новыми патчами, одновременно заменяя одну связную подготовленную область исходного B-rep.

## Обязательные условия

Внешний обод совпадает с границей удаляемой исходной области по индексам и ориентированным топологическим использованиям. Каждый внутренний интерфейс имеет два противоположных использования двумя различными патчами. Новые сущности задаются явно; сопоставления по близости координат нет. Вся сеть связна, неиспользованные новые сущности запрещены.

Сохранённые исходные поверхности не меняются. Новые именованные роли выводятся из ключа операции, исходных идентичностей и порядкового номера роли. Карты исходных сущностей доступны только для чтения. Отношение многих исходных секторов к многим патчам записывается через отдельные merge/split-отношения. Локальные допуски и отметки сшивки переносятся при назначении новых идентичностей.

Публикация результата требует свежих проверок конечной модели: допустимые trim-области, непрерывная C0-замкнутость, G2 всех рёбер новых патчей (включая каждый новый внутренний шов), регулярная инъективность каждого патча и главная кривизна всех сохранённых граней ≤10 мм⁻¹. Позиционный допуск — исходный, normal=1e-5, tensor=1e-4. Численные счётчики ограничены общей заявленной квотой. Кандидат на промежуточной стадии не выдаётся.

## Квалификация

- Два патча с новым общим диагональным ребром вместо прежнего исходного интерфейса.
- Шесть патчей вокруг новой общей вершины после общего разбиения внешнего исходного ребра.
- Неправильное направление, лишние/неиспользованные рёбра или вершины и исчерпанная квота.
- Позиционно замкнутая сеть с изломом поперечных производных на новом шве: C0 не разрешает выдачу G2-результата.
- Сохранение исходных идентичностей и сериализация/перезагрузка конечной модели.

## Граница этапа

API принимает подготовленную исходную область и заданную геометрию патчей/интерфейсов. Автоматическая генерация контактных ветвей и углов из исходных рёбер остаётся отдельной задачей. Контрольный шестилучевой узел проверяет общую сборку на одной NURBS-опоре; он не доказывает построение произвольного пространственного угла с шестью независимыми радиусами.

Используется достаточный C2-базисный критерий на внутренних узлах поверхностей. Геометрически G2-случаи с недостаточным параметрическим базисным критерием требуют отдельного доказательства и пока отклоняются. Замкнутость и локальные G2/кривизна не заменяют глобальную проверку самопересечений, толщины, радиусного закона и материального вложения. WASM/worker/UI на этом этапе не изменяются.

Проверка сохранности документа использует отдельное корректное второе B-rep-тело: вершины и рёбра без топологических использований не являются допустимым исходником данного ядра.
