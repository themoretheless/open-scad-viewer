# Корневые концы → обрезка исходных граней → сшивка → G2 и кривизна

Добавлен `region_replacement::trim_and_replace_contacts_g2`. Внутри одного вызова исходные NURBS-поверхности обрезаются по заданным контактам, выбранные секторы удаляются, переход сшивается через общие топологические рёбра. Затем проверяются фактические сохранённые швы и все обрезанные грани.

Результат `QualifiedContactBody` выдаётся только при подтверждённой C0-замкнутости, полном позиционном/G2-соответствии каждого явно выбранного гладкого контакта и абсолютной главной кривизне каждой сохранённой грани ≤10 мм⁻¹. Доступ к модели и отчётам только для чтения; внешние флаги, остатки подгонки и ранее сохранённые свидетельства не дают допуска.

Работа обрезки, сшивки, швов и кривизны расходует общие ограниченные счётчики cells/exact/domain/shape. При отказе или исчерпании бюджета кандидат остаётся внутренним; исходный документ не изменяется.

## Область

Контактные кривые, pcurve и удаляемая сторона заданы явно. Это не автоматический генератор произвольного B-rep-скругления. G2 квалифицируется на выбранных гладких контактах с позиционным допуском исходного документа, normal=1e-5 и tensor=1e-4; исходные острые и торцевые кромки не объявляются G2. Толщина, закон радиуса, материальное вложение и общий поиск самопересечений не следуют из этого свидетельства.

## Регрессии

- Свежая изоляция четырёх корней исходных рёбер → общие вершины → обрезка рациональных исходных граней → сшивка перехода → полные проверки швов и кривизны.
- Сохранность всех исходных поверхностей и неизменность источника.
- Исчерпание бюджета, отсутствие гладких контактов и ошибочно заявленный гладким острый торец не дают результата.
- Точное уменьшение той же геометрии в 1024 раза сохраняет сопряжённость, но нарушает предел кривизны; замкнутость не разрешает выдачу такого тела.

## Измеренный положительный результат

Контрольный рациональный источник после свежей привязки корней, обрезки и сшивки: **7 граней, 15 рёбер, 10 вершин; два полных G2-шва**. Верхняя оценка абсолютной главной кривизны всех сохранённых граней: **9.943636083130052 мм⁻¹**. Это консервативная граница именно контрольной детали, а не универсальная оценка произвольных тел.

Общие затраты положительной цепочки: `33431 cells`, `54756 exact work`, `1899 domain cells`, `256 shape cells`. Все шесть исходных определений поверхностей сохранены, меняются их trim-области. Тест заведомо чрезмерной кривизны и отказы для острого торца, отсутствующей G2-области и малого бюджета прошли.

`native-tests.log` содержит полный протокол, `result.json` — код завершения и проверку неизменности квалифицируемых исходников, `source-hashes.json` — их SHA-256.


Итог: **11 тестов прошли, 0 сбоев, 0 пропусков**; код завершения 0. Хеши исходников не изменились за время итогового прогона. Существующая отдельная проверка глобального вложения контрольной детали также прошла; это не расширяет область допуска нового API на произвольные самопересечения. WASM/worker/UI в этом этапе не пересобирались.
