# Атомарный допуск обрезанного G2-тела с глобальной проверкой

Добавлен `trim_and_sew_embedded_g2_patch_set`. Он выполняет существующую атомарную обрезку/сшивку с G2 и кривизной ≤10 мм⁻¹, затем заново проверяет глобальное вложение фактически сохранённой границы. Только полный положительный результат возвращает `EmbeddedPatchBody`.

Внутренние поля тела и глобального отчёта закрыты. Публичные методы возвращают неизменяемые ссылки на фактическую модель, карты исходных ролей, G2/кривизну и глобальный отчёт. Подставить чужой отчёт в новый допуск через публичный API нельзя. Параметры проверки и её UV-допуск сохранены вместе с результатом.

Отказы разделены: `Construction`, `GlobalAudit` и `Unproven`. При неполном доказательстве подтверждённое тело не возвращается. `GlobalPatchDiagnostic` сохраняет полный отчёт, карты исходных граней и новых патчей, лимиты и допуск для разборов/Retry. Результат с непроверенным суффиксом пар остаётся отказом, даже если все посещённые пары классифицированы. Исходник не меняется.

Квота построения/сшивки/G2/кривизны общая внутри существующего конструктора; последующий глобальный аудит имеет собственные явно заданные покомпонентные квоты. Это два ограниченных этапа, а не утверждение об одной суммарной аппаратной стоимости.

Существующий диагностический пример `retained_patch_embedding` переведён на новый путь допуска. При глобальной неопределённости он читает диагностический отказ, а не получает подтверждённое тело; полный положительный запуск выдаёт `Atomic admission ... admitted=true`.

## Область

Это допуск геометрически вложенной границы с подтверждёнными G2-интерфейсами и пределом кривизны на подготовленных данных. Он не подтверждает материальное вложение/ориентацию оболочек, объём, радиусный закон или толщину. Положительные контролы не доказывают генерацию произвольных пространственных узлов с независимыми радиусами.

Прежние API локальной сшивки остаются доступны и не становятся автоматически глобально квалифицированными. Новое обязательное владение отчётом применено в новом API и диагностическом драйвере; остальные потребители ещё требуют миграции. WASM, worker, UI, STEP-приёмка трёх деталей и остальная дорожная карта этим нативным этапом не закрыты.
