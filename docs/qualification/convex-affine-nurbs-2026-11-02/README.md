# Привязка ветви к аффинным NURBS-границам исходного тела

В fillet_contact::convex_branch распознавание исходной прямой UV-границы расширено с degree=1 / двух полюсов на исходную аффинную NURBS-запись с повышенной степенью и несколькими пролётами. Исходные коэффициенты не перестраиваются: проверяется точное воспроизведение линейной функции по абсциссам Гревилля с BigRational. Требуются зажатые концы и одинаковые положительные веса. Коллинеарности полюсов недостаточно: нелинейная скорость параметра не позволяет применять существующий перенос source_clock_interval.

Работа проверки включена в общий UV-бюджет. Явные неполные CoedgeTrim и ненулевые периодические подъёмы не игнорируются: возвращается Unresolved. Это ещё не реализация согласования произвольных корневых интервалов.

Проверены 17 тестов: convex_contact_branch 4, contact_branch 5, contact_topology 4, embedded_patch_body 4. Новые положительные сценарии используют степень 2 и вставленный узел на исходных UV-границах; сохраняется точный общий интервал [0.25,0.75]. Отрицательный сценарий сохраняет совпадение выбранного исходного ребра с обеими опорами, но задаёт нелинейную скорость на той же линии: аффинный интервал не выдаётся. Предыдущие проверки G2, кривизны <=10/mm, глобального вложения и STEP-roundtrip подготовленного тела также прошли.

В первых новых сценариях была ошибочно запрошена степень 2 для всех кривых, включая уже более высокие степени. Исправлены только тестовые преобразования: повышение применяется к линейным UV-границам; отрицательный контроль использует явную квадратичную параметризацию плоского исходного ребра. Окончательные логи приложены.

Команда:

```sh
CARGO_TARGET_DIR=/tmp/open-scad-trim-g2-20261101 cargo test --offline --manifest-path crates/Cargo.toml --config profile.dev.package.brep-core.opt-level=2 --config profile.dev.package.brep-core.debug=0 -p brep-core --test convex_contact_branch --test contact_branch --test contact_topology --test embedded_patch_body -- --nocapture
```

Ограничения: результат относится к точным аффинным исходным UV-границам внутри выпуклых полигонов. Это не решение для произвольной криволинейной UV-границы, нелинейного исходного параметрического соответствия, автоматического получения контактов, полного узла 5+ с независимыми радиусами или его общей G2-сборки. WASM/UI не пересобраны. Полная дорожная карта остаётся активной. Хеши двух затронутых файлов не изменились между окончательным снимком и завершением проверок; стабильность остальных параллельных правок не заявляется.
