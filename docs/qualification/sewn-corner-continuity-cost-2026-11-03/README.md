# Original sewn-corner continuity: decisive results within the existing budget

Two exact simplifications reduce proof cost without changing geometric tolerances or work ceilings:

- A full original Bernstein cell is copied in its existing common homogeneous gauge only when the requested endpoints exactly equal the original span endpoints and both knot multiplicities are at least the degree. Partial ranges and less-clamped cells retain division-free blossom restriction.
- When every requested cross-weight derivative vanishes identically on the seam, the Cartesian quotient-rule jets retain the original along-line weight denominator and omit only provably zero terms. The weight may still vary along the seam. Nonzero second weight derivatives use the general formula.
