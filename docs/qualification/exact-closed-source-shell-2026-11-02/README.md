# Exact trimming and closed source-shell assembly

The seven-stage CAD goal remains active. This native milestone closes the original-source shell for the currently qualified polynomial graph family. It does not admit or publish a solid. Earlier receipts remain unchanged.

## Construction and invariant checks

The two retained original roof regions use the exact source-chart notch loops from `retained.rs`. Their 45 transition boundary uses share the actual saved transition edge/root intervals. `Roof.close_original_shell` then reuses the six named full outer roof edges and appends the remaining five original side/floor/end faces. Original source topology must validate, select one closed outer shell without cavities, and preserve the authored source-face bindings. Original face orientations are retained.

Imported faces require a convex, exactly closed CCW polygon of polynomial UV lines, no holes or authored coedge trims, and a nonperiodic polynomial Bezier tensor support. `polynomial_surface_line` composes each actual UV line with the original support in exact rational Bernstein arithmetic, including non-natural endcap boundaries. Complete polynomial equality with the saved world edge is checked in the same normalized clock after exact degree elevation. No endpoint sampling or Cartesian tolerance welding is used. Each imported use protects its edge index, direction, root owner and parent interval.

Existing original source vertices and edge identities are reused through explicit maps. The result retains seven source-face links, ten original vertex links and sixteen edge links for fifteen unique original edges (the original crease has two retained intervals). New transition/cut identities are native topology identities, not a completed persisted document naming protocol. The original Model remains unchanged.

All saved edges, vertices, UV lifts, oriented loop incidence and closed-shell topology are checked before publishing `ClosedShell`. Every edge has two uses; there are zero open edges. Whole-support curvature is checked on the five imported supports as well as the two retained original supports and all twenty transition panels. The existing internal G2 reports and second-order original contact owners remain immutable. Unmodified original sharp body corners are not claimed G2.

## Explicit remaining scope

Closed incidence and exact boundary agreement are not global embedding or positive-volume proof. Global self-intersections/overlap, thickness, actual fillet radius and admissible volume remain required before solid admission. General rational/multi-span source faces/edges, nonconvex/holed source UV arrangements, arbitrary contact branches, unequal-radius complex nodes and 5+ corners remain open. WASM/worker/UI, STEP and independent measurements, Undo/Redo/reload, three-part acceptance, P0 and P2-P3 are not qualified by these native runs. Hashes describe listed source files in a shared dirty checkout, not an isolated delivery revision.
