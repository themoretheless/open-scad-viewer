# Exact C2-aware trimmed-face curvature

`face_curvature::inspect_with_continuity` and `surface_shape_operator::rectangle_bounds_with_continuity` accept only a native exact original-surface certificate of order two borrowing the same support. This replaces the conservative basis-multiplicity refusal; original span tensor enclosure, regularity, complete trim-domain coverage and existing work limits still apply. A copied support or a C1 certificate is rejected. A positive exact-continuity certificate alone never grants a curvature or solid certificate.

`SewnCornerCandidate::inspect_curvature_with_continuity` and `qualify_g2_with_continuity` recompute this evidence on saved supports with separately bounded shared exact work. Shares are reserved for later low-continuity faces. No caller-supplied audit can authorize admission. Existing conservative entry points remain available.

18 focused native tests pass: ten sewing/admission checks and eight face-curvature checks. The added positive case covers a truly C2 plane represented with low-continuity basis knots; foreign-support, C1 and exhausted-budget cases refuse. The actual trihedral corner remains unqualified: face 6 exceeds 10/mm, and faces 10/12 still have no exact C2 certificate within 1,000,000 shared operations. Failure to obtain that certificate is not proof of discontinuity. General G2 reparameterizations and degenerate-pole curvature coverage remain separate obligations.

The reproducible Rust example `trihedral_profile_curvature` investigates five explicit profile fractions while retaining the three requested rolling-centre radii. Fifteen saved trimmed strip faces are classified: eight complete positive covers and seven certified inside excess witnesses. Every tested 0.1 mm profile has an excess witness. This is not a proof over all possible fractions or all transition families. The 0.2/0.35 mm strip results are not whole-corner/body certificates. Witness proposals use the actual saved UV trim bounds and authorize rejection only after exact-domain membership and an interval lower bound; they never authorize a positive result.

Reproduce with `cargo test --offline --manifest-path crates/Cargo.toml -p brep-core --lib region_replacement::central_loft::sewing --config 'profile.dev.opt-level=2' --config 'profile.dev.debug=0' -- --nocapture`, then the same Cargo options with `--test face_curvature`, and `cargo run` with `--example trihedral_profile_curvature`. The recorded runs used isolated target directory `/tmp/osv-sewn-curvature-20261102`.

No new WASM artifact, worker/UI qualification, STEP acceptance or global arbitrary-solid fillet qualification is claimed. Next work remains shape rebuilding plus a cheaper exact continuity proof or a complete geometric-G2 field treatment for the two actual supports, followed by the full body checks.
