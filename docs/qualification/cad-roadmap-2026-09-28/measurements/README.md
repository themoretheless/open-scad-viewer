# Зазор по сеткам

`clearance.json`: два точных параллелепипеда, [0,10]³ и [13,23]×[0,10]². Ожидаемый зазор отображаемых сеток — 3 мм, объём перекрытия — 0.

Выбрать Clearance A → «Измерить вершины / ребро» → Тело B = Clearance B → «Зазор тел по сетке». Зелёный отрезок должен соединять точки с X=10 и X=13. Измерение не меняет документ или историю.

Для общего B-rep результат ограничен триангуляцией. При объёмном перекрытии зазор равен нулю, пара ближайших точек отсутствует. Это не сертификат аналитического минимального расстояния.

## Малое вложенное тело

`tiny-overlap.json`: внешний куб [0,0.01]³, внутренний [0.001,0.0011]³. Зазор равен 0; объём пересечения около 1e-12 мм³. Интерфейс должен показывать объём научной записью, не округлять до 0.000000; отрезок ближайших точек при объёмном перекрытии отсутствует.
