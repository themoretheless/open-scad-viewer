# Связанные экземпляры

`node --import tsx scripts/benchmark-solid-instances.mts` создаёт контрольные сцены в `output/qualification/solid-instances` и записывает `measurements.json`.

Каждая сцена содержит одно B-rep тело 2×3×4 мм и 100, 199, 500 или 1000 связанных экземпляров на сетке с шагом 5 мм. Замер проверяет восстановление документа, изменение ширины источника до 4 мм, Undo/Redo и сохранение ссылки последнего экземпляра. Сохраняются пять отдельных времён разбора, время пересчёта связей, commit, Undo и Redo, размер JSON. Первый замер не объявляется прогретым.

Эти числа относятся к Node и текущему хранению полной геометрии каждого экземпляра. Они не доказывают экономию памяти, аппаратный instancing или скорость браузерного viewport.

Преобразование экземпляра задаётся относительно текущего положения: XYZ — перенос в мировых координатах, поворот вокруг выбранной мировой оси через центр габаритов экземпляра, масштаб — положительный равномерный. Матрица нового преобразования умножается слева на существующее размещение. Источник не изменяется; последующая правка источника применяется через итоговую матрицу. Команда «Разместить экземпляр» отдельно изменяет абсолютную колонку переноса матрицы и сохраняет её линейную часть.

Первый запуск с общим лимитом 200 объектов сохранён в `measurements-node.json`: 500/1000 отклонялись. После перехода истории на компактные снимки пределы разделены: 200 независимых тел/эскизов и 1000 связанных экземпляров, с консервативной оценкой развёрнутой геометрии до 64 МБ. Новый запуск — `measurements-compact-history-node.json`; все четыре размера приняты. История держит геометрию только текущего состояния; Undo/Redo восстанавливают её из компактного текста и требуют больше времени.

## Преобразование множественного выбора

Общий центр — центр габаритов всего выбора. Все выбранные тела и эскизы получают одно и то же мировое преобразование T. Для выбранного экземпляра с матрицей M:

- Если источник не выбран, новое размещение — T M.
- Если источник выбран, новое размещение — T M T⁻¹. Его геометрия уже стала T source, поэтому итог экземпляра равен T M source без повторного перемещения.
- Невыбранные экземпляры продолжают обновляться из источника через прежнюю матрицу M. В этой модели перемещение источника является изменением его геометрии.
- При копировании выбранной пары новый экземпляр ссылается на новый источник. При копировании только экземпляра ссылка остаётся на прежнем источнике.

Проверки сравнивают выбранные тела с тем же преобразованием независимых копий, затем проходят Undo/Redo и повторную загрузку. Включены перенос, вращение, масштаб и два выбранных экземпляра без источника.
