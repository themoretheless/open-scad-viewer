# Solid: металлическость и шероховатость

Повторение: `SOLID_GPU_HEADED=1 node scripts/check-solid-material-browser.mjs`.

Оконный Chromium 151.0.7922.34 выполнил настоящий SolidGpuLayer и WGSL. Один треугольник с одинаковыми геометрией и цветом дал три различных изображения для metallic/roughness: 0/0.2, 1/0.2, 1/0.9. Ошибок страницы и шейдера нет; SHA-256 в report.json. PNG проверены визуально. Headless на этой машине терял GPU-устройство и не квалифицирован.

Это проверка рендера отдельно от приложения. UI-тест дополнительно меняет оба параметра и цвет через обработчики панели, проверяет Undo/Redo и восстановление документа. Сервисный тест проверяет границы параметров и сериализацию. Полный CAD-набор перед новым UI-тестом: 304 теста; после добавления UI-сценария: 107 тестов двух затронутых файлов.

Освещение GGX использует один фиксированный источник, без IBL, текстур, прозрачности и эмиссии. Выбор и наведение сохраняют свои диагностические цвета. Без WebGPU отображается базовый цвет и пояснение в свойствах. STEP и Blender пока не передают металлическость и шероховатость. Эти ограничения оставляют блок материалов P2 открытым.
