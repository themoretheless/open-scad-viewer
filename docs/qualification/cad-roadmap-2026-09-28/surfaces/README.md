# Контрольные поверхности

`seam-and-reduction.json` содержит две плоскости и кубическую прямую.

- Выберите Surface A, затем с Shift Surface B. «Проверить стык поверхностей»: A uMax, B uMin, направление B прямое. При 65 точках максимум зазора 0.25 мм, угол касательных плоскостей 0°. Допуск 0.01 мм не подтверждается; при 0.3 мм выбранные точки проходят проверку. Это не сертификат между точками.
- Выберите Reduce line, команда «Снизить степень кривой», степень 1 и допуск 0.05 мм. На контрольной сборке верхняя граница отклонения 0.02929687500000091 мм: оценка консервативна, точное совпадение этой масштабированной прямой ядро не распознало. Допуск 0.01 мм получает отказ. Enter сохраняет ID reduce-line и два контрольных пункта, Undo возвращает степень 3.

`sweep-inputs.json` содержит две рациональные квадратичные дуги. Выберите профиль, затем путь. Команда «Перенос профиля по пути» строит открытую поверхность с фиксированной ориентацией профиля.

Открытие Solid JSON заменяет текущий документ одной отменяемой операцией. Сначала сохраните свою работу. Для тестирования в существующей сцене возвращайтесь через Undo, включая отмену открытия контрольного файла.

## Снижение степени поверхности

`reduce-surface.json` содержит плоскость степени U=2, V=2 с сеткой контрольных точек 3×3. Выберите Reduce plane и команду «Снизить степень поверхности». Для новой степени 1 по U или V верхняя граница отклонения равна 0 мм. После применения по V ожидается U=2, V=1 и сетка 3×2; ID reduce-plane сохраняется. Escape оставляет исходную поверхность, Undo возвращает сетку 3×3. Нулевая, равная текущей и большая степень должны получать отказ.

## Четырёхсторонний patch

`coons-inputs.json`: выберите Bottom, Top, Left, Right по порядку, удерживая Shift, затем «Полиномиальный Coons patch». По нормализованным параметрам ожидается x=2u, y=2v, z=(1−v)·2u(1−u)+u·4v(1−v). Нижняя и правая границы квадратичные, верхняя и левая — прямые. Рациональные веса и несовпадающие углы не входят в текущую область поддержки. Контрольные источники сохраняются после применения.

### Перестроение непериодической кривой

`rebuild-curve.json`: квадратичная кривая на диапазоне [2,5], P(t)=(2t,4t(1−t),0), t=(u−2)/3. Команда «Перестроить кривую»: степень 3, 6 CV, допуск 0.1 мм должны принять результат; степень 1, 2 CV, нулевой допуск должны отказать без изменения документа. Отмена и Undo должны сохранять исходный ID и определение.

Rust проверяет этот сценарий и рациональную четверть окружности. UI-сценарии и контрольный файл проверены с WASM `curve_rebuild_certified`: отказ при степени 1, применение степени 3 с 6 CV, затем Undo до исходной кривой и рабочей сцены. Оценка консервативная и может быть ненулевой даже для геометрически точного результата.

### Перестроение непериодической поверхности

`rebuild-surface.json`: полиномиальная поверхность (2u,2v,4u(1−u)v(1−v)), максимум высоты 0.25 мм. При перестроении U в степень 1 / 2 CV выпуклость исчезает, поэтому допуск 0.01 мм должен блокировать применение. Степень 3 / 6 CV должна быть принята в том же допуске. Undo должен вернуть сетку 3×3 и исходную геометрию. Native-проверки охватывают обе оси, рациональные веса и узкий пик между точками равномерной выборки. Браузер подтвердил отказ при оценке 0.4444444444444467 мм и принятие степени 3 / 6 CV с оценкой 4.206400752255689e-15 мм; Undo восстановил исходную сетку 3×3 и рабочую сцену.
