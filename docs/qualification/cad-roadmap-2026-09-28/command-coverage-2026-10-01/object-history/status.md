Mouse and keyboard Chromium runs passed creation of a linked instance, absolute placement and Undo, source selection, source transform preview/cancellation/Apply, Duplicate, Delete of the copy and Make independent. Each of the last three actions is checked through full-document Undo/Redo. Detached identity and placement bounds are preserved; source unchanged; final document reload exact.

Invalid numeric input terminates the previous calculation, associates a localized field error, disables Apply and clears the error after valid input. Injected late successful transform result is ignored after cancellation. Apply reuses prepared worker result.
