# Общий NURBS offset: native-кандидат

Дата: 2026-09-30. Группа P2 остаётся открытой.

`nurbs-core::curve_offset::approximate` принимает исходную непериодическую рациональную XY-кривую, расстояние, положительный допуск и бюджет обхода. Возвращает отдельные линейные участки с исходными параметрическими интервалами и верхней оценкой ошибки каждого участка. Исходная кривая не изменяется. Это промежуточный геометрический расчёт для дальнейшего подключения команды.

## Основание оценки

Ограниченные однородные Bernstein-контроли извлекаются интервальным blossom/de Boor непосредственно из исходной кривой. Все арифметические операции округляются наружу. Однородные производные до третьего порядка получаются конечными разностями; рациональные производные — рекурсией производных P/W. Система координат переносится в исходную контрольную точку для уменьшения потери точности; перевод обратно нужен только для позиции.

На локальном параметре x∈[0,1] обозначим s=|C′|, a=|C″|, j=|C‴|. Для единичной нормали n=R(C′)/s используем консервативную оценку |n″|≤2j/s+6a²/s². Поэтому |F″|≤a+|d|(2j/s+6a²/s²), где F=C+d n. Ошибка хорды на всём интервале не больше sup|F″|/8. К ней прибавляется верхняя оценка погрешности выбранных концов хорды. При недостаточном допуске интервал делится пополам. Если касательная не отделена от нуля, subdivision продолжается; предел параметрической точности или бюджета приводит к отказу без частичного принятого результата.

## Проверки и оставшееся

Проверки включают рациональную круговую дугу с отрицательным/положительным offset, некруговую многопролётную кубическую кривую с дробными весами и сдвинутым параметрическим диапазоном; dense oracle проверяет оценку участков. Отдельно проверены cusp/refusal, сохранность источника, позиции и первые две производные, третья производная кубического полинома и неверные интервалы. Дискретные проверки — регрессия реализации; основание whole-cell оценки описано выше.

Открыто: согласование общих концов соседних сегментов и узлов, квалификация регулярности/самопересечений результирующего offset, соединения составных профилей и отверстия, periodic/замкнутые профили, transport/WASM/worker/UI, независимая квалификация и испытание обусловленности. Не объявлять эту группу готовой и не заменять сохранённый профиль отображаемой полилинией.


## Связанная цепочка и transport — 2026-10-01

Расчёт `approximate_curve` соединяет принятые хорды в цепочку NURBS degree 1. Общие точки соседних участков совпадают точно; дополнительные перемещения концов включены в верхнюю оценку ошибки. Вызов сначала использует половину заданного допуска, оставляя место для этой поправки. Сохраняется исходный параметрический диапазон. Результат разбивается по 255 сегментов: каждая retained-кривая соблюдает существующий предел 256 контрольных точек, а соседние части имеют одинаковые концы и параметры. Нулевое смещение возвращает исходное определение без аппроксимации.

Ненулевой offset требует внутренние узлы с гарантированной C1-непрерывностью. Угол сообщает параметр и необходимость явно задать профильное соединение; он не заменяется произвольным мостом. Отдельно ограничена работа Bernstein-обхода. Кривая валидируется один раз перед обработкой, без повторного полного обхода её определения в каждом подразделении.

`curve_offset_bounded` отдаёт chain `curves`, верхнюю оценку, исходные интервалы и оценки клеток; `regionTopologyCertified:false`. Native JSON export: пример `bounded_curve_offset` с required-feature transport. Исходный документ не меняется. WASM/worker/UI ещё не подключены и новый kernel для этого API не выпущен.

Независимый Decimal(70) Cox-de Boor oracle проверил экспорт: 5 частей, 1082 клетки, 9738 точек. Максимальная дискретная ошибка 0.000110183578621849 мм, native upper 0.0004988670243985645 мм при допуске 0.001 мм. Эта независимая проверка дискретная. Полный native-прогон: 162 теста и doctest прошли. Доказательства: `connected/{request,result,independent}.json` и `connected/native.txt`.

Следующее: политика соединения углов/замыкания, диагностика регулярности и самопересечений результирующей цепочки, подготовка профиля/областей и команды worker/UI. Полная группа общих профилей и весь P0–P3 остаются открытыми.


## Периодическое замыкание и диагностика цепочки — 2026-10-01

Периодический источник обрабатывается непосредственно по его активным knot spans, без округлённого предварительного открытия/trim. Последний конец результата становится ровно первым; величина изменения включается в верхнюю оценку последней клетки. Исходная wrapped storage остаётся неизменной. Нулевой offset сохраняет periodic-флаг и исходное определение. Узел, не дающий гарантию C1 по базису, требует явного профильного соединения, включая периодический шов.

`chainDiagnostics` использует outward interval-предикаты на определениях возвращённых line-сегментов. Проверяются точная связность, вырожденные клетки, не соседние пересечения и контакты. Неопределённые касания/перекрытия не превращаются в результат simple. Отдельно показаны полнота перечисления и разрешённость предикатов; достижение лимита пар возвращает частичный отчёт. Это диагностика представленого результата; никакой authored source certificate для округлённых construction coordinates не создаётся.

Контрольная weighted periodic-кривая: 255 клеток, одна retained-кривая, exact closing point. Проверены все 32385 пар без неопределённых результатов; эта представленная цепочка simple. Независимый Decimal(70) oracle: 2295 точек, max error 0.00020231713288175945 мм; whole-cell native upper 0.0004970256354838692 мм при допуске 0.001 мм. Независимый oracle дискретный.

Финальный прогон: 166 native-тестов и doctest прошли. Доказательства — `periodic/{request,result,independent,contract}.json`, `periodic/native.txt`. Отказы по periodic-углу, resource partial, overlap unknown и degeneracy проверены. `offsetRegularityCertified:false`, `regionTopologyCertified:false` остаются явными: сертификат ошибки положения не доказывает регулярность или исходную топологию offset. WASM/worker/UI и подготовка общих профилей не завершены; новый kernel для этой группы не опубликован.
