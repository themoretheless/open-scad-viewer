# Концевые G2-переходы с пределом кривизны — 2026-11-01

`region_replacement::build_g2_end_runout` строит конечные Hermite-переходы между двумя явными внутренними трассами исходных поверхностей. Исходные опоры и их размеры не изменяются. Затраты построения, швов, невырожденности и поля кривизны расходуют общие ограниченные счётчики.

До выдачи `QualifiedEndRunout` обязательны:

- полное позиционное и G2-соответствие исходным опорам, включая все внутренние швы при нескольких knot spans;
- невырожденность и инъективность каждой полной панели через подтверждённую целочисленную проекцию;
- абсолютная главная кривизна ≤10 мм⁻¹ на каждой полной панели.

Параметры G2: позиционный допуск задан явно, normal=1e-5, tensor=1e-4. Только неизменяемый доступ к прошедшим проверку поверхностям и отчётам. Внешние флаги или ранее полученные свидетельства не принимаются.

## Контрольные сценарии

Плоские и рациональные криволинейные опоры; корректный конечный переход; переход 0,1 мм с гладкими швами, но недопустимой внутренней кривизной; интервальный точечный свидетель превышения; исчерпанный бюджет и вырожденная проекция.

Размер перехода не увеличивается автоматически. Отказ одной поверхности шириной 0,1 мм не доказывает невозможность всех иных форм той же ширины.

## Граница этапа

Результат — открытые панели для последующей сшивки, а не новый замкнутый B-rep. Членство контактов в trim-областях исходных граней, центральные торцевые углы, общий поиск пересечений разных панелей, толщина и материальное вложение остаются отдельными обязательными этапами. Изолированный гладкий торец не устраняет исходные острые рёбра рядом с его концами: соседние переходы также должны входить в узел.

Это консервативные оценки контрольных поверхностей, не универсальная точность или область применимости для всех NURBS.
