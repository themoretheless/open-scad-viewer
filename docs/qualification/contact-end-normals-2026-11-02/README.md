# Необходимое условие нормалей концевой области

Добавлен `region_replacement::inspect_contact_end_normals` и структурированный `ContactPatchFailure::EndRegion`. Проверка выполняется до вызова конструктора новых поверхностей, после воспроизведения приватно связанного корневого плана.

В каждой общей концевой вершине вычисляются интервальные единичные нормали **реальных сохраняемых source-use концов**, по исходным коэффициентам и фактическим clamped pcurve. `surface_shape_operator::at` даёт округлённые наружу оценки; это точечный необходимый свидетель, не выборочное подтверждение всего тела. Обе ориентации нормалей учитываются; для отказа используется минимум двух строгих нижних границ.

Для регулярного конечного G2-веера каждая новая грань имеет одну непрерывную нормаль в общей вершине. Путь от одной сохраняемой опоры к другой через P новых патчей содержит не более P+1 швов. Даже позволяя каждому шву накопить текущий normal tolerance, необходима оценка gap <= (P+1)*tolerance. Максимум патчей 64 и tolerance 1e-5 взяты из общих с `sew_g2_patch_set` констант; бюджеты не изменены. Верхняя цепочная оценка считается интервально, с округлением наружу: 0.0006500000000000002.

На контрольной острой детали строгая unsigned lower граница исходного разрыва нормалей составляет 1.264911064067341 на обоих концах. Это исключает регулярный G2-веер в **неизменённой концевой области** под текущими ограничениями, независимо от формы плоской заглушки. Возвращается `ExpandEndRegion` с устойчивыми идентичностями корня, исходного ребра, обеих source-граней и исходной вершины, в направлении которой нужно пересмотреть область. Конструктор заведомо несовместимого торца не вызывается.

Условие не является запретом сингулярных/non-G2 форм и не доказывает невозможность построения после изменения концевой области. `NoObstructionProven` не является положительным G2-допуском; отсутствующие нормальные оценки дают Unresolved и не превращаются в положительное доказательство. Радиус, кривизна и полный global audit остаются отдельными гейтами.
