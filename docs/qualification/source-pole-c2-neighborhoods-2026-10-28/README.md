The Rust factory composes complete owned pole graph disks, common exact pole
jets and exact G2 coverage of every meridian in the native vertex link. It
retains same-body ownership and refuses C0, tolerance-only and exhausted
requests without returning a partial atlas. See THEOREM.md for the proof scope.

The flat capped-body regression covers two four-face neighborhoods, every
incident exact meridian, C0 refusal, tolerance-only refusal and one-short work
budget refusal. The independent parabolic closed body has exact caps
`z=x*x+y*y` and `z=8+x*x+y*y` over a diamond of area two. Native source
geometry admission succeeds, the volume interval
`[15.869729999452506, 16.11810938144759]` contains 16, and both C2 pole
disks have radius at least `0.031249999999998192`. Their common exact jet
bounds enclose `[gx,gy,Hxx,Hxy,Hyy]=[0,0,2,0,2]`. Each disk has four faces
and all four exact meridians; composition uses 54 incidence steps in total.

The qualification receipt records checks on unchanged Rust inputs. Targeted
native tests are not the full workspace suite, G1 semantic qualification, a
WASM/browser rebuild or remote CI. Architecture audit failures prevent push
under the invoked push-or-clear workflow. No audit baseline is relaxed.
