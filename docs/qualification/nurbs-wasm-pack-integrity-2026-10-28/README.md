# WASM packaging output integrity — 2026-10-28

A real geometry-packer reproduction confirmed that a same-length corrupted generated payload survived a second build: the old stamp checked only the original WASM hash and file existence. This could retain incorrect embedded bytes, identities or published raw modules when the source itself was unchanged.

The versioned cache now snapshots each requested output's relative label, byte length and SHA-256. Every cache hit checks the exact requested output set and every file. Legacy source-only stamps, missing/truncated/corrupt files, invalid manifests and mismatched source bytes invalidate the cache. Metadata paths are labels only: files are always selected by the caller, never opened from untrusted manifest entries. File URLs are supported; manifest parsing is size-bounded. Completed manifests are published through a unique temporary file and atomic rename. Failed snapshots or writes preserve the old stamp and clean up their temporary file.

Geometry, language, photogrammetry, HarfBuzz and Brotli-bootstrap producers now supply the full output inventory. The shared cache is build integrity only: it does not establish compiler-source provenance, authenticate hostile local authors, or make several independent artifact writes a multi-publisher transaction. Packer versions and source qualification remain separate requirements.

Verification passed **14 Node packaging tests** and **43 runtime tests across seven files**. Tests reproduce same-size corruption and repair of every geometry/language/photogrammetry output through the actual packers, plus legacy migration, ordered output-set identity, missing/truncated files, malformed/oversized manifests, URL paths and failed atomic publication. The first runtime run passed 42 and failed once because this temporary checkout lacked its raw photogrammetry build fixture. An independently compiled original-checkout artifact was restored only after its SHA-256 exactly matched the published module; the test and its expected path were retained. The recovery source/hash and initial failure remain in the receipt.

The real c8 geometry artifact was repacked and verified through the new cache. All four generated/public files were byte-identical: source/public WASM remain SHA-256 `c8a299c3e8e2bbccc5cc6a594b735bd27fb47daa5ea7aa7e45d2c027cf1af992` (15,811,953 bytes). Real HarfBuzz packing and the subsequent cache hit likewise retained every payload byte. One-run timings in matrix.json are observations under uncontrolled host load, not a performance qualification. No Rust source or WASM math changed.

Changed-script syntax, API mapping (239 public modules / 200 catalogue entries) and diff whitespace pass. Architecture retains 71 existing violations with no changed limits.
