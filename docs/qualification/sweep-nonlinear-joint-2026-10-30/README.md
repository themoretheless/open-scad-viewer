# Nonlinear original seam maps and joint sweep admission

This continuation keeps all geometry and certification in Rust. It changes no tolerances, exact-work/cell ceilings, test deadlines, runtime artifact, or application focus. Python only freezes sources and records native qualification.

## Nonlinear map theorem

The new `bspline_strip_nonlinear` predicate first recovers rational parameter maps from a proved affine Cartesian coordinate over the whole original seam. It then admits **ordered local Cartesian or projective charts**, including closed/periodic sources. Exact elimination can propose homogeneous linear forms L and M with `L(H_A)=s` and `M(H_A)=1`; this covers nondegenerate rational conics and full-rank spatial cubics without requiring any affine Cartesian axis. Elimination only proposes a chart: full composition, denominator/derivative positivity, range and coverage remain mandatory. Arbitrary higher-degree rational curves whose inverse does not belong to these chart families remain unresolved.

Original one-sided homogeneous transverse jets are converted to exact rational power polynomials on every original along span. The affine-coordinate identity is checked coefficient-wise on every A span. From actual B coefficients, `N=B_axis-lo*B_weight` and `D=(hi-lo)*B_weight` define the candidate map (with an exact common sign making D positive). Original positive B-spline weights establish positivity of D. Positive Bernstein coefficients of `N' D-N D'` on **each entire original B interval** certify strict monotonicity. Successive endpoint images must agree, start at zero, finish at one, and remain inside the complete original A domain.

For local charts each original B span must fit a single original A chart. Exact endpoint images must join the preceding endpoint, traverse original A charts in order, and finish the complete original domain once. This supplies a lift for periodic loops and refuses a second lap of the same geometric locus. No rounded knot-preimage splitting or sampled phase correction is used. Projective charts additionally prove positivity of their denominator over the whole original B interval.

Every original A/B span pair with nonempty mapped overlap must pass a formal homogeneous polynomial composition. No sampled map, rounded inverse, fitted surface or knot insertion is authority. Cartesian position and transverse velocity are checked by polynomial cross products that cancel variable homogeneous gauges. G2 additionally checks that the normalized acceleration difference is parallel to the independently regular transverse tangent. Every coefficient is mandatory. The existing original source joins and bounded interval normal covers remain independent requirements.

The shared exact context charges affine/projective proposals and nonlinear fallback work without resets or refunds. Cheap nominal and exact normal-scale proposals run before map search. The existing zeroth-jet comparisons expose `affine_parameter_identity` without repeating arithmetic; this is proposal-routing evidence, never a differential or Solid certificate. A proved common pointwise parameterization suppresses unnecessary nonlinear searches, preserving the budget for other owned seams. Missing independent source-join proofs cannot be replaced by a map candidate. The per-seam maximum remains 1,000,000, the collection allowance remains unchanged, original strips retain at most 33 controls per direction, and normal covers retain 4096 cells/depth 12. Unsupported graphs, uncertain positivity, stationary/reversing maps and exhausted work remain unproved. A linear authored pcurve still cannot borrow a nonlinear geometric point-set correspondence.

Regression cases include a quadratic speed map on a parabolic seam, rational speed without interior knots, same-degree Bezier fallback, a nonlinear rational conic without an affine Cartesian coordinate, a periodic one-lap map and a rejected double cover, hidden interior/one-ULP mismatches, G1 with a G2 curvature failure, stationary/reversing maps, zero work and one-short work.

## Joint continuous/global/differential admission

`brep_core::sweep_boundary_owned::joint::Certificate` has private fields and no public report-based constructor or deserializer. It borrows the immutable model owned by a successful native construction. Four owned body types expose `joint_certificate(order)`:

* Open authored filled-cap sweep and general closed sweep: order 0 requires a full continuous bound within budget, retained regularity/global volume, and the original filled-source global proof. Higher orders remain refused because these body types do not own full original and retained differential evidence.
* Smooth closed source/retained construction: orders 1 and 2 additionally require the corresponding complete original and retained boundary certificates. Retained G2 alone cannot manufacture original G1/G2.
* Exact rational affine source/retained construction: exact coefficient/domain binding and topology transport connect its original volume proof to the same actual model. Sharp C0 caps allow order 0 and keep higher-order refusal; G1-only source evidence cannot grant G2.

All joint grades require a finite nonnegative complete boundary-error bound. No new proof work is performed or hidden in token retrieval. Each refusal names the first missing stage. Native JSON exposes `jointContinuousGlobalCertified`, `jointContinuousGlobalG1Certified` and `jointContinuousGlobalG2Certified`, computed only from constructor-owned tokens. Caller flags cannot supply them. Existing construction, error-bound, retained smoothness and Solid fields retain their original separate meanings.
