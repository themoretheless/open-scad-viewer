## Original SS ownership

`ss_face_membership::partition_closed_branches` borrows a complete immutable `QualifiedMembership` and replays its original/proxy/face proof before construction. Every original branch edge clock and incident original vertex must be classified in both actual retained faces. A branch entirely excluded from their joint retained region authors nothing; an entirely retained closed branch is constructed on both supports. Open, mixed or trim-crossing retained branches require the root-bound open-contour stage and are refused here. An internal closed SS loop needs no boundary-root event and is no longer silently left without a construction path.

Contour order follows exact original vertex/edge incidence, never world-position proximity. Branches with inconsistent ports, disconnected components or ambiguous next ports refuse. Saved proxy curves and pcurves retain their original native UV coordinates. Reversal inherits the qualified source proxy only for exact single-span unit-clock pole/weight reversal, with no rounded interior-knot arithmetic. Proven original world/UV proxy error bounds must fit the actual model/UV tolerances. The SS wrapper requires both exact reference flags and definition-checks authored world edges against these immutable original qualified proxies. A source branch/edge and direction accompany every authored edge.

Both actual selected sides are processed atomically. When they belong to one `Model`, only one clone is used and each side remains in its own original shell. Different operands receive separate model copies with the same canonical world contour definitions. Shared cell/pair ledgers cover membership replay and all face constructors; source replay, proxy reconstruction, original range work and contour ordering have a separate bounded operation ledger. Existing bounded model/curve validation is not claimed as interval arithmetic work. Full immutable replay compares all saved models, regions, edge provenance and counters.
