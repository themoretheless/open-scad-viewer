# Типизированные рецепты областей и native replay · 28.10.2026

SourceRegion хранит исходные данные в Rust enum: Original, Cut (Linear/Curved), SplitRoot и SplitParameter. Сохраняются исходная спецификация допусков, поверхность, обе кривые каждого Boundary, направления, селекторы и адреса. JSON остаётся необязательным представлением definition; существующие поля и метки вариантов сохранены.

SourceRegion::requalify(ReplayLimits) заново допускает исходную область, повторяет поиск и классификацию разреза и заново вычисляет корень SplitRoot по исходным уравнениям и селектору. Сохранённые winding, whole-chart, петли, индексы петель и интервалы корней не дают разрешения. Сохраняется прежний контракт wire restore: глубина 1..64, до 16 исходных петель и 256 рёбер на петлю, независимые ограниченные бюджеты на каждом шаге. Бюджет не увеличивается автоматически.

Проверки на окончательных исходниках: **4207 успешных native-тестов, 0 отказов, 6 пропусков** (brep-core 2003/5, nurbs-core 1996/1, cad-predicates 100/0, nurbs-intersect 108/0). Обычная dev-сборка прошла. Старые проверки линейных/криволинейных/рациональных областей теперь сравнивают native replay с wire restore по исходным фрагментам, winding, whole-chart и индексам петель. Дополнительные тесты проверяют подменённые кэши, изменение исходного world-контура, исчерпание работы, ограничения глубины, разбиение по параметру и свежему корню. Разбиение по корню дополнительно проходит wire round-trip и проверку общих концов.

Минимальная сборка остаётся незавершённой: **55 ошибок вместо 59** (54 обращения к необязательному value_codec, 1 импорт linear_canal_body в restore-адаптере). Архитектурных превышений 70, лимиты не менялись. Карта API актуальна: 239 модулей / 200 записей. Это не квалификация общего Boolean/Solid, G2-угла, offset, упрощения или WASM/UI/STEP. Полный план остаётся открытым.

Команды и хэши журналов приведены в matrix.json. Следующий этап — свежий типизированный replay фрагментов/рёбер и устранение JSON из вычислительной подготовки обмена без пропуска математических проверок.
