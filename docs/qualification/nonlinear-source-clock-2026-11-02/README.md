# Нелинейные исходные часы контактной ветви

`fillet_contact::convex_branch::inspect` расширен на прямые в UV исходные NURBS-границы с нелинейной полиномиальной или рациональной скоростью параметра. До обращения доказывается строгая монотонность на всех исходных пролётах. Весь положительный контрольный многоугольник должен точно лежать на своём отрезке; выпуклость исходного полигона и доминирование выбранного носителя проверяются прежними точными полуплоскостями. Криволинейные UV-носители не заменяются отрезками.

Новый приватный source_clock вычисляет обратные скобки точным рациональным de Boor и 48 шагами бисекции. Это не выборка, принимаемая как доказательство монотонности: она доказана отдельно на всём интервале. Бисекция с точными сравнениями лишь изолирует единственный обратный корень. Исходные коэффициенты не перестраиваются. Нормализованный локальный параметр переводится с учётом обратного обхода в исходный 3D-параметр; совпадение фактического ребра с обеими опорами перед этим заново проверяется существующим full-interval lift API.

Работа точного обращения включена в общий UV-бюджет. Нехватка бюджета возвращает Unresolved; неопределённые корни не заменяются серединами. Общий участок образован max двух начальных корней и min конечных. Оболочки каждой границы переводятся в f64 с наружным округлением; при их перекрытии подтверждение не публикуется. Только [common[0][1],common[1][0]] является гарантированным общим внутренним диапазоном. Наружная оболочка или середины скобок не разрешают обрезку.

## Проверено

20 тестов прошли: convex_contact_branch 7, contact_branch 5, contact_topology 4, embedded_patch_body 4. Новые сценарии включают полиномиальную и рациональную скорость, обратный обход, неединичные независимые диапазоны 3D-ребра и pcurve, вставленный узел, разные контактные диапазоны соседних граней, бюджет на единицу меньше требуемого, стационарный исходный clock и диапазон исходных часов шириной 2 ULP. Скобки положительных корней проверены независимыми точными рациональными неравенствами для аналитических квадратичной и рациональной функций.

Пример для f(t)=(t+t²)/2: контакты [0.25,0.75] дают скобки [0.3660254037844375,0.36602540378444104] и [0.8228756555322931,0.8228756555322967]. Старый аффинный перенос 0.25/0.75 лежит вне этих скобок. При диапазоне 3D-ребра [-2,6] и локальном pcurve [8,12] проверены соответствующие исходные параметры. Для разных соседних диапазонов [0.25,0.75] и [0.375,0.625] независимо проверено пересечение по обратным корням 0.375 и 0.625.

Остались зелёными прежние проверки G2/кривизны <=10/mm, глобального вложения и STEP-roundtrip подготовленной сети. Это отдельные контрольные тела: новый нелинейный контакт пока не обрезан и не сшит в такое тело.

Первый отрицательный пример с изменением только 3D-домена до 1 ULP отклонялся уже структурной проверкой sampled lifts. Окончательный сценарий синхронно задаёт 2 ULP на 3D-ребре и исходных pcurve и проверяет отсутствие опубликованного интервала. Допуски, численные пределы и бюджеты ради прохождения не повышались.

## Воспроизведение

```sh
CARGO_TARGET_DIR=/tmp/open-scad-trim-g2-20261101 cargo test --offline --manifest-path crates/Cargo.toml --config profile.dev.package.brep-core.opt-level=2 --config profile.dev.package.brep-core.debug=0 -p brep-core --test convex_contact_branch --test contact_topology --test contact_branch --test embedded_patch_body -- --nocapture
```

Хеши трёх затронутых файлов совпали до и после итоговых проверок; стабильность остальных параллельно редактируемых файлов не заявляется. Лог сжат gzip без времени в заголовке.

## Открытая область

Криволинейные UV-границы, невыпуклые области и отверстия, частичные CoedgeTrim с корневыми концами и ненулевые периодические подъёмы остаются неподтверждёнными. Метод доказывает ограниченную принадлежность ветви, а не единственность rolling-ball продолжения, радиус, толщину, G2 или сборку полного угла. Для исходных опор сохраняется прежний proof gate глобальной инъективности; произвольная опора может оставаться Unresolved. WASM/worker/UI не пересобраны. Полная дорожная карта остаётся активной.
