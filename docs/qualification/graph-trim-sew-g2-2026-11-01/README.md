# Центральный граф: атомарная обрезка, сшивка и G2-допуск

Добавлен `trim_and_replace_graph_contacts_g2`. Он связывает геометрию центрального графа с исходными контактными разрезами через общий проверяемый mapping и вызывает существующий атомарный `trim_and_replace_contacts_g2`. Прежний C0 API сохранён. Перед выдачей read-only тела проверяются фактически сохранённые швы и поле кривизны всех сохранённых граней; предел — 10 мм⁻¹. Остатки конструктора не дают допуска.

Контрольная рациональная модель: 7 граней, 15 рёбер, 10 вершин, два заявленных гладких контакта. Верхняя оценка кривизны 9,943636083130052 мм⁻¹ относится к этой модели, не к общему классу NURBS.

Проверены неполная граница, неправильное направление pcurve, исчерпанная квота, превышение кривизны на масштабированной G2-совместимой модели при поддельных нулевых остатках конструктора, неизменность исходника при отказе, сохранность опорных поверхностей и сериализация/загрузка с повторной проверкой замкнутости. Положительный случай допускается при NaN в неавторитетных остатках конструктора, поскольку доказательство вычисляется заново.

Команда: `CARGO_TARGET_DIR=/tmp/open-scad-trim-g2-20261101 cargo test --offline --manifest-path crates/Cargo.toml --config profile.dev.package.brep-core.opt-level=2 --config profile.dev.package.brep-core.debug=0 -p brep-core --test qualified_contact_body --test sewn_patch_set --test trim_contact_replacement -- --nocapture`.

Результат: 12 тестов прошли, 0 сбоев. Полный протокол в native-tests.log. source-hashes.json фиксирует квалифицируемые файлы после прогона. Во время сборки другая работа изменила отдельный модуль nurbs-core/intersection/ss_intersection/fiber_coverage/components/discovery.rs; полного стабильного снимка всего репозитория и полной регрессии здесь не заявляется.

## Область поддержки

Нужны подготовленные общие корневые концы, исходные pcurve и явно заданная удаляемая сторона. Граф здесь один; сетевой сборщик нескольких патчей квалифицируется отдельно. Только явно выбранные smooth-контакты входят в G2-область: торцевые острые швы контрольной модели не стали гладкими. Это не автоматическая генерация произвольных контактных ветвей, не решение общих углов с независимыми радиусами и не сертификат толщины, радиусного закона или общего глобального вложения.

Изменение нативное. WASM/UI для нового API не пересобирались. Текущая проверка дистрибутива отдельно остаётся неуспешной: безымянный JS-чанк 128484 байта превышает порог классификации. Предыдущие ограничения размера геометрического payload также не сняты; бюджеты не менялись.
