# Runtime v6 delivery budget

The integrated native geometry artifact is independently versioned as runtime v6. Its first coherent production build measured 4,667,382 bytes in the losslessly packed geometry chunk and 9,071,527 asset bytes excluding the three streaming WASM files. The previous delivery limits (4,120,000 and 8,390,000) reject this build; the explicit v6 limits are 4,680,000 and 9,090,000 bytes. This permits the preserved combined NURBS, intersection, topology and CAD functionality with bounded packaging headroom. It is a measured size increase, not a performance improvement.

Frozen runtime v5 identity and qualification records retain their original artifact and budget. Native accuracy tolerances, interval proof budgets, maximum work, payload limits and acceptance conditions have not been increased to obtain passing results. Runtime v6 needs its own completed exact-artifact provider and browser evidence before publication.

The shared Solid worker client measures 110,536 bytes with retained-source replay and native boundary diagnostics. Its named v6 limit is 111,000 bytes (previously 103,000). All other named worker/chunk limits remain unchanged.
