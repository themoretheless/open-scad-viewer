a second lap, reversed order, changed coefficients and a G1-only curvature
perturbation cannot acquire the higher certificate. Native JSON recomputes the
proof and never promotes local G2 into Solid/global/joint admission.

This route requires corresponding ORIGINAL span endpoints. Arbitrary branch
graphs with unmatched algebraic cuts inside spans, missing monotone local charts

a universal real-algebraic correspondence solver.
