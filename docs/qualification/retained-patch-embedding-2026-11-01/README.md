# Глобальная диагностика обрезанных сетей — незавершённая квалификация

Добавлен запускаемый `retained_patch_embedding`: повторяет фактическую обрезку и сшивку трёх- и пятилучевой контрольных сетей, затем вызывает полный `boundary_embedding::inspect_with_linear`. Общая fixture вынесена из теста в `examples/support/retained_patch_fixture.rs`, чтобы диагностировать те же данные без копирования построения.

Проверяются все отдельные грани и все пары, включая смежные. Выводятся конкретные неопределённые пары, недоказанные подъёмы pcurve, решения точного предиката и расходы. Код завершения 2 означает, что хотя бы одно тело не получило глобального подтверждения; запуск такого отчёта не является зелёной приёмкой.

## Обнаружено

- Три патча: все 528 пар посещены, 73 пары остаются неподтверждёнными, непосещённых пар нет. Все грани инъективны, trim-области допустимы и UV-стыки точно замкнуты.
- Пять патчей: все 595 пар посещены, 82 пары остаются неподтверждёнными, непосещённых пар нет. Те же положительные результаты локальных проверок.
- Строгая идентичность сохранённых 3D-рёбер и подъёмов pcurve не подтверждена. Уже исходная центральная поверхность до обрезки имеет четыре решения `Different`. После предварительного разбиения исходного граничного ребра исходный пятилучевой случай имеет шесть таких использований. В собранных сетях есть дополнительные `Different`, случаи без решения `None` и `Indeterminate(PrecisionExhausted)`.
- Расход общего exact-прохода 470040/1000000 и 869253/1000000: общий предел не исчерпан. Увеличение общей квоты не устраняет решения `Different`.

`Different` здесь — точное различие представлений, а не доказательство недопустимого по CAD-допуску зазора. Предыдущие подтверждения замкнутости/G2/кривизны в пределах заявленных допусков остаются отдельными результатами. Они не подтверждают строгую глобальную квалификацию.

## Следующее исправление

Сохранять оригинальные представления граничных подъёмов при построении центральной поверхности и разрезов. Требуется раздельно исправить исходные границы, новые внутренние рёбра и исходные pcurve после проекции; повторить глобальный аудит после исправления, не ослабляя его предикаты. Затем квалифицировать оставшиеся контакты между различными опорами, включая узловые контакты. Форма независимых радиусных переходов, толщина, STEP, WASM/UI и остальная дорожная карта этим диагностическим этапом не закрыты.

Команда: `CARGO_TARGET_DIR=/tmp/open-scad-trim-g2-20261101 cargo run --offline --manifest-path crates/Cargo.toml --config profile.dev.package.brep-core.opt-level=2 --config profile.dev.package.brep-core.debug=0 -p brep-core --example retained_patch_embedding`.

Повторный финальный диагностический запуск завершился с ожидаемым кодом **2**, поскольку глобальное доказательство неполно. После выноса общей fixture все **3 теста сборки прошли**, код 0. `global-diagnostic.log`, `fixture-tests.log`, `result.json` фиксируют результаты; `source-hashes.json` содержит хеши относящихся к этапу файлов после прогона.
