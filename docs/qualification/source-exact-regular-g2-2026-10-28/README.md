# Exact original regular seam curvature qualification

The native `qualify_curvature_exact` factory composes fresh exact original
meridian gradient/Hessian identities with complete native regular shape
coverage and one coherent normal/tensor orientation. `is_exact()` distinguishes
this proof from a passed distance tolerance. Projection zeros require native
regularity; singular endpoints do not receive a continuation certificate.

`qualify_exact_curvature_collection` borrows one complete private source-body
collection and freshly certifies every requested regular Curvature carrier
under one aggregate ledger. Its certificate preserves all original C0 and G1
classes. Existing exact polar tokens can be reused from that same collection;
tolerance-only polar tokens refuse. THEOREM.md states the proof and limits.

The qualification includes eight nonzero-curvature affine-frame/weight cases,
a regular seam crossing a zero of the chosen projection, interior curvature
jumps despite matching endpoints, singular source endpoints despite dense jet
identity, and one-short exact/cell/curve/shape budgets. A closed seven-side
split prism owns three exact regular G2 carriers and retains its sharp joins.
It uses 21 incidence steps, 8155 exact operations, 6 carrier queries, 12 curve
spans and 12 native shape cells. Separate mixed-class admission preserves a G1
request. Polar-body tests reject a tolerance-only upgrade and reuse eight
already exact polar tokens without recomputing their exact predicates; each
polar record and every body-edge class still spends incidence work.

Read verification.json for frozen-source test results and log hashes. These
are targeted native checks, not the full workspace, full semantic G1 matrix,
WASM/browser or remote CI. The global ideal-law goal, arbitrary retained face
interiors, all filled cap families and closed seams are not completed by this
seam certificate. Unsupported original meridian layouts and maps remain
explicit refusals. Architecture audit remains a separate delivery gate, with
no relaxed baseline.

Frozen qualification: 20 native command groups, 132 passing Rust tests and
10 passing audit-tool tests. All Rust input hashes remain unchanged during
qualification. Architecture audit still emits 82 diagnostic lines.
