# Closed Fixed frame and exact volume rank obstructions

The Fixed frame now proves its own closed C2 seam from the original initial
basis and periodic twist jets. That frame result is separate from the full
volume certificate. Before trying a wrapped volume atlas, the native owner
requires exact closure and one common normalized carrier. For arc length it
also proves a regular inverse station map.

Two sufficient obstructions now reject folded fixed-frame constructions.
For a constant pose law apart from translation, fix any interior UV of a
carrier span. The two spatial carrier columns are constant along the sweep.
If their cross product vanishes, so does the volume determinant. Otherwise
the determinant is the derivative of the scalar projection of the closed
translation on that fixed cross product. Exact closure and interior C1
allow Rolle's theorem and force rank loss.

For a transverse carrier, all original rational control points have the same
projection along the exact initial tangent. The native test evaluates the
actual one-sided homogeneous endpoint jet. The constant projection means
the axial section coordinate is independent of UV for arbitrary axial offsets
and anisotropic scales. Twist takes place in the transverse plane. After the
path and the axial laws prove interior C1, the common axial coordinate has
equal endpoint values and a zero interior derivative. All three volume
columns then lie in the same two-dimensional plane.

The exact checks share the volume ledger. Missing premises, inconclusive
arithmetic or an exhausted proposal budget supply no rank conclusion.
The regular atlas remains the admission path for cases beyond these
obstructions.
