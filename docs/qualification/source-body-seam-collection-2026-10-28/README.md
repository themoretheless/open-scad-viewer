# Original-body seam collection

The Rust `source_seam_tangency::qualify_collection` entry point composes fresh
whole-carrier tangent-plane checks on every ordinary shared edge of one
immutable, privately admitted `source_volume::Body<E>`.

Every edge has exactly one requested class: explicit C0 or tangent planes within
a common `max_sine_squared` allowance. The result retains the complete class
vector and binds the certificate by borrow to that actual body. C0 entries do
not gain a tangency claim. No caller report, cached Boolean, omitted edge or
partial successful prefix constructs the certificate.

Cell, curve-span and surface-normal-span budgets are shared across all requested
seams, rather than reset for each edge. A failed requested seam returns no
collection certificate. Collapsed pole strata remain an explicit refusal,
including when all ordinary edges were requested C0.

## Scope

This milestone composes tolerance-based tangent-plane certificates on original
carriers. It does not prove face-interior regularity, G2 curvature, pole tangent
limits, or the whole ideal loft/sweep goal. It does not upgrade source-family
admission, supply unsupported frame/cap combinations, or qualify WASM, browser,
STEP or the full semantic G1 release matrix. There are no TypeScript changes.

Native checks cover curved tangent seams, an interior crease, each shared-budget
exhaustion dimension, omitted classifications, explicit C0, complete admitted
cylinder edge coverage, privately admitted root-ended tetrahedron variants,
and refusal for an admitted projective body with poles. See verification.json
for actual completed checks; a listed test is not a result until executed.
