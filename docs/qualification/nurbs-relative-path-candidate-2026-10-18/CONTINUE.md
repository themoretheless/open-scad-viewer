# Exact finite paths and per-authored-wire relative winding

OwnedPeriodicRelativeWinding binds the actual OwnedPeriodicWireJumps owner, original canonical pieces, declared exact rational chart-interior axis path, original algebraic native-clock cuts and all source-wire roles. It replays the full physical/source owner and computes one retained signed crossing record for EVERY path-segment/original-piece pair, including zero values. Complete census work is checked before assembly. Separate BigInt wire totals preserve multiplicity and authored orientation; coincident independent opposite wires do not collapse into a scalar fill.

The finite axis crossing primitive computes the difference of complete clipped exact ray counts at both endpoints. Vertical paths use the determinant+1 homogeneous rotation(v,-u), leaving native source parameters/cuts untouched. Selected boundary contacts, nongeneric paths coincident with an ORIGINAL supporting cell, non-axis segments, chart-shore/outside points and incomplete allowance refuse explicitly. Coincident supporting cells are conservatively refused even if only an excluded source portion lies on the path level: future generic-path proposals may retry this condition, but errors/unknowns must never become successful zero crossings. Zero-length segments still check selected boundary membership. No float temporary Curve or fitted topology is introduced.

Regressions prove horizontal/vertical orientation, closed-wire inside/outside changes, reversal and concatenation, original nonunit cuts, excluded-boundary points, endpoint contacts and collinearity refusals. The actual periodic square-tube support with a twice-traversed essential wire and an independent opposite wire gives[2,-1] and reverse[-2,1], retaining separate source terms. Replay rejects missing crossing records, changed totals/path, missing allowance and invalid path vertices. Fresh gates174 profile+74 integration=248 tests and WASM compilation.

These are chart-local RELATIVE values from a declared base point. They do not select an absolute outside on a periodic surface, enforce operand-group period compatibility, evaluate Boolean predicates, prove connected regions or publish physical faces. Essential individual wires may have nonzero homology and still bound a valid grouped band. Full natural-boundary ownership, generic path selection and global material side propagation remain.
