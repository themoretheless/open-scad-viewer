# Combined native T: proof ownership and qualification limits

T combines the R immutable original-span reuse, Q periodic FixedNormal arc-length source-bound extension and S finer integer-dual projection proposals. See the respective native manifests and owner proofs. Geometry, source correspondence, station correction, chart/global proofs and Solid admission remain Rust-owned. JS/Python files are qualification transport and independent verification.

## Immutable contact-patch reuse

Each `PreparedControlSurface` borrows one immutable `Surface` for one contact search. Its key contains the four parameter-domain binary64 bit patterns; a lookup cannot cross source identities. Original knot-span eligibility is recomputed for both charts before preparing either patch, retaining the original cross-knot refusal and error ordering. For a fixed immutable source and key the original first eligible knot spans are deterministic, including a degenerate domain on a knot.

A miss calls the original `Patch::new`; only successful patches are retained. A hit returns that same restricted rational control net. Dynamic pair lower bounds, integer-normal projection arithmetic, split proposals, traversal and all geometry/domain work charges are unchanged. The original free `rectangle_control_query` remains an independent uncached oracle. Eviction changes reuse only, not arithmetic or admission.

The LRU retains at most32 patches and normally at most2048 controls per source. An individually larger original patch evicts all other entries and remains alone;2048 is not a universal hard cap on the original patch size. Temporary construction of a replacement still needs the original patch allocation. There is no process-global or whole-model cache.
