# Original B-spline joins and sweep audit, 2026-10-30

Geometry and proof producers are Rust. Python only freezes inputs, launches native checks, and records hashes. This qualification does not publish WASM, run STEP/UI, change limits, or manipulate application focus.

## New proof scope

`cad-predicates::rational_bspline_independent_strip_jet_identity` no longer requires the same along degree, control census, or original knot partition. It evaluates original transverse homogeneous jets by exact rational de Boor series. Both along domains are normalized using exact positive widths; the union of original active knots partitions the complete seam. On each nonempty interval a second formal de Boor recurrence produces every power coefficient, padded by exact zeros when degrees differ. No fitted or rounded extracted surface supplies evidence.

The unchanged projective G1/G2 relations then check every homogeneous coefficient. Original source interior/periodic joins and independent interval normal covers remain mandatory. Full source equality is the only source-audit reuse. Each source retains its shared 4096-cell/depth-12 normal ledger, and all exact work remains charged to the original per-seam maximum of 1,000,000.

If affine correspondence fails, the first original interior knot from each source can propose `phi(t)=r*t/(1+(r-1)*t)`, where `r=a*(1-b)/(b*(1-a))`. Exact arithmetic must prove `r>0`. The common partition includes all original B knots and all preimages of original A knots. The transformed recurrence uses the linear homogeneous numerator and positive denominator of phi, producing `D(t)^p * H_A(phi(t))`. Because D is positive throughout the complete domain and independent of the transverse coordinate, it cancels from every Cartesian transverse jet. Every coefficient still has to satisfy the projective relations; knot correspondence alone grants no certificate. Missing proposals, unrelated representations, singularities, resource exhaustion and failed identities remain refusals. Arbitrary nonlinear reparameterizations and variable projective gauges are not claimed.

## Original world-curve ownership

`rational_bspline_independent_trace_identity` uses the same original-span coefficient comparison for the actual world curve and support trace. It permits independent degrees, counts and knots, but MUST use affine correspondence when the authored pcurve is linear. A fractional-linear geometric seam proof cannot certify a linear pcurve with a different parameterization. Reversal uses exact negation of reversed original knots. If either the curve or support free direction declares periodicity, an independent exact original endpoint-closure proof remains mandatory; a clamped closed chain can therefore own a periodic support trace without relying on flags.

Full boundary G1/G2 still requires complete edge extraction, original curve/support correspondence, connected vertex links, whole-face regularity, and all owned seam proofs. The new native integration test binds one actual torus world edge represented as a clamped cubic chain to the original doubly periodic quadratic tensor support. Mutating a world coefficient must remove the complete-boundary certificate. A smooth boundary certificate does not grant `solidCertified`.

The existing rounded-complement reversal regression retains its geometric refusal. Since failed original-basis coefficient comparisons now consume exact work, its result is a charged `Indeterminate` decision instead of an uncharged `None`; it still cannot certify equality. Existing Bezier composition and exact cap mismatch-witness paths are preserved.

## Sweep audit boundaries

The fresh native runner checks sweep laws/frames/bounds; retained walls, decomposition and filled caps; complete smoothness; embedding/regularity; material volume/orientation; nesting; intersections; and public native complete-boundary protocol. These checks exercise proof producers and refusal composition. They are not a fresh replay of the historical 207-case STEP matrix and do not imply universal coverage.

Source review preserves these independent gates:

* Open capped `continuousBound` requires a source wall bound, original complete cap contour ownership (including every hole), and filled-cap correspondence/error bounds. The final error is the maximum of wall and cap bounds. Budget acceptance, regularity and volume remain separate.
* Closed `continuousBound` requires original periodic wall correspondence, retained decomposition and complete wall ownership. Regularity and material volume are checked afterward; their failure must keep the construction refused even if a continuous distance bound is known.
* RMF/holonomy bounds continue to use original transport, original arc phase and charged interval restrictions; a frame flag or sampled closing correction grants no proof.
* Embedding includes exact boundary ownership, trim-domain checks and intersection evidence. Shell material roles, nesting and outward orientation remain independent conditions for solid volume.
* Complete G1/G2 requires every owned edge and the entire face/vertex evidence. Profile/station certificates alone are insufficient. Sharp miter/cap joins remain C0.

Outstanding broad scope: arbitrary nonlinear seam parameter maps, all previously unproved original-frame/law combinations, and unrestricted global intersection/nesting proofs are not closed by this change. The machine-readable result explicitly retains `fullGoalComplete:false`.
