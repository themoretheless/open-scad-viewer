# STEP-приёмка подготовленного G2-тела, 2026-11-02

Новый регрессионный тест `admitted_patch_body_step_roundtrip_retains_closed_curvature_bounded_boundary` строит подготовленную трёхпатчевую сеть атомарным trim/sew API, экспортирует STEP /9 и импортирует обратно. Отчёты исходного тела не используются как доказательство импортированного результата.

После импорта заново проверяются замкнутость, G2 на всех исходно квалифицированных швах, ограничение кривизны каждой грани 10 мм⁻¹ и глобальное отсутствие самопересечений. Область швов сопоставляется по уникальному точному совпадению исходных кривых; это лишь выбор области, G2 проверяется на импортированных поверхностях. Допуски G2: позиция — tolerance_mm исходного тела, нормаль 1e-5, кривизна 1e-4.

Все 4 теста embedded_patch_body прошли. Первая попытка нового теста использовала недопустимый бюджет 100000 ячеек face_curvature; исправлено на предусмотренные API 50000. Рабочие допуски и предел кривизны не изменены.

OpenCascade через cadquery-ocp независимо прочитал body.step: BRepCheck валиден, 1 Solid, 1 Shell. Этот независимый осмотр не проверяет G2; его заново проверяет Rust-тест.

Воспроизведение:

```sh
EMBEDDED_PATCH_STEP_OUTPUT=/tmp/embedded-g2-roundtrip.step CARGO_TARGET_DIR=/tmp/open-scad-trim-g2-20261101 cargo test --offline --manifest-path crates/Cargo.toml --config profile.dev.package.brep-core.opt-level=2 --config profile.dev.package.brep-core.debug=0 -p brep-core --test embedded_patch_body -- --nocapture
```

Артефакт body.step.gz сжат без времени в заголовке; SHA распакованного файла находится в occt-report.json. Результат относится к подготовленной сети на общем носителе, не к произвольным пространственным NURBS-рёбрам, независимым радиусам или автоматически найденным контактам. Толщина, закон радиуса, объём, UI/история и текущий WASM этой проверкой не квалифицированы. Полная дорожная карта остаётся открытой.
