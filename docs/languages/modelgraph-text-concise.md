# Короткая запись ModelGraph Text

Все примеры ниже — полные модели для редактора. Начальная строка выбирает язык
ModelGraph Text; синтаксис OpenSCAD остаётся отдельным.

## Аргументы по умолчанию и тип результата

После типа аргумента можно указать `= выражение`. Пропущенный аргумент получает
это значение. Оно вычисляется в окружении объявления функции и может ссылаться
на ранее объявленные аргументы. Переданное явно значение заменяет значение по
умолчанию; заменённое выражение не вычисляется. После изменения параметров
модели выражения пересчитываются, в том числе в каноническом документе.

В короткой функции `=> выражение` можно опустить тип результата. Явное
`-> Geometry` или другое ограничение типа по-прежнему поддерживается.

```text
// @modelgraph-text/1
param thickness = 4mm range 1mm..10mm
fn plate width: length, depth: length = width / 2, height: length = thickness =>
  box([width,depth,height])

show [plate(20mm),plate(width: 20mm,height: 6mm).move(x:25mm)]
```

Позиционные аргументы идут в порядке объявления. Именованные можно передавать
в любом порядке и пропускать те, у которых есть значение по умолчанию.
Смешивать именованные и позиционные аргументы в одном вызове нельзя.
Неизвестные и повторяющиеся имена, пропущенные обязательные аргументы и
несовместимые единицы приводят к ошибке.

Короткая запись работает также с `plate = fn width: length => ...`.
Фигурные скобки позволяют оставить проверки перед возвратом:

```text
// @modelgraph-text/1
plate = fn width: length = 20mm {
  assert(width > 0mm).message("Ширина должна быть положительной")
  ret box([width,12mm,4mm])
}
show plate()
```

Функция с отступами без `->` и без `=>` остаётся функцией **без результата**.
Это сохраняет смысл уже существующих вспомогательных функций с `assert`.

## Функция вместо пересылающей лямбды

В `select`, `where`, `aggregate` и других методах последовательностей можно
передать имя функции. В `repeat` функция получает один индекс.

```text
// @modelgraph-text/1
fn positive height: length => height > 0mm
fn plate height: length, width: length = 8mm => box([width,6mm,height])
show [4mm,0mm,8mm].where(positive).select(plate).move(z:2mm)
```

Одноаргументный callback получает элемент. Если у функции объявлен второй
обязательный аргумент, методы, поддерживающие индекс, передают его туда.
Если второй аргумент имеет значение по умолчанию, оно сохраняется. Редуктор
получает аккумулятор и элемент. Остальные аргументы функции должны иметь
значения по умолчанию. Проверки функции сохраняются при таком вызове.

```text
// @modelgraph-text/1
fn pin index: int => cylinder(2mm,6mm).move(x:index*8mm)
show repeat(4,pin)
```

`repeat` сохраняет своё прежнее поведение объединения результатов. Для отдельных
объектов используйте `select` или `foreach`.

## Индексы и распаковка

`values[index]` соответствует `at(values,index)`. Индекс отсчитывается от нуля;
он должен быть целым безразмерным числом в границах списка. Поддерживаются цепочки
вроде `items[1].sizes[0]`.

```text
// @modelgraph-text/1
sizes = [[20mm,12mm,4mm],[30mm,16mm,6mm]]
[width,depth,height] = sizes[1]
show box([width,depth,height])
```

Распаковка `[a,b,c] = values` требует ровно три элемента; она не обрезает список.
Имена должны быть различными. Проверка длины выполняется также для вычисляемых
списков. Распаковку можно использовать на верхнем уровне, в функциях, в блоках
`foreach` и `match`.

```text
// @modelgraph-text/1
fn plate sizes: Vec<length> -> Geometry
  [width,depth,height] = sizes
  ret box([width,depth,height])

show [[20mm,12mm,4mm],[30mm,16mm,6mm]].select(plate)
```

## Преобразования коллекций

`move`/`translate`, `rotate`, `scale` и `mirror` принимают коллекции фигур.
Преобразование применяется ко всем деталям относительно общего начала координат.
Они остаются отдельными объектами, даже если соприкасаются. Для геометрического
объединения по-прежнему нужен явный `union(parts)`.

```text
// @modelgraph-text/1
parts = [for i in 0..<3 => box([10mm,8mm,4mm]).move(x:i*10mm)]
show parts.move(z:5mm).rotate(z:30deg).scale(x:1.5)
```

Операции, меняющие топологию, например `extrude`, не применяются неявно ко всей
коллекции: вызовите их для отдельных элементов или явно объедините профили.
