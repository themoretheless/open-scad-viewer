# ModelGraph NURBS — инструкция для LLM

ModelGraph NURBS uses our own Rust numerical kernel, with no third-party spline or B-rep kernel. Select language:"modelgraph/nurbs-1",units:"mm". Scalars are finite numbers or {param:"id"}; define parameters:[{id,value}],nodes and root. Read the accompanying schema. Graph IDs are unique, all nodes reachable, cycles forbidden. Maximum128nodes, depth32 and30000values. This contract uses own Rust geometry and the shared brep-topology library, without routing into Manifold.
curve nodes specify degree, expanded knots, control_points (all2D orall3D), positive weights and periodic. surface nodes specify degree_u/v, knots_u/v, control_points[u][v][xyz], weights[u][v], periodic_u/v. Expanded knots have controlCount+degree+1 entries, finite nondecreasing values and active domain[knots[degree],knots[controlCount]]. Periodic data uses explicitly wrapped control points and extended knots, not an implicit one-period kernel-specific convention. Evaluation is homogeneous rational B-spline evaluation with first and second derivatives. At insufficient-continuity knots derivatives can be unavailable. Degenerate surface normals/curvatures are null; inspect derivative_status.
curve_edit supports insert_knots:[{value,count}], degree elevation, trim:[a,b] and reverse, in that order. surface_edit supports the same peraxis and trim:[uMin,uMax,vMin,vMax]. The NURBS foundation API separately provides outward-rounded per-span positive-denominator/hull certificates, conservative regularity classifications, bounded approximation, analytic linear-span projection, certified insertion/elevation wrappers, and exact affine monotone reparameterization. ModelGraph curve and surface root reports include these foundation certificates. A certificate can explicitly report unresolved; this is not proof of failure or regularity. General interval root isolation, nonplanar normal regularity, knot removal, degree reduction and nonlinear rational reparameterization are not implied. Elevation uses rational Bezier pieces and may increase interior knot multiplicities while preserving the curve image; reduced encoded continuity can make knot derivatives unavailable even for a smooth image. Insertion, trimming and elevation of periodic data operate on the active period and return a clamped nonperiodic representation; exact affine reparameterization and reversing preserve wrapped periodic storage, but full periodic insertion/removal/elevation is not yet a product edit. To split, create two trimmed references to one curve. iso_curve fixes the named u or v parameter. transform accepts a finite affine4x4 matrix and transforms control points; no perspective matrices.
grid_spline_surface(points,parameters_u,parameters_v) interpolates rectangular 2..11 site grids per axis with tensor natural cubics on [0,1]^2. Sites indexed [u][v] use mm; parameters strictly increase and are dimensionless. Real-arithmetic C2 is not a binary64 certificate. No regularity or injectivity guarantee; max31 controls per axis, precision refusals inherited from natural spline.
hermite_patch(corners,tangent_u,tangent_v,twist) constructs a bicubic [0,1]^2 patch from four positions, first u/v derivatives and mixed uv derivatives indexed [u][v]. All jets use mm per dimensionless parameters. Degenerate patches are permitted; no regularity or injectivity certificate. Nonfinite or unrepresentable authored conditions are refused.
closed_spline_curve(points,parameters) interpolates 4..86 sites including an exactly repeated endpoint. A cyclic cubic moment system matches real-arithmetic C2 through all joins and seam. Output domain [0,1] uses clamped, not periodic knots; binary64 continuity is not certified, regularity and absence of self-intersections are not guaranteed.
clamped_spline_curve(points,parameters,start_tangent,end_tangent) interpolates sites with endpoint dP/dt tangents in mm per dimensionless authored parameter. Interior tangents are solved for real-arithmetic C2 continuity. Output domain [0,1] scales endpoint derivatives by total authored parameter span; binary64 continuity is not certified and one-sided trimmed jets are needed at joins.
natural_spline_curve(points,parameters) interpolates 2..86 sites with natural zero second derivatives at endpoints, and solves interior cubic moments. Parameters are dimensionless and strictly increasing; positions use mm. Output domain is [0,1]. Real-arithmetic C2 continuity is not a binary64 certificate; joins require trimmed one-sided jets. Singular paths and overshoot are possible.
hermite_curve(points,tangents,parameters) constructs piecewise cubic interpolation of2..86 matching3D sites and authored dP/dt tangents. Parameters strictly increase and are dimensionless; points and tangents use mm coordinates. Output parameter is normalized to[0,1], so derivatives scale by the authored parameter span. Interior C0-multiplicity knots require one-sided jets; regularity is not certified.

Each loop is connected and closed with material left: CCW outer boundaries, CW holes; disconnected outer loops and a single multi-span circle are supported. Only degree-one rational lines and rational quadratic circular arcs are admitted; general noncircular NURBS fail explicitly. Curves and cap trims remain rational, without sampled profile reconstruction. Limits:64 loops,254 curve references and254 active knot spans in total,8192 control points and256 final faces. Each nonempty loop has at least one curve; loops:[] yields an empty B-rep. z_min/z_max are millimeters within +/-1000000 and z_max-z_min must be at least0.00001mm. brep_boolean(inputs:[a,b],operation) supports union, intersection, difference and xor. Text uses a.brep_union(b), a.brep_subtract(b), a.brep_intersection(b), a.brep_xor(b). Bounded planar CSG supports concave regions and holes. Curved CSG supports parallel extrusions of lines/circular arcs: equal axial intervals for all operations, arbitrary axial overlap for intersection, through cutters for difference and equal-footprint interval union/XOR/difference along the axis. A covering cutter footprint can remove a partial axial interval and leave zero, one or two separate bodies. Rational trimmed arcs and ruled surfaces remain authoritative; binary64 intersections and rigid-frame roundoff normalization are numerical, not certified. Empty results have no topology and tessellate to an empty mesh with null bounds. Strictly separated curved carrier hulls support independent bodies. Bounded stepped line/circle prisms support unequal axial intervals and repeated Boolean use after serialization, with at most8 layers,16 profiles and32 planar cells plus existing B-rep budgets. General sphere/torus/NURBS intersections remain unsupported. brep_chamfer(edges,size) and brep_fillet(edges,radius,segments) operate on connected convex planar edge chains; fillets are faceted approximations. Unresolved curved Boolean cases and curved blends are rejected without mesh fallback. brep_tessellate samples it with segments:1..32 and preserves faceIds. Shared B-rep topology includes vertices, edges, oriented coedges, loops, faces, shells and bodies. Geometry agreement is sampled, not certified; shell containment and self-intersections are not certified. General curved B-rep booleans, exact surface/surface trimming, STEP, analytic fillets and offset-shell construction are not implemented. Multi-profile progressive_sweep(profile1,profile2,...,path,scale:...,twist:...,normal:...,max_deviation:...) accepts 1..64 ordered profile curves followed by one path. All curves refine on common stations and share one acceptance budget; output is walls only, without contour nesting, caps or sewing. Direct API retains profilePatchRanges. brep_progressive_sweep([[outer],[hole,...]],path,scale:...,twist:...,normal:...,max_deviation:...) builds rational swept walls with audited planar cap trims and shared B-rep incidence. Profiles are world-space 3D curves. Open paths have audited planar caps; closed paths reuse periodic seam edges and preserve hole contours as inner shells. Refinement retains one aggregate sampled budget, constrained by the B-rep face budget. Cap nesting/orientation/simplicity must be proven; unresolved caps refuse. Side regularity and global self-intersections are unproven. Use brep_tessellate for display; Solid retains the authoritative body.

## MCP workflow

1. Read modelgraph_nurbs_language or openscad://language/modelgraph-nurbs-1.
2. Create a document and call modelgraph_nurbs_compile for graph validation and parameter resolution.
3. Call modelgraph_nurbs_evaluate for numerical jets, modelgraph_nurbs_build for evaluated definitions, mesh diagnostics and preview images.
4. Export JSON to preserve rational control data or STL/3MF/AMF from a closed mesh; OBJ/PLY/OFF can represent open meshes. STEP and general curved B-rep booleans are not implemented; planar B-rep booleans are available. Inspect topology and self-intersection status before claiming printability.

This implementation uses repository-owned Rust geometry kernels with a WASM bridge. Rational B-reps remain authoritative; tessellation is derived display/export data. Jobs use disposable Node processes (two concurrent,30seconds); they do not fall back to another kernel. The browser editor remains SCAD-based; use these tools through local or HTTP MCP.
